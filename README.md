一个仓库、十三个页面，给英文弱、中文强的高一新生用的 A-Level / IGCSE 自学预习站。
零外部依赖，手机 / 平板 / 电脑都能打开，支持一键中英切换（选择会被记住）。

在线地址：<https://xihongactuary.github.io/alevel-pure-math/>

## 每站长什么样

统一三段式：

1. **本单元包括什么** —— 先给一张路线图，知道今天要走哪几站
2. **知识点** —— 手绘示意图 → 说人话 → 记住这几点 → 一道例题 → 一道练习（答案默认折叠，点击展开）
3. **核心公式卡** —— 中英对照，考前扫一眼

练习答案一律折叠，先自己想，再点开对答案。打印时答案会自动展开。

## 物理站的实验部分

物理是实验科学，AS 阶段实验技能单独占一个单元；A2 六个单元也分别配了仿真与家庭实验。站里除了「实验技能」七站（有效数字、仪器读数、误差、不确定度、作图、直线化、6 分设计题），
「★ 学习资源」tab 的第一组就是**实验与仿真**：

- IOPSpark Practical Physics（英国物理学会 + Nuffield，含步骤、器材、安全、技术员说明）
- PhysicsUK 互动实验（涟漪水槽、电容充放电、简谐振动、光电效应）
- PhET、oPhysics、Maths with Matt、MarkScheme 9702 仿真
- 折叠卡「在家也能做的 16 个实验」（单摆测 g、弹簧胡克定律、水面波、水果电池……后 6 个覆盖 A2：弹簧振子、阻尼与共振、比热容、电容充放电、线圈发电、LED 里的量子）
- A2 专属：第五组「六个单元的仿真」（引力与轨道、单摆、共振、气体分子、电场等势面、电容、法拉第、光电效应等 PhET 仿真），第六组为 Save My Exams / Khan Academy / A Level Physics Online 的 A2 讲法

## 计算机科学站（0478）

按 Cambridge IGCSE Computer Science **0478**（2026–2028 大纲）组织，两卷各 1 小时 45 分、75 分：

- **Paper 1 计算机系统**（单元 1–6，灰蓝色角标）：二进制与数据表示、数据传输、硬件、软件、互联网与其用途、新兴技术
- **Paper 2 算法、编程与逻辑**（单元 7–10，青绿色角标）：算法设计与问题解决、编程、数据库、布尔逻辑

站里特色：伪代码一律采用 CAIE 官方写法（`←` 赋值、`IF … THEN` 同行、`FOR … NEXT`、`PROCEDURE` / `FUNCTION`、`DECLARE … ARRAY[1:n]`、`DIV` / `MOD`、`&` 拼接）；速查表第 7 组是「伪代码全套写法」，考前过一遍即可。

「★ 学习资源」tab 第一组是**能动手玩**的工具：Cisco 二进制游戏、CircuitVerse 与 logic.ly（搭逻辑门、自动生成真值表）、Scratch、Code.org、CS Unplugged（不插电学计算机科学）；第四组是 Paper 2 实战：在线 Python 编辑器、SQLBolt、W3Schools SQL；另有折叠卡「没有电脑也能练的 12 件事」。

## 化学站（9701）

按 Cambridge International AS & A Level Chemistry **9701**（2026–2028 大纲）组织，18 个单元 108 站，三大分支用角标颜色区分：

- **物理化学**（单元 1–8）：原子结构、摩尔计算、化学键、状态与气体、能量学、氧化还原、平衡与酸碱、动力学
- **无机化学**（单元 9–12，橙色角标）：周期性与第 3 周期、第 2 族、卤素、氮与硫
- **有机化学**（单元 13–17，紫色角标）：有机入门、烷烃烯烃、卤代烃与醇、羰基羧酸与衍生物、含氮化合物与聚合物
- **光谱与分析**（单元 18，粉色角标）：质谱、红外 IR、¹³C NMR、¹H NMR 与综合析谱

站里特色：每站配手绘示意图（原子轨道、点叉图、VSEPR 形状、反应机理 curly arrow、能量曲线、质谱/光谱等）；化学式用 `<sub>/<sup>` 规范排版；反应机理统一用弯箭头表示电子移动。速查表 11 组含「必背常数」「VSEPR 形状表」「无机趋势汇总」「有机官能团与命名后缀」「光谱特征吸收表」与「九条闭眼也要写得出的方程式」。「★ 学习资源」tab 第一组是**能动手玩**的工具（PhET 搭原子、MolView 3D 分子、Ptable 互动周期表）。

## 数学站的应用模块（力学 + 统计）

9709 数学除纯数学外还有两个应用模块，各独立成一页：

- **力学 `alevel-mechanics.html`**（6 单元 34 站）：运动学（suvat 五方程）、运动图像（s–t / v–t / a–t 图，斜率与面积）、力与平衡（合成 / 分解 / 摩擦 / 斜面）、牛顿定律（F=ma、连接体、电梯视重）、动量（守恒 / 冲量 / 碰撞）、功与能（动能 / 势能 / 功率）。速查表含 suvat 五方程与「画图→定方向→列已知→选公式」解题套路。
- **概率统计 `alevel-statistics.html`**（7 单元 37 站）：数据表示（直方图 fd=频数÷组宽 / 箱线图 / 茎叶图 / 累积频率图）、集中趋势与离散度（mean / median / 方差 / 标准差）、概率（Venn / 树图 / 互斥独立 / 条件概率）、排列组合（nPr / nCr）、离散随机变量（E(X) / Var(X)）、二项分布 B(n,p)、正态分布 N(μ,σ²)（Z 标准化）。

两页的「★ 学习资源」tab 第一组都是能动手玩的 PhET 模拟（力学：力和运动、抛体、能量滑板；统计：弹球概率、数据拟合）。
