2六大核心时态 · 时间轴对比
时态是英语语法地基。红色标注的「现在完成时」是中国学生最难掌握的——它跟一般过去时最容易混。
一般现在
do / does
He plays basketball every day.
every day, always, usually, often
一般过去
did（动词过去式）
He played basketball yesterday.
yesterday, last..., ...ago, in 2020
一般将来
will do / be going to do
He will play basketball tomorrow.
will = 临时决定 | be going to = 早已计划
现在进行
am/is/are + doing
He is playing basketball now.
now, look!, listen!, at this moment
过去进行
was/were + doing
He was playing basketball at 8 last night.
at + 过去时间, when/while
现在完成 ★
have/has + done（过去分词）
I have finished my homework.（写完了=现在不用写）
She has lived here for 3 years.（住了3年=现在还住）
already, yet, just, ever, never, for+时段, since+时点
⚠ 现在完成时 vs 一般过去时 —— 最易混
一般过去：强调"何时发生"
I lost my key yesterday.
只说昨天丢了，不管现在
现在完成：强调"现在状态"
I have lost my key.
= 现在没钥匙，进不了门
易错：has gone to vs has been to
has gone to
He has gone to Beijing.
去了还没回（人不在这）
has been to
He has been to Beijing.
去过已经回来（有经验）
判断口诀
看到 yesterday / last / ago / in+年份（具体过去时间）→ 一般过去时
看到 already / yet / just / ever / never / for+时段 / since+时点 → 现在完成时

who 已代替 the girl，she 多余

宾语从句两大铁律
① 时态一致：主句过去时 → 从句也变过去时（客观真理除外，如 The earth moves around the sun）
② 陈述语序：宾语从句永远用主语+谓语，不能写成疑问语序
状语从句核心规则
主将从现：主句用将来时(will)，时间/条件状语从句用现在时表将来。
例：If it rains tomorrow, I will stay at home.（不能说 will rain）

6语法复习心法
比背规则更重要的，是掌握正确的思维方式。

① 时态：先问"什么时候"

中文没有时态标记，所以中国学生最容易忘。每次写英语前先问自己：这件事发生在过去、现在、还是将来？答案一出，时态就定了。

② 从句：先找连接词

宾语从句 → 记住"时态一致 + 陈述语序"；状语从句 → 记住"主将从现"；定语从句 → 记住"关系词后不能再有它代替的代词"。

③ 主谓一致：三步检查链

找主语 → 判断人称单复数 → 确认动词形式。写句子前过一遍，三单漏加 s 的问题基本能消灭。

④ 介词搭配：场景联想

别死背。in = 沉浸进去（interested in）；at = 指向一个点（arrive at, good at）；on = 接触表面（depend on）。

⑤ 主动输出 > 被动输入

看懂规则不等于会用。每学一个点，立刻用造句"逼"自己用出来——卡住的地方，就是没真懂的地方。

⑥ 错题是最好的老师

错题不是用来"记住正确答案"的，而是用来找到思维盲区的。每次做错，问自己：我为什么会这么选？是哪一步推理断了？

核心概念
动词不充当谓语时的三种形态：to do（不定式）、doing（动名词/现在分词）、done（过去分词）
记忆口诀
to do 表将来和目的，doing 表习惯和进行
done 表被动和完成，三种形态别混用
to do vs doing 核心对比
stop to do
He stopped to smoke.
停下（手头的事）去抽烟 → 还没抽
stop doing
He stopped smoking.
停止抽烟 → 不抽了
remember to do
Remember to lock the door.
记得要去锁门 → 还没锁
remember doing
I remember locking the door.
记得锁过门 → 已锁
forget to do
Don't forget to call me.
别忘了打电话 → 还没打
forget doing
I'll never forget meeting her.
忘不了见过她 → 已发生
思维差异

中文"记得做"和"记得做过"靠上下文区分，英语靠 to do / doing 一刀切。记住：to do 指向未来还没做，doing 指向过去已发生。

动名词 doing 作主语/宾语
Swimming is good for your health.（作主语）
I enjoy reading books.（作宾语）
过去分词 done（表被动/完成）
现在分词 doing（主动/进行）
the boy reading a book
男孩主动在读
过去分词 done（被动/完成）
the book written by him
书是被写的
思考追问
这句话怎么填？"I want ____ (buy) a new phone." → to buy 还是 buying？
分析：want 后面接什么？
规则：want to do sth（想要做某事）—— 表"将来想做的事"
推导：买手机还没买，表将来 → to buy
答案：I want to buy a new phone.
⚠
陷阱：接 to do 还是 doing 的动词

接 to do：want, hope, decide, plan, agree, refuse, promise
接 doing：enjoy, finish, keep, mind, practice, avoid, consider
接两者（意思不同）：stop, remember, forget, try（try to do=尽力做 / try doing=试着做）

核心公式
被动语态 = be + done（过去分词）　be 随时态变化，done 不变
记忆口诀
被动就是宾语变主语，be 加过去分词不能丢
时态变化be 来变，分词永远是 done
主动 → 被动 三步转换法
原句（主动）
Tom broke the window yesterday.
Step1：找宾语 → the window → 提到主语位置
Step2：动词变 be + done → was broken（过去时→was）
Step3：原主语用 by 引出 → by Tom
结果：The window was broken by Tom yesterday.
各时态被动语态结构
一般现在时
am/is/are + done
English is spoken here.
一般过去时
was/were + done
The bridge was built in 1990.
一般将来时
will be + done
The work will be done tomorrow.
现在完成时
have/has been + done
The work has been done.
现在进行时
am/is/are being + done
The house is being painted.
含情态动词
情态 + be + done
It must be done at once.
什么时候用被动？

① 不知道/不必说谁做的：The window was broken.（不知道谁打破的）
② 强调承受者：The bridge was built in 1990.（重点是桥不是人）
③ 客观说明：English is spoken in many countries.

⚠
陷阱：不及物动词没有被动

happen, take place, occur, belong to, last, cost 等不及物动词不能变被动。
❌ The accident was happened. ✅ The accident happened.

思考追问
改成被动句："People speak English in Canada." → ____
Step1 找宾语：English → 提到主语
Step2 动词变被动：speak → is spoken（一般现在时，English 单数）
Step3 by 引出原主语：by people（可省略）
答案：English is spoken (by people) in Canada.

① There be 句型
口诀
There be 表"存在"，主语在 be 后面
时态变 be（is/are/was/were/will be），就近原则要记住
常见错误

中文"有"直译，英语不用 has
正确
There is a book on the desk.
表"存在"用 there be
思维差异

中文"桌子上有本书"用"有"，学生容易翻译成 has。但 has 表示"拥有"，there be 表示"存在"——某处存在某物，一律用 there be。

★动词变形规则 · 三大变化总结
时态、被动语态、完成时全部依赖动词变形。三单变化、过去式、过去分词是英语语法的"地基中的地基"。
总口诀
三单看主语人称（he/she/it 加 s）
过去式看"昨天发生"（加 ed 或不规则）
过去分词看"完成/被动"（have/has/be + done）

二、虚拟语气入门（进阶内容）
核心概念
虚拟语气 = 说的不是事实，而是假设/愿望/建议。和陈述语气（说事实）完全不同。
虚拟语气三步判断
Step1：这是事实还是假设？
Step2：假设 → 用虚拟语气
Step3：看假设的时间（现在/过去/将来）→ 动词变形
① 与现在事实相反
If I were you, I would study harder.（如果我是你 → 我不是你）
结构：If + 过去时(were)，主句 + would/could/should + do
② 与过去事实相反
If I had studied harder, I would have passed.（如果我当初更努力 → 我当初没努力）
结构：If + had done，主句 + would have done
③ 与将来事实相反
If it were to rain tomorrow, I would stay home.（万一明天下雨 → 不太可能）
结构：If + were to do / should do，主句 + would do
⚠
最大坑：虚拟语气里 was → were

虚拟语气中，无论主语是什么，be 动词一律用 were（不用 was）。
❌ If I was rich... → ✅ If I were rich...
❌ If she was here... → ✅ If she were here...

wish 后的虚拟

I wish I were taller.（我希望我更高 → 现在没那么高）
I wish I had studied harder.（真希望当初更努力 → 过去没努力）
wish + 过去时 = 对现在的愿望
wish + had done = 对过去的后悔

★ 现在不用背虚拟语气的全部结构，只要知道"虚拟语气 = 说的不是事实"这个概念，开学后就不会懵

1情态动词 · 完整系统
情态动词表达说话人的态度——能力、许可、可能、必须、建议。它没有人称和数的变化（can 不加 can-s），后接动词原形。
情态动词四大特点
① 不变形（can 不会变 cans）
② 后接原形（can do，不是 can to do）
③ 无分词（没有 canning）
④ 疑问否定自身变（Can you? / cannot / can't）
按功能分类
能力（can / could）
She can swim.
He could run fast at 5.
could 也可表委婉请求
许可（may / can）
May I come in?
You can go now.
may 更正式
必须/必要（must / have to）
You must stop.（主观必须）
I have to wear a uniform.（客观要求）
must 主观 / have to 客观
建议/义务（should / ought to）
You should rest.
You ought to apologize.
should 更常用
可能性（may / might / could）
He may be at home.
It might rain.
might 可能性更低
需要（need / dare）
You needn't worry.
Dare he jump?
可作情态或实义动词
must be vs can't be（推测）
肯定推测：must be / must have done
He must be a teacher.（他一定是老师）
有把握的肯定判断
否定推测：can't be / can't have done
He can't be a teacher.（他不可能是一位老师）
mustn't = 禁止，不是"不可能"
⚠
最大坑：mustn't ≠ can't

mustn't = 禁止（You mustn't smoke = 你不能抽烟）
can't = 不可能（He can't be a thief = 他不可能是小偷）
中文"不能"可表示两种意思，英语必须分开！

should have done（虚拟完成）
should have done = 本该做却没做
You should have told me earlier.（你本该早点告诉我）→ 其实没告诉
shouldn't have done = 本不该做却做了
You shouldn't have eaten so much.（你本不该吃那么多）→ 其实吃了
could have done = 本可以做却没做
I could have helped you.（我本可以帮你）→ 其实没帮
have to vs must 口诀
must = 内心觉得"必须"（I must study hard）
have to = 外界要求"不得不"（I have to wear uniform）
must 只有现在时；have to 可变各种时态

口诀
