2[4]

说出分组交换（packet switching）比电路交换的两个优点。Give two advantages of packet switching over circuit switching.

点开看答案Show answer

任答两条：① 多条线路可同时共享同一条物理连接，带宽利用率高；② 数据包可走不同路径绕开故障节点，网络更健壮；③ 不需要为一次通信独占整条线路，成本更低。Any two of: ① many transmissions share the same physical link, so bandwidth is used efficiently; ② packets can reroute around failed nodes, making the network more robust; ③ no need to reserve a whole line for one call, so it is cheaper.

3[6]

写出 CPU 中以下寄存器的作用：MAR、MDR、PC、ACC。State the purpose of each CPU register: MAR, MDR, PC, ACC.

点开看答案Show answer

MAR（内存地址寄存器）：存放正要读写的内存地址；MDR（内存数据寄存器）：存放刚从内存读出或要写入内存的数据；PC（程序计数器）：存放下一条要执行指令的地址；ACC（累加器）：存放 ALU 运算的中间结果。MAR holds the memory address being read/written; MDR holds the data read from or to be written to memory; PC holds the address of the next instruction; ACC holds intermediate results of the ALU.

4[4]

说出编译器和解释器的两个区别。State two differences between a compiler and an interpreter.

点开看答案Show answer

① 编译器一次性把整个程序翻译成机器码再执行，解释器逐行翻译逐行执行；② 编译器生成可独立运行的机器码文件，解释器不生成独立文件；③ 编译后运行更快，但改代码要重新编译；解释器改完即可重跑，但运行较慢。① a compiler translates the whole program at once before running, an interpreter translates and runs line by line; ② a compiler produces a standalone machine-code file, an interpreter does not; ③ compiled code runs faster but needs recompiling after changes; an interpreter reruns instantly but runs slower.

5[6]

解释 HTTPS 如何比 HTTP 更安全地传输数据。Explain how HTTPS transmits data more securely than HTTP.

点开看答案Show answer

HTTPS 在 HTTP 上加了 SSL/TLS 加密：① 数据在发送前被加密，即使被截获也无法读懂（窃听者看到的是密文）；② 用数字证书验证服务器身份，防止冒充；③ 这样就能安全传输密码、银行卡号等敏感信息。HTTPS adds SSL/TLS encryption on top of HTTP: ① data is encrypted before sending, so an eavesdropper only sees ciphertext; ② digital certificates verify the server's identity, preventing impersonation; ③ this makes it safe to send passwords, card numbers and other sensitive data.

6[8]

用伪代码写一个程序：输入 10 个数，输出它们的平均值。Write pseudocode that inputs 10 numbers and outputs their average.

点开看答案Show answer
Total ← 0 FOR i ← 1 TO 10 INPUT Num Total ← Total + Num NEXT i Average ← Total / 10 OUTPUT Average

要点：先初始化 Total 为 0，用 FOR 循环读 10 个数累加，最后除以 10 输出。别忘了给变量赋值用 ←。Key: initialise Total to 0, loop 10 times accumulating, then divide by 10. Use ← for assignment.

7[6]

学生表 Student 有字段 Name、Mark。写一条 SQL 查出分数不低于 80 的学生名字，并按名字升序排列。A table Student has fields Name and Mark. Write SQL to list the names of students with Mark at least 80, ordered by name ascending.

点开看答案Show answer
SELECT Name FROM Student WHERE Mark >= 80 ORDER BY Name ASC;

关键字顺序：SELECT → FROM → WHERE → ORDER BY。ASC 可省略（默认升序），但写上更规范。Order: SELECT → FROM → WHERE → ORDER BY. ASC is the default, but writing it is good form.

2[6]

(a) 解释奇偶校验（parity check）如何检测传输错误。(a) Explain how a parity check detects errors in transmission.

(b) 采用偶校验时，字节 1011011? 最后一位应为 0 还是 1？(b) Using even parity, should the last bit of 1011011? be 0 or 1?

点开看答案Show answer

(a) 发送前统计 1 的个数，加一个校验位使 1 的总数为偶数（偶校验）；接收方重新统计，若 1 的个数变成奇数，说明有奇数个位出错。(a) A parity bit is added so the total number of 1s is even (even parity); the receiver recounts — if the count is now odd, an odd number of bits has been corrupted.

(b) 1011011 有 5 个 1（奇数），要使总数为偶数，校验位应为 1（总数变 6）。(b) 1011011 has five 1s (odd), so the parity bit must be 1 to make six (even).

3[4]

解释虚拟内存（virtual memory）是什么，以及它在什么情况下被使用。Explain what virtual memory is and when it is used.

点开看答案Show answer

虚拟内存是把硬盘的一部分当作额外 RAM 使用。当 RAM 被占满、又有新程序要运行时，操作系统把暂时不用的数据从 RAM 挪到硬盘，腾出空间；需要时再换回来。缺点是硬盘比 RAM 慢得多，频繁换页会让电脑变卡。Virtual memory uses part of the hard disk as extra RAM. When RAM is full, the OS moves currently unused data to disk to free space, swapping it back when needed. Downside: disk is far slower than RAM, so heavy swapping makes the computer sluggish.

4[4]

说出自动系统中「传感器 → 处理器 → 执行器」这条链里，传感器和执行器各做什么。In an automated system's chain "sensor → processor → actuator", state what the sensor and the actuator each do.

点开看答案Show answer

传感器：测量物理量（温度、光、压力、运动等），把物理信号转成电信号；模拟信号通常还要经 ADC 转成数字信号给处理器。执行器：接收处理器的指令，把电信号转成物理动作（如开灯、启动电机、开阀门）。Sensor: measures a physical quantity (temperature, light, pressure, motion) and converts it to an electrical signal; an ADC often turns the analogue signal digital for the processor. Actuator: takes the processor's command and turns it into physical action (lighting a lamp, starting a motor, opening a valve).

5[8]

对比线性查找和冒泡排序：各是干什么的？各在大数据下表现如何？Compare linear search and bubble sort: what does each do, and how does each behave with large data?

点开看答案Show answer

线性查找：从头到尾逐个比较找目标，可用于无序数据；最坏要查 n 次，数据越大越慢。冒泡排序：相邻元素两两比较、把较大的「冒」到末尾，重复多轮直到有序；约需 n²/2 次比较，数据翻倍、时间翻四倍，大数据下很慢。二者都是简单但低效的算法，适合小数据或教学。Linear search checks items one by one, works on unsorted data, and takes up to n comparisons — slower as data grows. Bubble sort repeatedly swaps adjacent pairs so the larger values "bubble" to the end; it needs roughly n²/2 comparisons, so doubling the data roughly quadruples the time. Both are simple but inefficient, best for small data or learning.

6[8]

用伪代码写一个程序：在数组 List[1..n] 里找出最大值并输出。Write pseudocode to find and output the maximum value in an array List[1..n].

点开看答案Show answer
Max ← List[1] FOR i ← 2 TO n IF List[i] > Max THEN Max ← List[i] ENDIF NEXT i OUTPUT Max

先假设第一个是最大值，从第二个开始逐个比较，遇到更大的就更新 Max。循环结束 Max 就是最大值。Assume the first element is the max, then compare each remaining element and update Max whenever a larger one appears.

7[4]

解释数据库中的主键（primary key）是什么，并说明为什么每张表都需要它。Explain what a primary key is in a database and why every table needs one.

点开看答案Show answer

主键是唯一标识一条记录的字段（如学号、身份证号），它的值不能重复、也不能为空。需要它的原因：没有主键就无法可靠地区分两条记录，也无法在表之间建立关联（外键引用主键）。A primary key is a field that uniquely identifies each record (e.g. student ID); its values are unique and never null. Without it you cannot reliably tell records apart, nor link tables together (foreign keys reference primary keys).
