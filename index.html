1 多项式运算Polynomials Polynomial多项式

学完你会：看懂一个「多项式」，并算出把它代入某个数后的结果。

说人话：多项式就是「几个带 x 的项加在一起」，比如 x³ − 2x² − 5x + 6。 里面最高的那个次方（这里是 3），叫它的次数 degree。上图那种 S 形曲线，就是三次多项式长什么样。
记住这几点：
  • 次数 degree = 最高次项的次方数。
  • 代入求值：把 x 换成那个数，一项一项算。
  • 因式定理 Factor Theorem：如果 f(a) = 0，那么 (x − a) 一定是它的因式（能整除）。

例题

已知 f(x) = x³ − 2x² − 5x + 6。求 f(1)，并判断 (x − 1) 是不是它的因式。
解： 把 x 换成 1：f(1) = 1³ − 2×1² − 5×1 + 6 = 1 − 2 − 5 + 6 = 0。 因为 f(1) = 0，根据因式定理，(x − 1) 是 f(x) 的因式。

✏️ 你来试一题

先自己在纸上算，算完再点开答案。

已知 f(x) = x³ + 2x² − 5x − 6。求 f(2)。如果 f(2) = 0，这说明什么？
点开看答案
答案： f(2) = 2³ + 2×2² − 5×2 − 6 = 8 + 8 − 10 − 6 = 0。 因为 f(2) = 0，说明 (x − 2) 是 f(x) 的因式。

By the end you'll be able to: read a polynomial and work out its value when x is a number.

In plain words: a polynomial is just "several x-terms added together", like x³ − 2x² − 5x + 6. The highest power (here 3) is called its degree. The S-shaped curve above is what a cubic looks like.
Remember these:
  • Degree = the highest power of x.
  • To evaluate: replace x with the number and calculate term by term.
  • Factor Theorem: if f(a) = 0, then (x − a) is a factor of f(x).

Example

f(x) = x³ − 2x² − 5x + 6. Find f(1), and decide whether (x − 1) is a factor.
Solution: Replace x with 1: f(1) = 1 − 2 − 5 + 6 = 0. Since f(1) = 0, by the Factor Theorem (x − 1) is a factor.

Work it out on paper first, then open the answer.

f(x) = x³ + 2x² − 5x − 6. Find f(2). If f(2) = 0, what does that tell you?
Show answer
Answer: f(2) = 8 + 8 − 10 − 6 = 0. Since f(2) = 0, (x − 2) is a factor of f(x).

2 分式Rational expressions Rational expression分式

学完你会：把一个分式化简（约分），并知道分母永远不能为 0。

说人话：分式就是「上面一个式子、下面一个式子的分数」，比如 (x² − 4)/(x − 2)。 它和普通分数一样能约分，只是约的是整个括号。上图那条直线上的空心圈，就是被约掉的 (x − 2) 留下的「洞」。
记住这几点：
  • 分母不能为 0——这是出题最爱挖的坑。
  • 化简 = 上下先分解，再约掉相同的因式。

例题

化简 (x² − 4)/(x − 2)。
解： 先把上面分解：x² − 4 = (x − 2)(x + 2) 〔平方差公式〕。 于是 (x − 2)(x + 2) / (x − 2) = x + 2。 注意：这里要写上 x ≠ 2（因为原来分母不能为 0）。

✏️ 你来试一题

提示：上面 x² − 9 也是平方差，想想它等于什么乘什么。

化简 (x² − 9)/(x + 3)。
点开看答案
答案： 上面分解：x² − 9 = (x − 3)(x + 3)。 上下约掉 (x + 3)，得 x − 3。 别忘了条件：x ≠ −3。

By the end you'll be able to: simplify a rational expression — and remember the denominator can never be 0.

In plain words: a rational expression is "an expression on top and an expression underneath", e.g. (x² − 4)/(x − 2). You cancel whole brackets, just like with ordinary fractions. The open circle in the diagram is the "hole" left behind.
Remember these:
  • The denominator can never be 0 — exam questions love this trap.
  • To simplify: factorise the top and bottom, then cancel the common bracket.

Example

Simplify (x² − 4)/(x − 2).
Solution: Factorise the top: x² − 4 = (x − 2)(x + 2) [difference of squares]. So (x − 2)(x + 2)/(x − 2) = x + 2. Always add the condition x ≠ 2.

✏️ Your turn

Hint: x² − 9 is also a difference of squares.

Simplify (x² − 9)/(x + 3).
Show answer
Answer: x² − 9 = (x − 3)(x + 3). Cancel (x + 3): result is x − 3. Don't forget: x ≠ −3.

3 因式分解Factorisation Factorisation因式分解

学完你会：把一个二次式子拆成两个括号相乘。

说人话：因式分解就是「拆括号的逆运算」。比如 x² − 5x + 6 可以拆成 (x − 2)(x − 3)——你把它乘回去，正好还原。上图就是从面积的角度看这件事。
记住这三个就够用：
  • 平方差：a² − b² = (a − b)(a + b)
  • 完全平方：a² + 2ab + b² = (a + b)²
  • 二次三项式 x² + bx + c：找两个数 p、q，让 p×q = c 且 p+q = b，答案就是 (x + p)(x + q)。

例题

分解 x² − 5x + 6。
解： 要找两个数：乘积 = 6，相加 = −5。 想一下：−2 和 −3 —— (−2)×(−3) = 6，−2 + (−3) = −5。正好！ 所以 x² − 5x + 6 = (x − 2)(x − 3)。

✏️ 你来试一题

提示：找两个数，乘积 = 12，相加 = 7。（可以对照上面的面积图）

分解 x² + 7x + 12。
点开看答案
答案： 乘积 = 12、相加 = 7 的两个数是 3 和 4。 所以 x² + 7x + 12 = (x + 3)(x + 4)。 检验：(x+3)(x+4) = x² + 4x + 3x + 12 = x² + 7x + 12 ✓

By the end you'll be able to: split a quadratic expression into two brackets.

In plain words: factorising is "expanding brackets backwards". For example x² − 5x + 6 becomes (x − 2)(x − 3) — multiply it back out and you get the original. The area diagram shows why it works.
These three are enough for now:
  • Difference of squares: a² − b² = (a − b)(a + b)
  • Perfect square: a² + 2ab + b² = (a + b)²
  • For x² + bx + c: find p and q with p×q = c and p + q = b; answer is (x + p)(x + q).

Example

Factorise x² − 5x + 6.
Solution: We need two numbers: product = 6, sum = −5. −2 and −3: (−2)×(−3) = 6 and −2 + (−3) = −5. So x² − 5x + 6 = (x − 2)(x − 3).

✏️ Your turn

Hint: two numbers with product 12 and sum 7 (check the area diagram).

Factorise x² + 7x + 12.
Show answer
Answer: The numbers are 3 and 4. So x² + 7x + 12 = (x + 3)(x + 4). Check: (x+3)(x+4) = x² + 7x + 12 ✓

4 二次函数与图像Quadratic functions Quadratic function二次函数

学完你会：从 y = ax² + bx + c 里读出顶点在哪、和 x 轴交于哪几点。

说人话：二次函数就是「带 x² 的函数」，图像是一条抛物线 parabola，像个碗。 a > 0 时碗口朝上（有最低点），a < 0 时碗口朝下（有最高点）。
记住这几点：
  • 对称轴：x = −b / (2a)
  • 顶点（转折点）：把对称轴那个 x 代进去，算出 y。
  • 与 x 轴交点：令 y = 0 解方程（常用因式分解）。
  • 判别式 discriminant Δ = b² − 4ac：>0 两个交点，=0 一个，<0 没有交点。

例题

y = x² − 4x + 3，求它的顶点，以及和 x 轴的交点。
解： ① 对称轴：x = −(−4)/(2×1) = 2。 ② 代入求 y：y = 2² − 4×2 + 3 = 4 − 8 + 3 = −1。所以顶点是 (2, −1)（a=1>0，是最低点）。 ③ 与 x 轴交点：x² − 4x + 3 = 0 → (x − 1)(x − 3) = 0 → x = 1 或 x = 3。 所以交点是 (1, 0) 和 (3, 0)。

✏️ 你来试一题

照着例题的三步走：先对称轴，再代进去，最后令 y = 0 解方程。

y = x² − 6x + 8，求它的顶点，以及和 x 轴的交点。
点开看答案
答案： ① 对称轴：x = −(−6)/(2×1) = 3。 ② y = 3² − 6×3 + 8 = 9 − 18 + 8 = −1。顶点 (3, −1)。 ③ x² − 6x + 8 = 0 → (x − 2)(x − 4) = 0 → x = 2 或 4。交点 (2, 0)、(4, 0)。

By the end you'll be able to: read off the vertex and the x-intercepts from y = ax² + bx + c.

In plain words: a quadratic function has an x² term, and its graph is a parabola — like a bowl. If a > 0 it opens upwards (lowest point); if a < 0 it opens downwards (highest point).
Remember these:
  • Axis of symmetry: x = −b / (2a)
  • Vertex (turning point): substitute that x-value to get y.
  • x-intercepts: set y = 0 and solve.
  • Discriminant Δ = b² − 4ac: >0 two crossings, =0 one, <0 none.

Example

y = x² − 4x + 3. Find the vertex and the x-intercepts.
Solution: ① Axis: x = −(−4)/(2×1) = 2. ② y = 2² − 4×2 + 3 = −1, so the vertex is (2, −1) (a = 1 > 0, so it's the lowest point). ③ x-intercepts: x² − 4x + 3 = 0 → (x − 1)(x − 3) = 0 → x = 1 or 3. So the points are (1, 0) and (3, 0).

✏️ Your turn

Follow the same three steps: axis → substitute → set y = 0.

y = x² − 6x + 8. Find the vertex and the x-intercepts.
Show answer
Answer: ① Axis: x = −(−6)/2 = 3. ② y = 9 − 18 + 8 = −1, so vertex (3, −1). ③ (x − 2)(x − 4) = 0 → x = 2 or 4, so (2, 0) and (4, 0).

5 绝对值Modulus (absolute value) Modulus绝对值

学完你会：解带 | | 的方程。

说人话：|x| 读作「x 的绝对值」，意思就是把负号去掉，只留下这个数到 0 的距离， 所以结果永远 ≥ 0。比如 |−3| = 3，|3| = 3。图像就是上图那个 V 形。
记住这几点：
  • |x| = x（当 x ≥ 0）；|x| = −x（当 x < 0）。
  • 解 |A| = k（k > 0）就拆成两种可能：A = k 或 A = −k。

例题

解 |x − 3| = 5。
解：里面那一坨（x − 3）算出来可能等于 5，也可能等于 −5，两种都要考虑。 ① x − 3 = 5 → x = 8 ② x − 3 = −5 → x = −2 检验：|8 − 3| = 5 ✓；|−2 − 3| = |−5| = 5 ✓。所以 x = 8 或 x = −2。

✏️ 你来试一题

提示：拆成 2x − 1 = 7 和 2x − 1 = −7 两种情况。

解 |2x − 1| = 7。
点开看答案
答案： ① 2x − 1 = 7 → 2x = 8 → x = 4 ② 2x − 1 = −7 → 2x = −6 → x = −3 所以 x = 4 或 x = −3。

By the end you'll be able to: solve equations that contain | |.

In plain words: |x| means "drop the minus sign — just the distance from 0", so the result is always ≥ 0. For example |−3| = 3 and |3| = 3. Its graph is the V shape above.
Remember these:
  • |x| = x when x ≥ 0; |x| = −x when x < 0.
  • To solve |A| = k (k > 0), split it: A = k or A = −k.

Example

Solve |x − 3| = 5.
Solution: the inside could equal 5 or −5 — consider both. ① x − 3 = 5 → x = 8 ② x − 3 = −5 → x = −2 Check: |8 − 3| = 5 ✓ and |−2 − 3| = 5 ✓. So x = 8 or x = −2.

✏️ Your turn

Hint: split into 2x − 1 = 7 and 2x − 1 = −7.

Solve |2x − 1| = 7.
Show answer
Answer: ① 2x − 1 = 7 → 2x = 8 → x = 4 ② 2x − 1 = −7 → 2x = −6 → x = −3 So x = 4 or x = −3.

6 反比例Reciprocal functions Reciprocal function反比例函数

学完你会：看懂 y = k/x 这类函数，知道它的图长什么样、x 和 y 怎么互相影响。

说人话：反比例就是「一个变大、另一个就变小」。y = k/x：x 翻一倍，y 就减一半。 图像是两条弯弯的线（双曲线 hyperbola），永远碰不到 x 轴和 y 轴—— 这两条碰不到的线叫渐近线 asymptote。
记住这几点：
  • 形式：y = k/x（k 是常数，k ≠ 0）。
  • 渐近线：x = 0（y 轴）和 y = 0（x 轴）。（分母不能为 0，y 也不会等于 0）
  • 核心感觉：x 越大，y 越贴近 0。

例题

y = 6/x。当 x = 2 时 y 是多少？如果 x 变成 4（翻一倍），y 会怎么变？
解： x = 2 → y = 6/2 = 3。 x = 4 → y = 6/4 = 1.5。 所以 x 翻一倍，y 从 3 变成 1.5，正好减半——这就是「反比例」。

✏️ 你来试一题

第②问：把 y = 2 代进去，得到 2 = 12/x，两边同时乘 x 看看。

y = 12/x。① x = 3 时 y = ?　② 如果 y = 2，x = ?
点开看答案
答案： ① y = 12/3 = 4。 ② 2 = 12/x → 两边乘 x：2x = 12 → x = 6。

By the end you'll be able to: understand y = k/x — its shape and how x and y move together.

In plain words: inverse proportion means "one goes up, the other goes down". With y = k/x, if you double x, y halves. The graph is two curved branches (a hyperbola) that never touch the axes — those lines are called asymptotes.
Remember these:
  • Form: y = k/x (k is a constant, k ≠ 0).
  • Asymptotes: x = 0 and y = 0.
  • Big idea: the bigger x gets, the closer y creeps to 0.

Example

y = 6/x. What is y when x = 2? What happens to y if x becomes 4 (doubled)?
Solution: x = 2 → y = 6/2 = 3. x = 4 → y = 6/4 = 1.5. Doubling x halves y — that is exactly what "inverse proportion" means.

✏️ Your turn

For ②: put y = 2 in, so 2 = 12/x, then multiply both sides by x.

y = 12/x. ① Find y when x = 3. ② Find x when y = 2.
Show answer
Answer: ① y = 12/3 = 4. ② 2 = 12/x → 2x = 12 → x = 6.

7 函数的图像与变换Transformations of graphs Transformation变换

学完你会：看到改动后的函数，说出它的图是「往哪搬」或「怎么翻」的。

说人话：你已经知道 y = f(x) 长什么样了。现在只要在式子的外面、里面加加减减， 整个图像就会搬家或翻转——不用重新描点画图，省大事。
记住这四条就够用：
  • y = f(x) + a：整体上移 a（写成 −a 就是下移）。
  • y = f(x + a)：整体左移 a（这里最容易错！+ 是往左）。
  • y = −f(x)：以 x 轴为镜子，上下翻。
  • y = f(−x)：以 y 轴为镜子，左右翻。
易错提醒：括号里面是「反」的——(x − 3) 是往右移 3，(x + 1) 是往左移 1。 很多同学在这里丢分，记牢这一条。

例题

已知 y = x² 的顶点在 (0, 0)。那 y = (x − 3)² + 2 的图像是怎么移动的？新顶点在哪？
解： x 变成 (x − 3) → 括号里是「−3」，所以向右移 3。 整个式子 + 2 → 向上移 2。 所以顶点从 (0, 0) 搬到 (3, 2)。

✏️ 你来试一题

提示：(x + 1) 是往哪边移？后面的 − 4 又是往哪边？

y = x² 变成 y = (x + 1)² − 4，图像怎么移动？新顶点在哪？
点开看答案
答案： (x + 1) → 向左移 1。 − 4 → 向下移 4。 顶点从 (0, 0) 搬到 (−1, −4)。

By the end you'll be able to: look at a changed function and say how the graph moved or flipped.

In plain words: you already know what y = f(x) looks like. Add or subtract (outside or inside) and the whole graph moves or flips — no need to plot points all over again.
These four are enough:
  • y = f(x) + a: moves up by a (−a means down).
  • y = f(x + a): moves LEFT by a (this is the classic trap!).
  • y = −f(x): reflected in the x-axis (flipped vertically).
  • y = f(−x): reflected in the y-axis (flipped horizontally).
Common trap: inside the bracket is "backwards" — (x − 3) moves RIGHT 3, while (x + 1) moves LEFT 1. Many students lose marks here.

Example

y = x² has vertex (0, 0). How does y = (x − 3)² + 2 move? Where is the new vertex?
Solution: x becomes (x − 3) → move right 3. The + 2 outside → move up 2. So the vertex moves from (0, 0) to (3, 2).

✏️ Your turn

Hint: which way does (x + 1) move? And which way does the − 4 move it?

y = x² becomes y = (x + 1)² − 4. How does it move? Where is the new vertex?
Show answer
Answer: (x + 1) → move left 1. − 4 → move down 4. Vertex moves from (0, 0) to (−1, −4).

1 二次方程的三种解法Solving quadratic equations Solving quadratics解二次方程

学完你会：用三种方法解 ax² + bx + c = 0。

说人话：解二次方程就是「找 x 等于几时，整个式子等于 0」——也就是上图抛物线与 x 轴交点的 x 坐标。 三种办法：能分解就分解（最快）；分解不了就用求根公式（万能，直接套）。
记住这几点：
  • 因式分解法：化成 (x − p)(x − q) = 0 → x = p 或 x = q。
  • 配方法：写成 (x − h)² = k，再开方。
  • 求根公式（最万能）：x = [−b ± √(b² − 4ac)] / (2a)
  • 用公式前，先把方程整理成 ax² + bx + c = 0 的标准样子（右边必须是 0）。

例题

用求根公式解 2x² − 5x − 3 = 0。
解： 先认出 a = 2，b = −5，c = −3。 算判别式：Δ = (−5)² − 4×2×(−3) = 25 + 24 = 49，√49 = 7。 代入公式：x = [−(−5) ± 7] / (2×2) = (5 ± 7) / 4。 所以 x = 12/4 = 3，或 x = −2/4 = −0.5。 检验：2×9 − 15 − 3 = 0 ✓；2×0.25 + 2.5 − 3 = 0 ✓。

✏️ 你来试一题

提示：a = 3，b = 2，c = −8，先算 Δ = b² − 4ac。

用求根公式解 3x² + 2x − 8 = 0。
点开看答案

By the end you'll be able to: use geometric sequences for compound interest and depreciation.

In plain words: the most down-to-earth use of a geometric sequence is money. Compound interest: you leave the interest in, so next year it earns interest too — the balance is multiplied by (1 + rate) every year. Depreciation: a machine loses a fixed fraction of its value each year — multiply by (1 − rate). Both are geometric sequences; one goes up, one goes down.
Remember these:
  • Compound interest: after n years the balance is P(1 + r)ⁿ (P = starting amount, ratio = 1 + r).
  • Depreciation: after n years the value is P(1 − d)ⁿ (d = yearly rate, ratio = 1 − d).
  • 5% means 0.05, not 5 — and you multiply by 1.05, not 0.05.
  • The power is the number of years n: after 1 year, one multiplication; after 5 years, five.

1 直线方程 y = mx + c 与斜率The line y = mx + c and its gradient Gradient斜率

学完你会：看到两个点就能写出直线方程。

说人话：一条直线有多斜，用斜率 m（gradient）表示。算法很简单： 往右走了多少（前进量），对应地升高了多少（上升量），两者一除就是 m。
c 是直线和 y 轴相交的那个高度，叫截距（intercept）。知道 m 和 c，这条线就完全定下来了：y = mx + c。
记住这几点：
  • 斜率：m = (y₂ − y₁)/(x₂ − x₁)　——顺序要一致，都用「后点减前点」
  • 直线方程：y = mx + c；也可以写成 y − y₁ = m(x − x₁)（已知一点时用这个最快）
  • m > 0 往右上走，m < 0 往右下走，m = 0 是水平线。
  • 写完后一定要代回原点检查：把已知点代进去，等式成立就对了。

例题

In plain words: how steep a line is, is called its gradient, m. The rule is simple: divide the rise (up) by the run (across).
c is how high the line crosses the y-axis — the intercept. Once you know m and c, the line is fixed: y = mx + c.
Remember these:
  • Gradient: m = (y₂ − y₁)/(x₂ − x₁)　— keep the order the same in top and bottom
  • Line equation: y = mx + c, or y − y₁ = m(x − x₁) when you know one point

  • Always check by substituting the point back in.

2 两点之间的距离Distance between two points Distance距离

学完你会：给两个点，算出它们之间有多远。

说人话：两点之间画一条斜线，这条斜线可以当直角三角形的斜边。 两条直角边分别就是「x 差了多少」和「y 差了多少」。用勾股定理一算，距离就出来了。
记住这几点：
  • 距离公式：d = √[(x₂ − x₁)² + (y₂ − y₁)²]
  • 差是负的没关系，平方之后就变正了，所以不用管谁减谁。
  • 答案经常能开方开尽（3-4-5、6-8-10 这类），开不尽就保留根号。
  • 如果题目要求长度，答案只取正的。

4 平行与垂直：m₁m₂ = −1Parallel and perpendicular: m₁m₂ = −1 Parallel / perpendicular平行 / 垂直

学完你会：判断两条直线是不是平行、是不是垂直，并写出满足条件的直线。

说人话：平行就是两条线一样斜 → 斜率相等。 垂直就妙了：两条垂直的直线，斜率乘起来刚好等于 −1。 所以已知一条线的斜率 m，跟它垂直的那条就是 −1/m（取倒数再变号，叫负倒数）。
记住这几点：
  • 平行：m₁ = m₂　（两条线的 c 不同，否则是同一条线）
  • 垂直：m₁ × m₂ = −1　也就是 m₂ = −1/m₁
  • 常见搭配：2 和 −½；3 和 −⅓；−3 和 ⅓；−⅔ 和 3/2。
  • 写直线：先定 m，再用 y − y₁ = m(x − x₁) 代入已知点。
易错提醒：竖直线（像 x = 3）是没有斜率的，水平线 m = 0。 这时候不能套 m₁m₂ = −1（0 不能做分母），但竖直线和水平线依然是垂直的——遇到这种题直接写答案就行。

例题

直线 L：y = 2x + 3。求过点 (4, 5) 且 (a) 与 L 平行、(b) 与 L 垂直的直线方程。
解： L 的斜率是 2。 (a) 平行 → m = 2：y − 5 = 2(x − 4)　→　y = 2x − 8 + 5 = 2x − 3。 (b) 垂直 → m = −½：y − 5 = −½(x − 4)　→　y = −½x + 2 + 5 = −½x + 7。 　　也可以写成 x + 2y = 14（两边乘 2 再移项）。

By the end you'll be able to: tell whether two lines are parallel or perpendicular, and write lines that satisfy either condition.

In plain words: parallel means equally steep, so equal gradients. Perpendicular is the neat one: the two gradients multiply to give −1. So if one line has gradient m, the perpendicular one has −1/m (flip it over and change the sign).
Remember these:
  • Parallel: m₁ = m₂　(with different c, otherwise it's the same line)
  • Perpendicular: m₁ × m₂ = −1, i.e. m₂ = −1/m₁
  • Common pairs: 2 and −½; 3 and −⅓; −3 and ⅓; −⅔ and 3/2.
  • To write the line: fix m, then use y − y₁ = m(x − x₁).

5 圆的方程 (x − a)² + (y − b)² = r²Equation of a circle Circle圆

学完你会：由圆心和半径写圆的方程；也能从方程里读出圆心和半径。

说人话：圆的定义是「到圆心距离都相等的一圈点」。 把第 2 站的距离公式平方一下，就得到圆的方程：(x − a)² + (y − b)² = r²， 其中 (a, b) 是圆心，r 是半径。注意右边是 r²，这是最容易忘的地方。
记住这几点：

6 圆的切线Tangents to a circle Tangent切线

学完你会：求圆上某一点的切线方程。

说人话：切线就是刚好擦着圆过、只碰一下的直线。 它有一个铁律：切线 ⟂ 过切点的半径。 所以做法永远是三步——① 连圆心到切点，算这条半径的斜率；② 取负倒数，得到切线斜率；③ 代入切点写方程。
记住这几点：
  • 铁律：切线 ⟂ 半径 → 用第 4 站的 m₁m₂ = −1。
  • 先确认这个点真的在圆上（代入圆的方程看等不等于 r²）。
  • 半径的斜率 = (y₁ − a)/(x₁ − b)，其中 (a, b) 是圆心、(x₁, y₁) 是切点。
  • 最后用 y − y₁ = m(x − x₁) 写切线。

例题

求圆 x² + y² = 25 在点 (3, 4) 处的切线方程。
解： ① 圆心是 (0, 0)。半径从 (0, 0) 到 (3, 4)，斜率 = 4/3。 ② 切线斜率 = 负倒数 = −3/4。 ③ 过 (3, 4)：y − 4 = −(3/4)(x − 3)。 　　两边乘 4：4y − 16 = −3x + 9　→　3x + 4y = 25。 顺带一提：右边正好是 25 = r²，这不是巧合（x₁x + y₁y = r² 是通用快捷式）。

7 直线与圆：相交、相切还是相离Line and circle: intersect, touch or miss Discriminant判别式

学完你会：不画图，判断一条直线和圆有几个交点；还能反过来求相切时的参数。

说人话：直线和圆放在一起，要么穿过（2 个交点），要么擦一下（1 个），要么压根没碰上（0 个）。 怎么判断？把直线方程代进圆的方程，会得到一个二次方程，然后看判别式 Δ = b² − 4ac： Δ > 0 两个解（相交），Δ = 0 一个解（相切），Δ < 0 无解（相离）。
记住这几点：
  • 步骤：把 y = mx + c 代进圆的方程 → 整理成 ax² + bx + c = 0 → 算 Δ。
  • Δ > 0 → 相交（2 点）；Δ = 0 → 相切（1 点）；Δ < 0 → 相离（0 点）。
  • 求交点：解方程，把 x 代回直线求 y。
  • 反过来用：题目说「相切」，就是告诉你 Δ = 0，据此解未知参数。

例题

判断直线 y = x + 1 与圆 x² + y² = 25 的位置关系；若相交，求出交点。
解： ① 代入：x² + (x + 1)² = 25。 ② 展开：x² + x² + 2x + 1 = 25　→　2x² + 2x − 24 = 0　→　x² + x − 12 = 0（两边除以 2）。 ③ 算 Δ = 1² − 4×1×(−12) = 1 + 48 = 49 > 0 → 相交，2 个交点。 ④ 因式分解：(x + 4)(x − 3) = 0　→　x = −4 或 x = 3。 ⑤ 代回 y = x + 1：交点 (−4, −3) 和 (3, 4)。

✏️ 你来试一题

By the end you'll be able to: decide how many times a line meets a circle without drawing it, and find an unknown when the line is a tangent.

In plain words: a line and a circle either cut through (2 points), just touch (1 point), or miss entirely (0 points). To tell which: substitute the line into the circle, get a quadratic, then look at the discriminant Δ = b² − 4ac: Δ > 0 means two points, Δ = 0 means a tangent, Δ < 0 means no meeting.
Remember these:
  • Steps: put y = mx + c into the circle → rearrange to ax² + bx + c = 0 → find Δ.
  • Δ > 0 → 2 points; Δ = 0 → tangent; Δ < 0 → no intersection.
  • To get the points: solve for x, then use the line to get y.
  • The other way round: "tangent" in a question means Δ = 0 — use it to find the unknown.

Example

记住这几点：
  • 弧长：l = rθ　　扇形面积：A = ½r²θ　　（θ 用弧度）

3 sin、cos、tan 的图像Graphs of sin, cos and tan Trig graphs三角图像

学完你会：说出 sin、cos、tan 的关键点、周期和取值范围。

说人话：sin 从 0 起步，爬到 1，回到 0，跌到 −1，再回到 0——像上下起伏的波浪。 cos 长相一模一样，只是起点在最高处 1（相当于 sin 往左挪了 π/2）。 tan 不一样：它会冲到无穷高，然后在某处断开，从下方重新来一遍。
记住这几点：
  • sin 关键点：sin 0 = 0，sin(π/2) = 1，sin π = 0，sin(3π/2) = −1，sin 2π = 0。

  • 周期：sin 和 cos 都是 2π；tan 是 π。
  • 范围：−1 ≤ sin ≤ 1，−1 ≤ cos ≤ 1；tan 可以是任何数。
  • 变形规律：y = A sin(Bx) → 最大值是 A，周期是 2π/B。

In plain words: sin starts at 0, climbs to 1, drops back through 0 down to −1, then returns — a smooth wave. cos has exactly the same shape but starts at the top, at 1 (sin shifted left by π/2). tan is different: it shoots up to infinity, breaks, and restarts from below.

5 三角恒等式 sin²θ + cos²θ = 1The identity sin²θ + cos²θ = 1 Identity恒等式

学完你会：已知 sin 求 cos（或反过来），并求出 tan。

说人话：在半径为 1 的圆（单位圆）上，那个点的横坐标就是 cos θ，纵坐标就是 sin θ。 它到圆心的距离恒等于 1，用勾股定理写出来就是 sin²θ + cos²θ = 1。 这条式子对任何角度都成立，所以叫恒等式（identity）——不是方程，不用解。
记住这几点：
  • 核心恒等式：sin²θ + cos²θ = 1　（对任意 θ 都成立）
  • 变形：sin²θ = 1 − cos²θ；cos²θ = 1 − sin²θ。
  • tan 的定义：tan θ = sin θ / cos θ，所以求出 sin 和 cos 就能得 tan。
  • 开方要定正负：题目说 θ 是锐角（0 < θ < 90°）就取正；说钝角时 cos 取负。

例题

已知 sin θ = 3/5，且 θ 是锐角。求 cos θ 和 tan θ。
解： 用恒等式：cos²θ = 1 − sin²θ = 1 − (3/5)² = 1 − 9/25 = 16/25。 开方：cos θ = 4/5（θ 是锐角，cos 为正，取正号）。 tan θ = sin θ / cos θ = (3/5) ÷ (4/5) = 3/4。 核对：这就是经典的 3-4-5 三角形。

✏️ 你来试一题

提示：sin²θ = 1 − (5/13)² = 1 − 25/169。分母是 169，想想哪个数的平方是 144？

已知 cos θ = 5/13，且 θ 是锐角。求 sin θ 和 tan θ。
点开看答案
答案： sin²θ = 1 − 25/169 = 144/169 → sin θ = 12/13。 tan θ = (12/13) ÷ (5/13) = 12/5。 （这是 5-12-13 三角形。）

By the end you'll be able to: find cos from sin (or the other way round), and then find tan.

In plain words: on a circle of radius 1 (the unit circle), the point's x-coordinate is cos θ and its y-coordinate is sin θ. Its distance from the centre is always 1, so Pythagoras gives sin²θ + cos²θ = 1. This is true for every angle — that's why it's called an identity, not an equation to solve.
Remember these:
  • Core identity: sin²θ + cos²θ = 1　(true for every θ)
  • Rearranged: sin²θ = 1 − cos²θ; cos²θ = 1 − sin²θ.
  • Definition: tan θ = sin θ / cos θ.
  • Watch the sign: acute θ (0 < θ < 90°) means take the positive root; obtuse means cos is negative.

Example

Solution: cos²θ = 1 − sin²θ = 1 − (3/5)² = 1 − 9/25 = 16/25. cos θ = 4/5 (θ is acute, so cos is positive). tan θ = sin θ / cos θ = (3/5) ÷ (4/5) = 3/4. Check: the classic 3-4-5 triangle.

6 解三角方程Solving trigonometric equations Trig equation三角方程

学完你会：在给定范围内解出 sin x = k、cos x = k 这类方程。

说人话：三角方程和普通方程最大的区别是——它通常不止一个答案。 第 3 站的图已经告诉你原因：波浪会重复，一条水平线可能穿过它好几次。 做法：① 先用计算器（或特殊角）求出第一个解（叫参考角）； ② 再按规律找出范围里的其他解；③ 最后逐个检查是否落在题目给的范围里。
记住这几点：
  • sin x = k：第二个解 = π − 第一个解（两个解关于 π/2 对称）。
  • cos x = k：第二个解 = 2π − 第一个解（关于 x 轴对称）。
  • tan x = k：加 π 就得到下一个解（周期是 π）。
  • 要更多解？在结果上加减 2π（sin/cos）或 加减 π（tan）。
  • 必看范围：题目写 0 ≤ x ≤ 2π 就只留这个区间里的解。

例题

解方程 sin x = ½，其中 0 ≤ x ≤ 2π。
解： ① 第一个解：由特殊角表，sin(π/6) = ½ → x = π/6。 ② 第二个解：π − π/6 = 5π/6。 ③ 检查范围：两者都在 0 到 2π 之间 ✓；再加 2π 就超范围了，不再有解。 答案：x = π/6 或 5π/6。

✏️ 你来试一题

In plain words: the big difference from ordinary equations is that there is usually more than one answer. Method: ① find the first solution (the reference angle); ② use the pattern to get the others; ③ keep only those in the given range.
Remember these:
  • sin x = k: second solution = π − first (they mirror around π/2).
  • cos x = k: second solution = 2π − first (mirror in the x-axis).
  • tan x = k: add π for the next one.
  • Need more? Add or subtract 2π (sin/cos) or π (tan).
  • Always check the range given in the question.

7 正弦定理与余弦定理The sine rule and the cosine rule Sine / cosine rule正弦/余弦定理

学完你会：判断该用哪条定理，并求出三角形里未知的边或角。

说人话：直角三角形用勾股定理就够，普通三角形要靠这两条。怎么选？看已知条件： 知道两角一边（或一个角和它对面那条边）→ 用正弦定理； 知道两边和它们的夹角（或三条边）→ 用余弦定理。 还有一条：面积 = ½ab·sin C（两边乘夹角正弦再除以 2）。
记住这几点：
  • 边的命名：边 a 对着角 A，边 b 对着角 B，边 c 对着角 C（一定先看清楚）。
  • 正弦定理：a/sin A = b/sin B = c/sin C　（用到「一对边角」＋另一个量）
  • 余弦定理：a² = b² + c² − 2bc·cos A　（注意是 减号；A = 90° 时它就变成勾股定理）
  • 面积：Area = ½ab·sin C　（两边及其夹角）
  • 余弦定理求角时用变形：cos A = (b² + c² − a²)/(2bc)。

例题

三角形中 b = 8，c = 5，角 A = 60°。求边 a。
解： 已知两边及其夹角 → 用余弦定理。 a² = b² + c² − 2bc·cos A = 8² + 5² − 2×8×5×cos 60°。 = 64 + 25 − 80 × ½ = 89 − 40 = 49。 a = √49 = 7。

✏️ 你来试一题

提示：已知两角一边 → 正弦定理。b/sin B = a/sin A，所以 b = a × sin B / sin A。

点开看答案
答案： 正弦定理：b/sin 45° = 6/sin 30°。 b = 6 × sin 45° / sin 30° = 6 × (√2/2) ÷ (1/2)。 = 6 × √2 = 6√2（约 8.49）。

By the end you'll be able to: choose the right rule and find an unknown side or angle in any triangle.

In plain words: right-angled triangles only need Pythagoras, but a general triangle needs these two rules. How to choose? Two angles and a side (or an angle and its opposite side) → sine rule; two sides and the angle between them (or all three sides) → cosine rule. And the area: ½ab·sin C (two sides and the angle between them).
Remember these:
  • Naming: side a faces angle A, b faces B, c faces C — check this first.
  • Sine rule: a/sin A = b/sin B = c/sin C
  • Cosine rule: a² = b² + c² − 2bc·cos A　(note the minus; at A = 90° it becomes Pythagoras)
  • Area: Area = ½ab·sin C
  • To find an angle: cos A = (b² + c² − a²)/(2bc).

Example

In a triangle, b = 8, c = 5 and angle A = 60°. Find side a.
Solution: Two sides and the angle between → cosine rule. a² = b² + c² − 2bc·cos A = 8² + 5² − 2×8×5×cos 60°. = 64 + 25 − 80 × ½ = 89 − 40 = 49. a = √49 = 7.

✏️ Your turn

Show answer

1 指数运算的三条律Three laws of indices Indices指数

学完你会：把带指数的式子化简成一个幂。

说人话：aⁿ 的意思是「n 个 a 相乘」。所以 同底数相乘时，个数直接相加—— 就像 3 个 2 再叠 2 个 2，一共 5 个 2。相除就是抵消掉几个，指数相减。
记住这几点：
  • 乘 → 加：aᵐ × aⁿ = aᵐ⁺ⁿ
  • 除 → 减：aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • 幂的幂 → 乘：(aᵐ)ⁿ = aᵐⁿ
  • a⁰ = 1（a ≠ 0）；a⁻ⁿ = 1/aⁿ——负号不是"变负数"，是"翻到分母去"
  • 分数指数：a^(1/2) = √a，a^(m/n) = (ⁿ√a)ᵐ
  • 这三条律只在底数相同时成立：2³ × 3² 不能合并。

例题

化简：(x⁴ · x⁻²)² ÷ x³
解： 先算括号里：x⁴ · x⁻² = x^(4−2) = x²。 再算平方：(x²)² = x⁴。 最后除以 x³：x⁴ ÷ x³ = x^(4−3) = x。

✏️ 你来试一题

By the end you'll be able to: simplify index expressions into a single power.

In plain words: aⁿ means "n copies of a multiplied together". So when you multiply, the counts add — 3 twos times 2 twos is 5 twos. Dividing cancels some out, so the powers subtract.
Remember these:
  • multiply → add: aᵐ × aⁿ = aᵐ⁺ⁿ
  • divide → subtract: aᵐ ÷ aⁿ = aᵐ⁻ⁿ
  • power of a power → multiply: (aᵐ)ⁿ = aᵐⁿ
  • a⁰ = 1 (a ≠ 0); a⁻ⁿ = 1/aⁿ — a minus means "flip to the bottom", not "make it negative"
  • fractional powers: a^(1/2) = √a
  • These laws only work when the base is the same: 2³ × 3² cannot combine.

Solution: Bracket first: x⁴ · x⁻² = x^(4−2) = x². Then square it: (x²)² = x⁴. Divide by x³: x⁴ ÷ x³ = x^(4−3) = x.

2 指数函数 y = aˣ 的图像The graph of y = aˣ Exponential指数函数

学完你会：一眼看出 y = aˣ 的形状，知道它过哪、往哪走。

说人话：指数函数就是"翻倍的学问"。x 每增加 1，y 就乘一个 a（不是加一个 a）。 前面慢悠悠，后面越涨越吓人——这就是"爆炸式增长"。
记住这几点：
  • 图像一定过 (0, 1)，因为 a⁰ = 1。这是最稳的定位点。
  • a > 1（如 y = 2ˣ）：从左往右上升，叫增长。
  • 0 < a < 1（如 y = (½)ˣ）：从左往右下降，叫衰减。
  • x 轴（y = 0）是渐近线：图像无限靠近但永不相交，y 恒为正。
  • 定义域：全体实数；值域：y > 0。

例题

对 y = 3ˣ：(a) 求 x = 0、1、2 时的 y；(b) 说明为什么图像永远不会到 x 轴下方。
解： (a) 3⁰ = 1，3¹ = 3，3² = 9。三点：(0,1)、(1,3)、(2,9)。 (b) 正数的任何次方还是正数，3ˣ > 0 恒成立，所以图像永远在 x 轴上方。 x 取很大的负数时（如 3⁻¹⁰），y 会非常接近 0，但不会等于 0。

✏️ 你来试一题

提示：(½)² 就是 ½ × ½，越乘越小。

对 y = (½)ˣ：(a) 求 x = 0、2、−1 时的 y；(b) 它是增长还是衰减？
点开看答案
答案： (a) x=0 → 1；x=2 → (½)² = 1/4；x=−1 → (½)⁻¹ = 2。 (b) 底数 ½ 在 0 和 1 之间，所以是衰减（越往右越低）。

By the end you'll be able to: recognise the shape of y = aˣ and where it goes.

In plain words: an exponential is the maths of doubling. Every time x goes up by 1, y is multiplied by a (not added to). It starts slowly, then takes off — that is "explosive growth".
Remember these:
  • The graph always passes through (0, 1) since a⁰ = 1. That is your anchor point.
  • a > 1 (e.g. y = 2ˣ): increasing — growth.
  • 0 < a < 1 (e.g. y = (½)ˣ): decreasing — decay.
  • The x-axis is an asymptote: the curve gets closer forever but never touches it, so y > 0 always.
  • Domain: all real x. Range: y > 0.

Example

For y = 3ˣ: (a) find y when x = 0, 1, 2; (b) explain why the graph never goes below the x-axis.
Solution: (a) 3⁰ = 1, 3¹ = 3, 3² = 9. Points: (0,1), (1,3), (2,9). (b) A positive number to any power stays positive, so 3ˣ > 0 always. For very negative x (like 3⁻¹⁰) y gets close to 0, but never equals 0.

✏️ Your turn

  • e ≈ 2.718（记住前三位就够）。

4 对数：指数的反问句Logarithms: the inverse of indices Logarithm对数

学完你会：把 logₐ x = y 和 aʸ = x 来回翻译。

说人话：指数是"我知道指数，求结果"；对数是反着问——"我知道结果，指数是几？"。 写出来：logₐ x = y 就等价于 aʸ = x。底数 a 从头到尾不变，变的只是谁站在等号另一边。
记住这几点：
  • 翻译公式：logₐ x = y ⟺ aʸ = x。（底数是 a，对数的答案 y 就是指数）
  • logₐ 1 = 0（a⁰ = 1）；logₐ a = 1（a¹ = a）。
  • x 必须 > 0：负数和 0 没有对数（因为 aʸ 永远是正的）。
  • 底数写法：log 默认底数 10，ln 底数 e。
  • 看不懂的时候，就在心里把它翻回指数式，十有八九就明白了。

Remember these:
  • Key translation: logₐ x = y ⟺ aʸ = x.

5 对数运算律Laws of logarithms Log laws对数律

学完你会：把一个复杂的 log 拆开或合并。

说人话：对数律和指数律是同一件事的两面。指数里"相乘就加指数"， 所以对数里"相乘就加对数"。最实用的是第三条：指数可以提到前面当系数——这正是解指数方程的钥匙。
记住这几点：
  • 乘法变加法：log(xy) = log x + log y
  • 除法变减法：log(x/y) = log x − log y
  • 指数提前面：log(xⁿ) = n·log x　← 最有用
  • 换底公式：logₐ b = log b / log a（计算器只有 log 和 ln 时用）
  • 大坑警告：log(x + y) 不能拆成 log x + log y。加法没有公式！

1 导数是什么：切线的斜率What a derivative is: the gradient Derivative导数

学完你会：说出导数是什么、怎么写、代表什么。

说人话：直线有固定的斜率，但曲线每一点的陡峭程度都不一样。 导数就是"曲线在某一点那一刻的斜率"。做法很朴素：在曲线上取两个点连一条割线， 让两点越靠越近，割线就变成切线，它的斜率就是导数。
记住这几点：
  • 写法：y = f(x) 的导数写作 f′(x) 或 dy/dx（读作 "dee y by dee x"）。
  • 几何意义：曲线在该点切线的斜率。
  • 物理意义：变化率。位移求导是速度，速度求导是加速度。
  • 正负看方向：导数 > 0 → 曲线上升；导数 < 0 → 下降；导数 = 0 → 那一刻是平的。
  • 求导这个动作叫 differentiate（求导），结果叫 derivative（导数）。

例题

用"越靠越近"的想法，求 f(x) = x² 在 x = 3 处的导数。
解： 取 x = 3 和附近一点 x = 3 + h，算割线斜率。 斜率 = [f(3+h) − f(3)] / h = [(3+h)² − 9] / h。 展开：(9 + 6h + h² − 9)/h = (6h + h²)/h = 6 + h。 让 h → 0（两点重合）：6 + 0 = 6。所以 f′(3) = 6。 口诀：先算差商，再让 h 消失。

Remember these:
  • Notation: for y = f(x) we write f′(x) or dy/dx ("dee y by dee x").
  • Geometric meaning: the gradient of the tangent at that point.
  • Physical meaning: rate of change. Differentiating distance gives velocity.
  • Sign tells direction: derivative > 0 → rising; < 0 → falling; = 0 → flat at that instant.
  • The action is differentiate; the result is the derivative.

  • 公式：若 y = f(g(x))，则 dy/dx = f′(g(x)) × g′(x)。
  • 口诀：外层导数（里面照抄）× 内层导数。
  • 常见外形：(ax + b)ⁿ、√(ax² + b)、e^(kx)、sin(2x) 都要用链式。

  • 内层是 x 本身时（如 x⁵），内层导数 = 1，所以看不出差别。

5 乘积法则与商法则The product and quotient rules Product / quotient乘积 / 商

学完你会：对两个函数相乘、相除的形式求导。

说人话：乘积法则：两块相乘，导数 = 前一块的导数 × 后一块 + 前一块 × 后一块的导数（各导一次，加起来）。 商法则：分子分母相除，导数 = （上导×下 − 上×下导）/ 下面的平方，注意是减号。
记住这几点：
  • 乘积：y = uv → dy/dx = u′v + uv′（口诀：前导后 + 前后导）。
  • 商：y = u/v → dy/dx = (u′v − uv′)/v²（口诀：上导下 − 上下导，除下²）。
  • 两个法则可以链起来用：块里还套着函数时，里面再用链式。
  • 商法则是减号，而且分母是 v² 不是 v。这是最常写错的两处。
  • 能先展开化简的（如 x²(3x+1)）可以先展开再求导，用来验算。

例题

用乘积法则求 y = x²(3x + 1) 的 dy/dx，再用展开法验算。
解： 设 u = x²，v = 3x + 1，则 u′ = 2x，v′ = 3。 代入公式：dy/dx = u′v + uv′ = 2x(3x + 1) + x²·3。 展开：6x² + 2x + 3x² = 9x² + 2x。 验算：展开原式 y = 3x³ + x²，求导 = 9x² + 2x ✓ 完全一致。

提示：u = x + 1、v = x − 1，两个导数都是 1；分母记得平方。

点开看答案

In plain words: Product rule: for two things multiplied, differentiate each one in turn and add the results. Quotient rule: for a fraction, it is (top-derivative × bottom − top × bottom-derivative) over the bottom squared — note the minus.
Remember these:
  • Product: y = uv → dy/dx = u′v + uv′.
  • Quotient: y = u/v → dy/dx = (u′v − uv′)/v².
  • Both can combine with the chain rule when a piece is itself composite.
  • The quotient rule has a minus, and the denominator is v², not v. These are the two classic slips.
  • If you can expand first (like x²(3x+1)), do it as a check.

Example

Solution: Let u = x², v = 3x + 1, so u′ = 2x, v′ = 3. Formula: dy/dx = u′v + uv′ = 2x(3x + 1) + x²·3. Expand: 6x² + 2x + 3x² = 9x² + 2x. Check: expand first — y = 3x³ + x², derivative = 9x² + 2x ✓ matches.

6 二阶导数与驻点Second derivative and stationary points Stationary point驻点

学完你会：找驻点，并判断它是极大还是极小。

说人话：曲线"走平"的那些点（山顶、谷底）导数都等于 0，叫驻点。 要分清是山顶还是谷底，就再求一次导：二阶导数为正 = 碗口朝上 = 谷底（极小）；为负 = 碗口朝下 = 山顶（极大）。
记住这几点（三步法）：
  • ① 求 dy/dx，令它 = 0，解出 x（可能有多个）。
  • ② 把 x 代回原式求 y，得到驻点坐标。
  • ③ 求二阶导数 d²y/dx²，代 x 进去：> 0 → 极小（minimum）；< 0 → 极大（maximum）。
  • 二阶导数 = 0 时无法判断，可能是拐点，需要用两侧导数符号来判断。
  • 二阶导数写法：d²y/dx² 或 f″(x)。就是把导数再求一次导。

例题

求 y = x³ − 3x² 的驻点，并判断极大还是极小。
解： ① dy/dx = 3x² − 6x = 3x(x − 2)。令其 = 0 → x = 0 或 x = 2。 ② 代回：y(0) = 0 → 点 (0, 0)；y(2) = 8 − 12 = −4 → 点 (2, −4)。 ③ 二阶导数 d²y/dx² = 6x − 6。 x = 0：6(0) − 6 = −6 < 0 → 极大点 (0, 0)。 x = 2：6(2) − 6 = 6 > 0 → 极小点 (2, −4)。

Remember these (three steps):

  • ② Substitute back into y to get the coordinates.
  • ③ Find d²y/dx² and substitute: > 0 → minimum; < 0 → maximum.
  • If the second derivative is 0, the test fails — check the sign of dy/dx on either side.
  • Notation: d²y/dx² or f″(x) — just differentiate the derivative.

1 不定积分与那个 + cIndefinite integration and the + c Integration积分

学完你会：理解积分是求导的逆运算，知道为什么答案后面要写 + c。

说人话：求导是「知道函数求导数」，积分是知道导数反推原函数——倒着走。 但求导时常数会变成 0 消失掉，所以往回走时那个常数丢了， 只能笼统写一个 + c（任意常数）。这就是"不定积分"。
记住这几点：
  • 符号：∫ f(x) dx 读作「对 x 积分」，∫ 是拉长的 S（求和 sum）。
  • 不定积分的结果是一个函数族（一整条上下平移的曲线），所以必须写 + c。
  • 自检方法：把答案求导一次，应该回到原来的式子——这是最可靠的验算。
  • 漏写 + c 要扣分：不定积分不写 + c，考试里通常要丢一分。
  • 如果题目给了额外条件（如「过点 (1, 2)」），就可以把 c 具体求出来。

例题

求 ∫(3x² + 2) dx，并验算。
解： 逐项积分：∫3x² dx = 3 · x³/3 = x³；∫2 dx = 2x。 所以 ∫(3x² + 2) dx = x³ + 2x + c。 验算：把 x³ + 2x + c 求导 → 3x² + 2 + 0 = 3x² + 2 ✓ 回到原式。

In plain words: differentiation goes "from function to derivative"; integration goes backwards, from derivative to function. But constants vanish when you differentiate, so on the way back that information is lost — we just write + c (an unknown constant). That is an indefinite integral.
Remember these:
  • Symbol: ∫ f(x) dx — ∫ is an elongated S, for "sum".
  • An indefinite integral is a whole family of curves, hence + c.
  • Best check: differentiate your answer — you should get back the original expression.
  • Forgetting + c costs a mark in the exam.
  • If the question gives extra information (e.g. "passes through (1, 2)"), you can find the actual value of c.

2 幂函数积分：xⁿ → xⁿ⁺¹/(n+1)Integrating xⁿ Power rule幂法则

学完你会：对多项式、分式、根式的幂形式积分。

说人话：求导是「指数搬到前面、指数减 1」，积分就反过来： 指数先加 1，再除以这个新指数。比如 x³：加 1 变 x⁴，再除以 4 → x⁴/4。
记住这几点：
  • 核心公式：∫ xⁿ dx = xⁿ⁺¹/(n+1) + c（n ≠ −1）。
  • 带系数：∫ a xⁿ dx = a · xⁿ⁺¹/(n+1) + c。
  • 逐项积分：加减拆开，各自积分后拼起来，最后统一写一个 + c。
  • 先化后积：1/x² 写成 x⁻²，√x 写成 x^(½)。化成幂的形式才能套公式。
  • 特例：∫ 1/x dx = ln|x| + c（n = −1 时幂法则失效，记住即可）。

例题

3 定积分：带上下限的积分Definite integration Definite integral定积分

学完你会：算带上下限的定积分。

说人话：不定积分给你「一整族函数」，定积分给你一个确定的数。 做法：先照常积分（这次不写 + c），写成 [ ] 带上下限， 然后代上限的值减代下限的值——就这一个动作。
记住这几点（三步法）：
  • ① 先求不定积分（不写 + c），外面套方括号 [ ]，右下写下限、右上写上限。
  • ② 把上限代入方括号里的式子，得到一个数。
  • ③ 减去「把下限代入」得到的数。答案 = 上 − 下。
  • 结果是一个数值（可正可负），不再是函数。
  • 顺序别搞反：一定是上限减下限，反过来会差一个负号。

例题

计算 ∫₁³ (2x + 1) dx。
解： ① 先积分：∫(2x + 1) dx = x² + x，写成 [x² + x]₁³。 ② 代上限 3：3² + 3 = 9 + 3 = 12。 ③ 代下限 1：1² + 1 = 2。 ④ 相减：12 − 2 = 10。

✏️ 你来试一题

提示：∫(3x² − 2) dx = x³ − 2x；代 x = 2 得 8 − 4 = 4，代 x = 0 得 0。

By the end you'll be able to: evaluate a definite integral with limits.

In plain words: an indefinite integral hands you a family of functions; a definite integral hands you one number. How: integrate as usual (no + c this time), put the result in square brackets with the limits, then subtract the value at the bottom limit from the value at the top limit.
Remember these (three steps):
  • ① Integrate (no + c) and write it in [ ] with the limits attached.
  • ② Substitute the upper limit to get one number.
  • ③ Subtract the value obtained from the lower limit. Answer = top − bottom.
  • The result is a number (it can be negative), not a function.
  • Do not reverse the order: it is always top minus bottom.

Example

4 曲线下的面积Area under a curve Area面积

学完你会：用定积分求曲线与 x 轴之间的面积。

说人话：积分这个符号 ∫ 本来就是拉长的字母 S，代表 sum（求和）。 把曲线底下的区域切成一片片极窄的竖条，每条面积 ≈ 高 × 宽 = y × dx， 全部加起来就是 ∫ y dx。这就是「积分求面积」的原理。
记住这几点：
  • 公式：曲线 y = f(x)、x 轴、x = a、x = b 围成的面积 = ∫ₐᵇ f(x) dx。
  • 做法是标准的定积分：积分 → 代上限 → 减下限。
  • 面积总是正的；如果算出来是负数，说明曲线在 x 轴下方（见第 6 站）。
  • 题目常要求单位²，记得写面积单位。
  • 先确认上下限是哪两条竖线，别把交点当成了给定的 a、b。

5 两条曲线之间的面积Area between two curves Between curves曲线之间

学完你会：求两条曲线围成的封闭区域面积。

说人话：两块面积相减，就得到夹在中间的部分。 所以面积 = ∫(上面那条 − 下面那条) dx。 关键是先求两条曲线的交点，交点就是积分的上下限。
记住这几点（三步法）：
  • ① 求交点：令两式相等，解出 x —— 这些 x 就是积分的上下限。
  • ② 判断谁在上：在区间内取一个 x 代进去比大小，或者看图像。
  • ③ 积分：∫(上 − 下) dx，注意减号要作用于整个下方式子。
  • 常见错误：写 ∫上 dx − ∫下 dx 时忘了给下面的式子加括号，导致符号错。
  • 上下限有时题目直接给了（如 x = 0 到 x = 1），那就不用求交点。

例题

求 y = x 与 y = x² 围成的面积。
解： ① 求交点：x = x² → x² − x = 0 → x(x − 1) = 0 → x = 0 或 1。 ② 判断上下：取 x = 0.5，直线 y = 0.5，抛物线 y = 0.25 → 直线在上。 ③ 面积 = ∫₀¹ (x − x²) dx = [x²/2 − x³/3]₀¹。 代 1：1/2 − 1/3 = 1/6；代 0：0 → 面积 = 1/6。

Remember these (three steps):
  • ① Intersections: set the two expressions equal and solve — these x-values are the limits.
  • ② Which is on top: test one x inside the interval, or look at the sketch.
  • ③ Integrate: ∫(top − bottom) dx, making sure the minus applies to the whole bottom expression.
  • Classic error: forgetting brackets around the bottom curve, which flips a sign.
  • Sometimes the limits are given directly (like x = 0 to x = 1) — then no intersections needed.

6 曲线在 x 轴下方时怎么办Areas below the x-axis Negative area负面积

学完你会：分清「净积分值」和「几何面积」，会处理跨过 x 轴的情况。

说人话：曲线跑到 x 轴下面时，y 是负的，所以积出来也是负数——这是「带符号的面积」。 如果题目问的是面积（几何大小），就要按交点分段，每段单独积分再取绝对值相加。
记住这几点：
  • 定积分 = 带符号：轴上方为正，轴下方为负，可以互相抵消。
  • 面积 ≠ 定积分：面积永远是正的。跨轴时必须分段。
  • 分段法：① 求曲线与 x 轴的交点（令 y = 0）→ ② 每段单独积分 → ③ 取绝对值 → ④ 相加。
  • 看到 "find the area" 就要警惕：如果图穿过 x 轴，绝不能直接积一整段。
  • 奇函数（如 y = x³）在对称区间上的积分 = 0，因为两边完全抵消。

例题

求 y = x² − 4 与 x 轴、x = 0、x = 3 围成的总面积。
解： ① 先找与 x 轴交点：x² − 4 = 0 → x = 2（在区间 [0, 3] 内）。 ② 分两段：x ∈ [0, 2] 时曲线在轴下；x ∈ [2, 3] 时在轴上。 ③ 第一段：∫₀²(x² − 4)dx = [x³/3 − 4x]₀² = 8/3 − 8 = −16/3，取绝对值 16/3。 ④ 第二段：∫₂³(x² − 4)dx = (9 − 12) − (8/3 − 8) = −3 + 16/3 = 7/3。 ⑤ 总面积 = 16/3 + 7/3 = 23/3 ≈ 7.67。

✏️ 你来试一题

提示：先想图像——两块三角形，一块在轴下一块在轴上；用几何法算更快。

By the end you'll be able to: tell a net integral from a geometric area.

In plain words: when the curve dips below the x-axis, y is negative, so the integral comes out negative — it is a "signed area". If the question asks for area (a physical size), you must split the region at the intersections, integrate each piece, and add the absolute values.
Remember these:
  • Definite integrals carry a sign: positive above the axis, negative below; they can cancel.
  • Area ≠ integral: area is always positive, so split whenever the curve crosses the axis.
  • Splitting method: ① find where y = 0 → ② integrate each piece → ③ take absolute values → ④ add.
  • When you see "find the area", check whether the curve crosses the axis — if it does, never integrate across in one go.
  • An odd function (like y = x³) over a symmetric interval integrates to 0: the two halves cancel.

Example

Find the total area between y = x² − 4, the x-axis, x = 0 and x = 3.
Solution: ① Where does it cross? x² − 4 = 0 → x = 2 (inside [0, 3]). ② Split: on [0, 2] the curve is below the axis; on [2, 3] it is above. ③ First piece: ∫₀²(x² − 4)dx = [x³/3 − 4x]₀² = 8/3 − 8 = −16/3, absolute value 16/3. ④ Second piece: ∫₂³(x² − 4)dx = (9 − 12) − (8/3 − 8) = 7/3. ⑤ Total area = 16/3 + 7/3 = 23/3 ≈ 7.67.

7 梯形法则：估算面积The trapezium rule Trapezium rule梯形法则

学完你会：用梯形法则估算曲线下面积。

说人话：有些函数（比如 ∫e^(x²)dx）根本积不出来，这时候就用梯形拼图近似。 把区间等分成 n 段，每段用一条直线连起曲线上两点，形成 n 个梯形，把它们的面积加起来。
记住这几点：
  • 公式：面积 ≈ ½ h [ y₀ + yₙ + 2(y₁ + y₂ + … + yₙ₋₁) ]
  • h = (b − a) / n：区间长度除以条数，是每条的宽。
  • y₀ 和 yₙ 是最边上两条（首尾），中间的都乘 2（因为每个中间高度被两个梯形共用）。
  • 先列一张 x、y 的表，再套公式，不容易乱。
  • 凹凸影响方向：曲线下凸（碗口朝上）时梯形法高估；上凸时低估。

例题

用 4 个梯形估算 y = x² 在 x = 0 到 4 之间的面积，并与精确值比较。
解： h = (4 − 0)/4 = 1。取 x = 0, 1, 2, 3, 4。 对应 y = 0, 1, 4, 9, 16。 代入：½ × 1 × [0 + 16 + 2(1 + 4 + 9)] = ½ × [16 + 28] = 22。 精确值：∫₀⁴x²dx = [x³/3]₀⁴ = 64/3 ≈ 21.33。 梯形法略大（22 > 21.33）——因为 y = x² 下凸，梯形跑到了曲线上方。

✏️ 你来试一题

提示：h = 0.5，x 取 0、0.5、1、1.5、2，对应 y = 0、0.25、1、2.25、4。

点开看答案
答案： h = 2/4 = 0.5；y 值：0, 0.25, 1, 2.25, 4。 面积 ≈ ½ × 0.5 × [0 + 4 + 2(0.25 + 1 + 2.25)] = 0.25 × [4 + 7] = 2.75。 精确值 = 8/3 ≈ 2.667，同样是略高估。

By the end you'll be able to: estimate an area using the trapezium rule.

In plain words: some functions cannot be integrated at all. Then we patch the region with trapezia: split the interval into n equal strips, join consecutive points on the curve with straight lines, and add up the trapezia.
Remember these:
  • Formula: area ≈ ½ h [ y₀ + yₙ + 2(y₁ + y₂ + … + yₙ₋₁) ]
  • h = (b − a) / n: the width of each strip.
  • y₀ and yₙ are the two end heights; every middle height is doubled (each is shared by two trapezia).
  • Make a table of x and y values first — it keeps things tidy.
  • Direction of error: for a curve that opens upwards the rule overestimates; opening downwards, it underestimates.

Example

Solution: h = (4 − 0)/4 = 1. Take x = 0, 1, 2, 3, 4. Corresponding y = 0, 1, 4, 9, 16. Area ≈ ½ × 1 × [0 + 16 + 2(1 + 4 + 9)] = ½ × [16 + 28] = 22. Exact: ∫₀⁴x²dx = [x³/3]₀⁴ = 64/3 ≈ 21.33. The estimate is a little high, because y = x² opens upwards and the trapezia sit above the curve.

1 向量怎么表示、模长怎么算How to write a vector and its magnitude Vector向量

学完你会：读写向量，会算它的长度（模）。

说人话：普通数字（比如温度 20°）只有大小，叫标量 scalar。 但"往东走 3 公里"这种，光有大小不够，还得有方向——这就是向量 vector。 写法很简单：括号里两个数，表示"向右几个、向上几个"。
记住这几点：
  • 写法：a = (3, 4) 或竖着写列向量；印刷体用粗体 a，手写时下面加波浪线 a。
  • 模长（长度）：|a| = √(x² + y²)——就是勾股定理。也记作 |a⃗|。
  • 向量的模长一定 ≥ 0。
  • 方向相反、长度相同的是两个不同的向量，例如 (3, 4) 和 (−3, −4)。
  • 两个向量相等必须大小和方向都一样，也就是两个分量分别相等。

例题

已知 a = (3, 4)，求 |a|。
解： 套公式：|a| = √(3² + 4²) = √(9 + 16) = √25 = 5。 这就是最经典的勾股数 3-4-5，看到就秒答。

  • A magnitude is always ≥ 0.
  • Opposite direction, same length = a different vector, e.g. (3, 4) and (−3, −4).
  • Two vectors are equal only when both components match — same size and same direction.

2 向量加法与数乘Adding vectors and multiplying by a number Addition加法与数乘

学完你会：做向量的加、减和数乘运算。

说人话：向量加法是"首尾相接"——先走 a 再走 b，总的位移就是 a + b。 用坐标算更简单：对应位置直接相加。数乘 ka 就是每个分量都乘 k， 相当于把箭头拉长（k > 1）或缩短（0 < k < 1），k 为负时还会掉头。
记住这几点：
  • 加法：(x₁, y₁) + (x₂, y₂) = (x₁ + x₂, y₁ + y₂)。
  • 减法：(x₁, y₁) − (x₂, y₂) = (x₁ − x₂, y₁ − y₂)。
  • 数乘：k(x, y) = (kx, ky)。k < 0 时方向反过来。
  • 模长变化：|ka| = |k| · |a|（数乘会把长度按倍数拉长）。
  • 平行判定：如果 a = kb（某个倍数关系），那么两向量平行。这是几何题最常用的判据。

例题

已知 a = (2, 3)，b = (1, −4)。求 (a) a + b　(b) 2a。
解： (a) a + b = (2 + 1, 3 + (−4)) = (3, −1)。 (b) 2a = (2 × 2, 2 × 3) = (4, 6)。 核对：|a| = √13，|2a| = √(16 + 36) = √52 = 2√13，正好是 2 倍 ✓

By the end you'll be able to: add, subtract and scale vectors.

In plain words: adding vectors is "head to tail" — travel along a, then along b, and the total displacement is a + b. With coordinates it is even easier: add matching components. Multiplying by k scales every component: the arrow stretches (k > 1) or shrinks (0 < k < 1), and a negative k also reverses it.
Remember these:
  • Addition: (x₁, y₁) + (x₂, y₂) = (x₁ + x₂, y₁ + y₂).
  • Subtraction: (x₁, y₁) − (x₂, y₂) = (x₁ − x₂, y₁ − y₂).
  • Scalar multiplication: k(x, y) = (kx, ky); a negative k flips the direction.
  • Magnitude: |ka| = |k| · |a|.
  • Parallel test: if a = kb then the vectors are parallel — the most useful fact in geometry questions.

3 单位向量Unit vectors Unit vector单位向量

学完你会：求一个向量的单位向量，会用 i、j 表示法。

说人话：单位向量就是长度恰好为 1 的向量。 要把任何向量变成长度 1 而方向不变，只要除以它自己的长度：â = a/|a|。 另外，A-Level 常用 i（向右 1）和 j（向上 1）作基本单位， 所以 (3, 4) 也写成 3i + 4j。
记住这几点：
  • 单位向量：â = a / |a|（每个分量都除以模长）。
  • 验算：算完后求一次模长，应该正好等于 1。
  • i、j 表示法：i = (1, 0)，j = (0, 1)；所以 (x, y) = xi + yj。
  • 三维再加一个 k = (0, 0, 1)，写作 xi + yj + zk。
  • 题目问"方向"时，通常就是要你给单位向量——别只写原向量。

例题

已知 a = (3, 4)，求 a 方向上的单位向量。

4 点积（数量积）The scalar product Scalar product数量积

学完你会：算点积，并用它判断垂直。

说人话：向量和向量相乘有特别的方式，叫点积（数量积 scalar product）： 对应分量相乘再相加，结果是一个普通的数（不是向量）。 它最厉害的用途：如果点积 = 0，两个向量一定垂直——比看图量角快得多。
记住这几点：
  • 公式：a · b = x₁x₂ + y₁y₂（三维再加 z₁z₂）。
  • 结果是标量（一个数），可以是负数。
  • 垂直判定：a · b = 0 ⟺ a ⊥ b（非零向量）。
  • 另一个公式：a · b = |a| |b| cos θ —— 下一站用它求夹角。
  • 别把点积写成向量：点积的答案不能带括号或 i、j。

例题

已知 a = (2, 3)，b = (1, 4)。求 a · b。
解： 对应相乘：2 × 1 = 2；3 × 4 = 12。 相加：a · b = 2 + 12 = 14。 因为 14 ≠ 0，所以这两个向量不垂直。

✏️ 你来试一题

Remember these:

  • Perpendicular test: a · b = 0 ⟺ a ⊥ b (for non-zero vectors).

  • Never write the answer as a vector: no brackets, no i and j.

5 两向量的夹角The angle between two vectors Angle夹角

学完你会：求两个向量之间的夹角。

说人话：点积公式里藏着夹角：a · b = |a||b| cos θ。 把它变形，就得到 cos θ = (a·b)/(|a||b|)。 所以求夹角的流程是固定的三步：算点积 → 算两个模长 → 相除再用计算器反查 cos⁻¹。
记住这几点：
  • 公式：cos θ = (a · b) / (|a| |b|)。
  • 三步走：① 点积 ② 两个模长相乘 ③ 相除 → θ = cos⁻¹(结果)。
  • 符号看方向：cos θ > 0 锐角；= 0 直角；< 0 钝角（点积为负就一定是钝角）。
  • 夹角范围 0° ≤ θ ≤ 180°。
  • 答案通常保留 1 位小数（如 36.9°）。

例题

已知 a = (1, 2)，b = (2, 1)，求两向量夹角 θ。
解： ① 点积：a · b = 1×2 + 2×1 = 4。 ② 模长：|a| = √(1 + 4) = √5；|b| = √(4 + 1) = √5；相乘 = 5。 ③ cos θ = 4/5 = 0.8 → θ = cos⁻¹(0.8) ≈ 36.9°。 检查：cos θ > 0 说明是锐角，两个向量方向大致相同，合理 ✓

Remember these:
  • Formula: cos θ = (a · b) / (|a| |b|).
  • Three steps: ① dot product ② product of magnitudes ③ divide, then θ = cos⁻¹(result).
  • Sign tells you the type: cos θ > 0 acute; = 0 right angle; < 0 obtuse.
  • The angle satisfies 0° ≤ θ ≤ 180°.
  • Give angles to 1 decimal place unless told otherwise.

Solution: ① Scalar product: a · b = 1×2 + 2×1 = 4. ② Magnitudes: |a| = √5, |b| = √5, product = 5. ③ cos θ = 4/5 = 0.8 → θ = cos⁻¹(0.8) ≈ 36.9°. Check: cos θ > 0 means an acute angle — the two vectors point in similar directions ✓

6 位置向量与几何证明Position vectors and geometry proofs Position vector位置向量

学完你会：用位置向量做简单的几何证明（平行、中点）。

说人话：把原点 O 到某点的箭头叫这个点的位置向量。 那么从 A 走到 B 的向量就是 AB = b − a（终点减起点，顺序别反）。 有了这一条，几何证明就变成了代数运算：证明平行就找倍数关系，证明中点就比一比。
记住这几点：
  • 位置向量：点 A 的位置向量就是向量 OA，简记为 a。
  • 核心公式：AB = b − a（终点 − 起点）。反过来 BA = a − b = −AB。
  • 中点：AB 中点的位置向量 = (a + b)/2。
  • 证平行：算出两个向量，说明其中一个 = k × 另一个。
  • 证垂直：算出两个向量，说明点积 = 0。

例题

解： 位置向量：a = (1, 2)，b = (4, 6)。 AB = b − a = (4 − 1, 6 − 2) = (3, 4)。 |AB| = √(9 + 16) = 5。 中点 = (a + b)/2 = ((1+4)/2, (2+6)/2) = (2.5, 4)。

With that one fact, geometry proofs turn into algebra: to prove parallel, find a multiple; to prove perpendicular, show the dot product is 0.
Remember these:
  • Position vector: for point A it is the vector OA, written a.
  • Key formula: AB = b − a (end − start). Reversing gives BA = a − b = −AB.
  • Midpoint: its position vector is (a + b)/2.
  • To prove parallel: show one vector is k times the other.
  • To prove perpendicular: show the scalar product is 0.

1 微分方程是什么What a differential equation is Differential equation微分方程

学完你会：认出微分方程，理解"解"是一族函数。

说人话：普通方程解出来是一个数；微分方程里出现了导数， 解出来是一整个函数。比如 dy/dx = 2y 的意思是"这个量长得有多快，正比于它现在有多大"—— 细菌繁殖、复利都是这个规律，答案是 y = Ae²ˣ。
记住这几点：
  • 识别：方程里带 dy/dx（或 d²y/dx²）的就是微分方程。
  • 解的形式：通常是一族函数，含一个任意常数 c（因为要积分）。
  • A-Level 只考最简单的一种：可分离变量型（下一站）。
  • 验证方法：把声称的解求导，代回原方程看两边是否相等。
  • 别把 dy/dx 当分数去"约分"——但分离变量时确实可以像分数那样移项，这是标准做法。

例题

验证 y = 3e²ˣ 是微分方程 dy/dx = 2y 的解。
解： 左边：对 y = 3e²ˣ 求导（链式为 ×2）→ dy/dx = 6e²ˣ。 右边：2y = 2 × 3e²ˣ = 6e²ˣ。 左右相等 ✓ 所以 y = 3e²ˣ 确实是解。

✏️ 你来试一题

For instance dy/dx = 2y means "the rate of growth is proportional to the current size" — that is how bacteria multiply and how compound interest works, and the answer is y = Ae²ˣ.
Remember these:
  • Spot it: if the equation contains dy/dx (or d²y/dx²), it is a differential equation.
  • Form of the solution: usually a family of functions with a constant c.
  • At A-Level you only need the simplest type: separable variables (next stop).

  • dy/dx is not really a fraction, but in separation of variables you may move it around like one — that is the standard method.

2 可分离变量型：分离再积分Separable variables: separate, then integrate Separation分离变量

学完你会：解形如 dy/dx = f(x)·g(y) 的微分方程。

说人话：如果方程能写成"只含 x 的部分 × 只含 y 的部分"，就叫可分离。 做法是把 y 和 dy 都挪到左边、x 和 dx 都挪到右边，然后两边各自积分。 左边积出 ln|y| 是常态，最后再把它"解出来"写成 y = ……
记住这几点（三步法）：
  • ① 分离：把所有含 y 的移到 dy 那一边，含 x 的移到 dx 那一边（乘除移项）。
  • ② 积分：两边同时积分；只在一边写 + c（写两边会重复）。
  • ③ 整理：把 ln|y| = … 化成 y = Ae^(…)（利用 e^(ln y) = y，把常数 c 吸收成 A）。
  • 必背积分：∫(1/y) dy = ln|y|。
  • 别忘绝对值：积分出的是 ln|y|；化成 y = Ae^(…) 时，A 可以是正也可以是负，所以不用再纠结。

例题

解微分方程 dy/dx = x y。
解： ① 分离：dy/y = x dx　（两边同除以 y，同乘 dx）。 ② 积分：∫(1/y)dy = ∫x dx → ln|y| = x²/2 + c。 ③ 整理：两边取 e → |y| = e^(x²/2 + c) = e^c · e^(x²/2)。 把 e^c 记成新常数 A：通解 y = A e^(x²/2)。 验算：y′ = A e^(x²/2) · x = x·y ✓

✏️ 你来试一题

提示：右边只有 y，分离后是 dy/y = 3 dx，积分得 ln|y| = 3x + c。

解微分方程 dy/dx = 3y。
点开看答案
答案： dy/y = 3 dx。 积分：ln|y| = 3x + c。 通解：y = A e³ˣ。 验算：y′ = 3Ae³ˣ = 3y ✓

By the end you'll be able to: solve equations of the form dy/dx = f(x)·g(y).

In plain words: if the equation can be written as "a part with only x × a part with only y", it is separable. Move everything with y to the dy side and everything with x to the dx side, then integrate both sides. The left side usually gives ln|y|, which you then rearrange into y = …
Remember these (three steps):
  • ① Separate: y-terms with dy on one side, x-terms with dx on the other.
  • ② Integrate: integrate both sides; write + c on one side only.
  • ③ Tidy up: turn ln|y| = … into y = Ae^(…) (using e^(ln y) = y; the constant c becomes A).
  • Must know: ∫(1/y) dy = ln|y|.
  • Do not drop the modulus: you get ln|y|, and when writing y = Ae^(…) the constant A can be positive or negative anyway.

Example

Solve the differential equation dy/dx = x y.
Solution: ① Separate: dy/y = x dx. ② Integrate: ∫(1/y)dy = ∫x dx → ln|y| = x²/2 + c. ③ Tidy: take e of both sides → |y| = e^c · e^(x²/2). Write e^c as a new constant A: y = A e^(x²/2). Check: y′ = A e^(x²/2) · x = x·y ✓

Show answer
Answer: dy/y = 3 dx. Integrate: ln|y| = 3x + c. General solution: y = A e³ˣ. Check: y′ = 3Ae³ˣ = 3y ✓

3 通解与特解General and particular solutions Particular solution特解

学完你会：用初值条件把通解变成特解。

说人话：积分产生的常数 A 说明解有一整族（一摞形状相同、高矮不同的曲线）。 题目再给一个条件（比如"一开始有 5 个细菌"），就能把 A 定下来， 得到唯一的特解 particular solution。
记住这几点：
  • 通解 general solution：含任意常数 A（或 c）的解。
  • 特解 particular solution：把给定条件代进去、求出 A 之后的解。
  • 步骤：① 先求通解 → ② 把 x、y 的给定值代入 → ③ 解出 A → ④ 把 A 写回通解。
  • 条件常见写法：「y = 5 when x = 0」「at t = 0, N = 200」。
  • 最后一定要把 A 代回原式重写一遍，只写"c = 5"通常不算完整答案。

例题

解 dy/dx = 2y，已知 x = 0 时 y = 5。
解： ① 分离积分：dy/y = 2dx → ln|y| = 2x + c → 通解 y = Ae²ˣ。 ② 代入 x = 0、y = 5：5 = A·e⁰ = A × 1 → A = 5。 ③ 写回：特解 y = 5e²ˣ。 验算：x = 0 时 y = 5 ✓；y′ = 10e²ˣ = 2y ✓

By the end you'll be able to: turn a general solution into a particular one using a condition.

  • Particular solution: the one you get after substituting the given values.
  • Steps: ① general solution → ② substitute the given x and y → ③ find A → ④ write it back in.
  • Conditions are often written "y = 5 when x = 0" or "at t = 0, N = 200".

4 指数增长与衰减建模Modelling growth and decay Modelling建模

学完你会：把文字描述翻译成微分方程，并解出模型。

说人话：应用题里出现"增长率与当前数量成正比"，就写成 dy/dt = ky。 k > 0 是增长（人口、细菌），k < 0 是衰减（药物、放射性、折旧）。 解出来就是单元 6 见过的老朋友：y = A eᵏᵗ。
记住这几点：
  • 翻译：「变化率正比于 y」→ dy/dt = k y。
  • 通解：y = A eᵏᵗ（分离变量积分即得）。
  • 符号：题目说"减少/衰减"时，方程写成 dy/dt = −ky（k > 0）。
  • 单位：t 用年，k 就是"每年"；别混用。
  • 看清问的是"数量"还是"速率"：dN/dt 是变化速度，N 才是数量。

例题

某种细菌的增长速率与当前数量成正比，比例常数 0.1/小时。初始有 200 个。求 10 小时后的数量。
解： ① 写方程：dN/dt = 0.1 N。 ② 解：分离积分 → ln N = 0.1t + c → N = A e^(0.1t)。 ③ 代入 t = 0、N = 200 → A = 200，所以 N = 200 e^(0.1t)。 ④ t = 10：N = 200 × e¹ = 200 × 2.718 ≈ 544 个。

✏️ 你来试一题

提示：衰减写成 dV/dt = −0.05V，解出 V = A e^(−0.05t)；t = 20 时是 e⁻¹。

答案： dV/dt = −0.05 V → V = A e^(−0.05t)。 代入 t = 0、V = 1000 → A = 1000，所以 V = 1000 e^(−0.05t)。 t = 20：V = 1000 × e⁻¹ = 1000 × 0.3679 ≈ 367.9 mg。

By the end you'll be able to: turn a worded description into a differential equation and solve it.

In plain words: when a question says "the rate of growth is proportional to the current amount", write dy/dt = ky. k > 0 means growth (population, bacteria); k < 0 means decay (drugs, radioactivity). The solution is the old friend from Unit 6: y = A eᵏᵗ.
Remember these:
  • Translation: "rate proportional to y" → dy/dt = k y.
  • Solution: y = A eᵏᵗ.
  • Sign: if it says "decreases", write dy/dt = −ky with k > 0.
  • Units: if t is in years, k is "per year" — keep them consistent.
  • Watch what is asked: dN/dt is the rate, N is the amount.

Example

Bacteria grow at a rate proportional to their number, with constant 0.1 per hour. Initially there are 200. Find the number after 10 hours.
Solution: ① Equation: dN/dt = 0.1 N. ② Solve: ln N = 0.1t + c → N = A e^(0.1t). ③ At t = 0, N = 200 → A = 200, so N = 200 e^(0.1t). ④ At t = 10: N = 200 × e¹ = 200 × 2.718 ≈ 544.

5 迭代法：xₙ₊₁ = f(xₙ)Iteration: xₙ₊₁ = f(xₙ) Iteration迭代

学完你会：用迭代公式一步步算出方程的近似根。

说人话：有些方程（比如 x³ + 2x = 5）解不出精确的 x。 办法是把它改写成 x = f(x) 的形式，然后猜一个数代进去，算出结果再代回去， 反复几次，数值会越来越稳，停在方程的根上。
记住这几点：
  • 迭代公式：xₙ₊₁ = f(xₙ)。x₁ 是题目给的起始值（starting value）。
  • 做法：把 x₁ 代入右边算出 x₂，再把 x₂ 代入算出 x₃……一直算下去。
  • 下标含义：xₙ 是"第 n 次的结果"，xₙ₊₁ 是"下一次"。
  • 收敛：相邻两次结果越来越接近（比如都四舍五入到 2.24），说明快到了。
  • 计算器技巧：算出答案后按 ANS 键，直接把上一轮结果代入，不用每次重打。

例题

用迭代公式 xₙ₊₁ = (xₙ + 5/xₙ)/2，从 x₁ = 2 出发，求 x₂、x₃（保留 4 位小数）。这个序列在逼近什么数？
解： x₂ = (2 + 5/2)/2 = (2 + 2.5)/2 = 2.25。 x₃ = (2.25 + 5/2.25)/2 = (2.25 + 2.2222)/2 = 2.2361。 再算一次：x₄ = (2.2361 + 5/2.2361)/2 = (2.2361 + 2.2360)/2 = 2.2361，已经稳定。 它在逼近 √5 ≈ 2.2361——这正是"求平方根"的经典迭代。

✏️ 你来试一题

提示：x₂ = (2.5 + 7/2.5)/2 = (2.5 + 2.8)/2；x₃ 再把 2.65 代进去。

用迭代公式 xₙ₊₁ = (xₙ + 7/xₙ)/2，从 x₁ = 2.5 出发，求 x₂、x₃（保留 4 位小数）。它在逼近什么数？

By the end you'll be able to: use an iteration formula to approximate a root.

In plain words: some equations (like x³ + 2x = 5) cannot be solved exactly. The trick is to rearrange them into x = f(x), then guess a value, feed it in, and feed the result back in again. After a few rounds the numbers settle down on the root.
Remember these:
  • Formula: xₙ₊₁ = f(xₙ). The question supplies a starting value x₁.
  • Method: substitute x₁ to get x₂, then x₂ to get x₃, and so on.
  • Subscripts: xₙ is the current value, xₙ₊₁ the next one.
  • Convergence: when successive values agree to the required accuracy, you have arrived.
  • Calculator tip: use the ANS key to feed the previous result straight back in.

Example

Using xₙ₊₁ = (xₙ + 5/xₙ)/2 with x₁ = 2, find x₂ and x₃ (4 d.p.). What number is the sequence approaching?
Solution: x₂ = (2 + 5/2)/2 = (2 + 2.5)/2 = 2.25. x₃ = (2.25 + 5/2.25)/2 = (2.25 + 2.2222)/2 = 2.2361. One more: x₄ = (2.2361 + 2.2360)/2 = 2.2361 — it has settled. It approaches √5 ≈ 2.2361 — the classic square-root iteration.

6 用符号变化定位根Locating a root by a change of sign Change of sign符号变化

学完你会：用 f(a)、f(b) 异号来证明根落在哪个区间。

说人话：如果函数图像是连续不断的一笔， 而它在 a 点的值是负的、在 b 点的值是正的，那它中途一定要穿过 x 轴—— 所以 (a, b) 之间一定藏着一个根。这叫符号变化法（change of sign）。
记住这几点：
  • 判据：f(a) 和 f(b) 异号（一正一负）→ 区间 (a, b) 内至少有一个根。
  • 前提：函数在这个区间上连续（A-Level 里的多项式、指数都满足）。
  • 答题写法：算出 f(a) = …（负值）、f(b) = …（正值），然后写「符号改变，故根在 (a, b) 内」。
  • 它只能说明存在，不能保证只有一个根（除非函数在该区间单调）。
  • 必须算出具体数值再下结论，只写"因为异号"不给分。

例题

证明方程 x³ − x − 1 = 0 在 1 和 2 之间有一个根。
解： 设 f(x) = x³ − x − 1。 f(1) = 1 − 1 − 1 = −1（负）。 f(2) = 8 − 2 − 1 = 5（正）。 符号由负变正，且 f 连续 → (1, 2) 内至少有一个根 ✓

✏️ 你来试一题

提示：f(1) = 1 + 2 − 5；f(1.5) = 3.375 + 3 − 5。

答案： f(1) = 1 + 2 − 5 = −2（负）。 f(1.5) = 3.375 + 3 − 5 = 1.375（正）。 符号改变 → (1, 1.5) 内有一个根 ✓

By the end you'll be able to: show a root lies in an interval using a change of sign.

In plain words: if the graph is drawn in one continuous stroke, and it is negative at a but positive at b, then it must cross the x-axis somewhere in between — so a root is trapped in (a, b). This is the change of sign method.
Remember these:
  • Test: f(a) and f(b) have opposite signs → at least one root in (a, b).
  • Condition: the function must be continuous on that interval.
  • Writing it up: state f(a) = … (negative), f(b) = … (positive), then "sign change, so a root lies in (a, b)".
  • It proves existence, not uniqueness (unless the function is monotonic there).
  • You must show the actual values — just saying "the sign changes" earns no marks.

Example

Solution: Let f(x) = x³ − x − 1. f(1) = 1 − 1 − 1 = −1 (negative). f(2) = 8 − 2 − 1 = 5 (positive). The sign changes and f is continuous → a root lies in (1, 2) ✓

7 牛顿迭代法The Newton-Raphson method Newton-Raphson牛顿法

学完你会：用牛顿迭代公式求根的近似值。

说人话：牛顿法比普通迭代更聪明：它在当前猜测点作一条切线， 把切线与 x 轴的交点当作下一个猜测。因为用了导数（斜率）， 它通常收敛得特别快——两三步就能精确到小数后好几位。
记住这几点：
  • 公式：xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ)（先求导函数 f′）。
  • 步骤：① 写出 f′(x) → ② 把 xₙ 代入 f 和 f′ → ③ 套公式算出 xₙ₊₁ → ④ 重复。
  • 优点：收敛快，通常 2–3 步就很准。
  • 失效情况：如果某一步 f′(xₙ) = 0（切线水平），公式分母为 0，方法就崩了；起始值选得太远也可能不收敛。
  • 它就是"用切线代替曲线"——和单元 7 的切线方程是同一件事。

例题

用牛顿法求 f(x) = x² − 5 的正根，从 x₁ = 2 出发，求 x₂、x₃。
解： ① 求导：f′(x) = 2x。 ② x₁ = 2：f(2) = 4 − 5 = −1；f′(2) = 4。 x₂ = 2 − (−1)/4 = 2 + 0.25 = 2.25。 ③ x₂ = 2.25：f = 5.0625 − 5 = 0.0625；f′ = 4.5。 x₃ = 2.25 − 0.0625/4.5 = 2.25 − 0.0139 = 2.2361　（= √5，一步到位）

✏️ 你来试一题

提示：f′(x) = 2x；x₁ = 2.6 时 f = 6.76 − 7 = −0.24，f′ = 5.2，所以 x₂ = 2.6 + 0.24/5.2。

用牛顿法求 f(x) = x² − 7 的正根，从 x₁ = 2.6 出发，求 x₂（保留 4 位小数）。

By the end you'll be able to: use the Newton-Raphson formula to approximate a root.

In plain words: Newton-Raphson is cleverer than plain iteration: at your current guess, draw the tangent and use where it hits the x-axis as the next guess. Because it uses the derivative (the slope), it usually converges very fast — two or three steps can give several decimal places.
Remember these:
  • Formula: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ) — find f′ first.
  • Steps: ① write f′(x) → ② evaluate f and f′ at xₙ → ③ apply the formula → ④ repeat.
  • Advantage: very fast convergence, often accurate in 2–3 steps.
  • When it fails: if f′(xₙ) = 0 the tangent is horizontal and the formula breaks down; a poor starting value may not converge at all.
  • It is exactly "replace the curve by its tangent" — the same idea as the tangent in Unit 7.

Example

Use Newton-Raphson on f(x) = x² − 5 starting from x₁ = 2 to find x₂ and x₃.
Solution: ① Differentiate: f′(x) = 2x. ② At x₁ = 2: f(2) = −1, f′(2) = 4. x₂ = 2 − (−1)/4 = 2 + 0.25 = 2.25. ③ At x₂ = 2.25: f = 0.0625, f′ = 4.5. x₃ = 2.25 − 0.0625/4.5 = 2.2361 — that is √5, in just two steps.
