四、考试提示4 · Exam tips

  • P1 靠套公式：纯数学 1 大部分是直接套公式的计算题，微积分、三角、数列的公式要熟到不假思索。P1 rewards formulae: most of Pure Mathematics 1 is direct calculation — know the calculus, trig and series formulae cold.
  • 写步骤拿方法分：即使最后答案算错，正确的方法步骤也能拿大部分分，别只写一个答案。Show working for method marks: even with a wrong final answer, correct steps earn most of the marks — never write just the answer.
  • 单位与精度：角度默认用弧度，除非题目注明度数；最终答案一般保留三位有效数字。Units and accuracy: angles are in radians unless stated; give final answers to 3 significant figures.
  • 先画图：力学先画受力图，正态分布题先标出区域，坐标几何先画草图，能少犯很多错。Draw first: sketch force diagrams in mechanics, shade the region in normal-distribution questions, and sketch graphs in coordinate geometry.

1[6]

解二次方程 2x2 − 5x − 3 = 0。Solve the quadratic equation 2x2 − 5x − 3 = 0.

点开看答案Show answer
2x2 − 5x − 3 = 0 (2x + 1)(x − 3) = 0 x = 3 或 x = −1/2

因式分解：把 −5x 拆成 −6x + x，再两两分组提公因式得 (2x+1)(x−3)。检验：x=3 与 x=−1/2 代回原式都等于 0。Factorise by splitting −5x into −6x + x, then group and take out common factors to get (2x+1)(x−3). Check: both x=3 and x=−1/2 give 0.

2[4]

求函数 f(x) = (2x − 1)/(x + 3) 的定义域。Find the domain of f(x) = (2x − 1)/(x + 3).

点开看答案Show answer
x + 3 ≠ 0 → x ≠ −3 定义域：除 −3 外的所有实数

分式的分母不能为 0。令 x+3=0 得 x=−3，这是唯一要排除的点，其余所有实数都可以取。The denominator of a fraction cannot be 0. Setting x+3=0 gives x=−3, the only point to exclude; all other real numbers are allowed.

3[6]

写出 (1 + 2x)5 二项式展开的前三项。Write down the first three terms of the binomial expansion of (1 + 2x)5.

点开看答案Show answer
(1 + 2x)5 = 1 + 5C1(2x) + 5C2(2x)2 + … = 1 + 5(2x) + 10(4x2) = 1 + 10x + 40x2

公式：(1+u)n = 1 + nC1u + nC2u2 + …。这里 u=2x，5C1=5、5C2=10，注意 (2x)2=4x2。Formula: (1+u)n = 1 + nC1u + nC2u2 + …. Here u=2x, 5C1=5, 5C2=10; note (2x)2=4x2.

4[6]

等差数列首项 a=3、公差 d=5，求前 20 项和 S20。An arithmetic sequence has first term a=3 and common difference d=5. Find the sum of the first 20 terms, S20.

点开看答案Show answer
Sn = (n/2)[2a + (n−1)d] S20 = (20/2)[2×3 + 19×5] = 10[6 + 95] = 10 × 101 = 1010

等差数列求和公式 Sn=n/2·[2a+(n−1)d]。代入 n=20、a=3、d=5 即可。也可用首末项：a20=3+19×5=98，S20=20/2·(3+98)=1010，两种都对。Sum formula Sn = n/2·[2a+(n−1)d]. Substitute n=20, a=3, d=5. Or use first+last: a20 = 3+19×5 = 98, S20 = 20/2·(3+98) = 1010 — both are correct.

5[6]

解方程 sin x = 1/2，其中 0 ≤ x ≤ 2π。Solve sin x = 1/2 for 0 ≤ x ≤ 2π.

点开看答案Show answer
sin x = 1/2 x = π/6 (第一象限) x = π − π/6 = 5π/6 (第二象限) 答案：x = π/6, 5π/6

sin 在第一、二象限为正。基准角 sin−1(1/2)=π/6；第二象限的解是 π−π/6=5π/6。在 0≤x≤2π 范围内只有这两个解。Sine is positive in quadrants 1 and 2. The base angle is sin−1(1/2)=π/6; the second-quadrant solution is π−π/6=5π/6. These are the only two solutions in 0≤x≤2π.

6[8]

求曲线 y = x3 − 6x2 + 9x 的驻点，并判断每个驻点是极大还是极小。Find the stationary points of y = x3 − 6x2 + 9x and determine whether each is a maximum or minimum.

点开看答案Show answer
dy/dx = 3x2 − 12x + 9 = 3(x − 1)(x − 3) 驻点：x = 1 或 x = 3 d2y/dx2 = 6x − 12 x = 1: y″ = −6 < 0 → 极大；y(1) = 4 x = 3: y″ = +6 > 0 → 极小；y(3) = 0 答案：(1, 4) 极大；(3, 0) 极小

先令一阶导为 0 求驻点，再用二阶导判断凹凸：y″<0 是极大、y″>0 是极小。把 x 代回原式得到 y 值。Set the first derivative to 0 to find the stationary points, then use the second derivative: y″<0 gives a maximum, y″>0 a minimum. Substitute x back to get the y-values.

7[6]

计算定积分 ∫01 (3x2 − 2x + 1) dx。Evaluate ∫01 (3x2 − 2x + 1) dx.

点开看答案Show answer
∫(3x2 − 2x + 1)dx = x3 − x2 + x ∫01 = (13 − 12 + 1) − (0 − 0 + 0) = 1 − 1 + 1 = 1

先逐项求原函数（幂次 +1 再除以新幂次），再代入上下限做差：上界值减下界值。Integrate term by term (add 1 to the power and divide by the new power), then substitute the limits: upper value minus lower value.

8[8]

物体从静止开始，以 2 m/s2 的加速度做匀加速直线运动，持续 5 s。求：(a) 末速度；(b) 位移。An object starts from rest and accelerates at 2 m/s2 for 5 s. Find (a) the final velocity and (b) the displacement.

点开看答案Show answer
u = 0, a = 2, t = 5 (a) v = u + at = 0 + 2×5 = 10 m/s (b) s = ut + ½at2 = 0 + ½×2×25 = 25 m

「从静止」表示初速度 u=0。用两个 suvat 公式：v=u+at 求末速度，s=ut+½at2 求位移。单位别忘写。"From rest" means initial velocity u=0. Use two suvat equations: v=u+at for final velocity, s=ut+½at2 for displacement. Remember the units.

1[6]

解不等式 x2 − 4x − 5 < 0。Solve the inequality x2 − 4x − 5 < 0.

点开看答案Show answer
x2 − 4x − 5 < 0 (x − 5)(x + 1) < 0 根：x = −1 和 x = 5 抛物线开口向上 → 两根之间取负 答案：−1 < x < 5

因式分解得 (x−5)(x+1)。二次项系数为正，抛物线开口向上，所以函数值在两个根之间为负。写成区间就是 −1<x<5（端点不含，因为严格小于 0）。Factorise to (x−5)(x+1). The leading coefficient is positive, so the parabola opens up and is negative between the two roots. In interval form: −1<x<5 (endpoints excluded, since it is strictly less than 0).

2[6]

设 f(x) = 2x + 1、g(x) = x2。(a) 求复合函数 fg(x)；(b) 求 f 的反函数 f−1(x)。Let f(x) = 2x + 1 and g(x) = x2. (a) Find the composite function fg(x); (b) find the inverse function f−1(x).

点开看答案Show answer
(a) fg(x) = f(g(x)) = f(x2) = 2x2 + 1 (b) y = 2x + 1 → 2x = y − 1 → x = (y − 1)/2 f−1(x) = (x − 1)/2

(a) 复合 fg 表示先做 g 再做 f：把 x2 代入 f 里。(b) 求反函数：把 y=2x+1 解出 x，再把 x、y 互换即可。(a) fg means do g first then f: substitute x2 into f. (b) To find the inverse, solve y=2x+1 for x, then swap x and y.

3[6]

等比数列首项 a=2、公比 r=3，求前 5 项和 S5。A geometric sequence has first term a=2 and common ratio r=3. Find the sum of the first 5 terms, S5.

点开看答案Show answer
Sn = a(rn − 1)/(r − 1) S5 = 2(35 − 1)/(3 − 1) = 2(243 − 1)/2 = 242

等比数列求和公式 Sn=a(rn−1)/(r−1)。代入 a=2、r=3、n=5：35=243，所以 S5=2×242/2=242。也可逐项加：2+6+18+54+162=242。Geometric sum formula Sn=a(rn−1)/(r−1). Substitute a=2, r=3, n=5: 35=243, so S5=2×242/2=242. Or add term by term: 2+6+18+54+162=242.

4[8]

用乘法法则求 y = x·ex 的导数 dy/dx。Use the product rule to find dy/dx for y = x·ex.

点开看答案Show answer
u = x, v = ex u′ = 1, v′ = ex dy/dx = u′v + uv′ = 1·ex + x·ex = ex(1 + x) = ex(x + 1)

乘法法则：(uv)′=u′v+uv′。令 u=x、v=ex，注意 ex 的导数还是它自己。最后提出公因式 ex。Product rule: (uv)′=u′v+uv′. Let u=x, v=ex; note the derivative of ex is itself. Finally factor out ex.

5[8]

求直线 y = 2x 与 x 轴、以及直线 x = 0 到 x = 3 之间围成的面积。Find the area enclosed by the line y = 2x, the x-axis, and the lines x = 0 to x = 3.

点开看答案Show answer
面积 = ∫03 2x dx = [x2]03 = 32 − 02 = 9

定积分求面积：∫2x dx = x2，代入上下限 9−0=9。也可当三角形看：底 3、高 y=2×3=6，面积 ½×3×6=9，两种方法结果一致。Area by integration: ∫2x dx = x2, substitute the limits to get 9−0=9. Or treat it as a triangle: base 3, height y=2×3=6, area ½×3×6=9 — both agree.

6[6]

对数据 2, 4, 4, 6, 8，求：(a) 平均数；(b) 中位数；(c) 标准差（总体）。For the data 2, 4, 4, 6, 8, find (a) the mean, (b) the median, and (c) the standard deviation (population).

点开看答案Show answer
(a) mean = (2+4+4+6+8)/5 = 24/5 = 4.8 (b) 排好序：2,4,4,6,8 → 中位数 = 第 3 个 = 4 (c) 方差 = [(2−4.8)2+(4−4.8)2+(4−4.8)2+(6−4.8)2+(8−4.8)2]/5 = (7.84+0.64+0.64+1.44+10.24)/5 = 20.8/5 = 4.16 SD = √4.16 ≈ 2.04

平均数把所有值相加除以个数；中位数是排序后正中间的值；标准差先算每个数与平均数的差的平方和，再除以 n（总体）取平方根。The mean is the sum divided by the count; the median is the middle value after sorting; for the standard deviation, sum the squared deviations from the mean, divide by n (population), then take the square root.

7[4]

同时掷两枚均匀骰子，求两数之和等于 7 的概率。Two fair dice are thrown. Find the probability that the sum of the two numbers is 7.

点开看答案Show answer
和为 7 的组合：(1,6)(2,5)(3,4)(4,3)(5,2)(6,1) → 6 种 总结果：6 × 6 = 36 种 P(和为 7) = 6/36 = 1/6

两枚骰子共有 6×6=36 种等可能结果。和为 7 的有序数对共 6 种，所以概率 = 6/36 = 1/6。There are 6×6=36 equally likely outcomes. There are 6 ordered pairs summing to 7, so the probability is 6/36 = 1/6.

8[6]

设 X ~ N(100, 152)，求 P(X > 115)。Given X ~ N(100, 152), find P(X > 115).

点开看答案Show answer
z = (x − μ)/σ = (115 − 100)/15 = 1 P(X > 115) = P(Z > 1) = 1 − Φ(1) = 1 − 0.8413 = 0.1587

先标准化成 z 值：z=(x−μ)/σ=1。查标准正态表 Φ(1)=0.8413 是 Z≤1 的概率，我们要求的是大于 1 的部分，所以用 1 减去它，得 0.1587（约 15.9%）。Standardise first: z=(x−μ)/σ=1. The normal table gives Φ(1)=0.8413, the probability that Z≤1; we want the part greater than 1, so subtract from 1 to get 0.1587 (about 15.9%).
