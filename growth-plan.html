理科工程方向 · 升学成长计划

高一 → 大学申请 · 四门 A-Level（数学 / 物理 / 计算机 / 化学）· 五个目的地（香港 / 英国 / 澳洲 / 内地 / 加拿大）。 这份计划把「十年路线」里与企业资源相关的动作，落成一份能照着月历执行的升学清单——每学期学什么、考什么、报什么、做什么，都写到了点。

① 定位与总路线 ② 四门考试策略 ③ 分年级时间轴 ④ 五目的地要点 ⑤ 背景提升清单 ⑥ 行动清单
①

定位与总路线

Positioning & route
先对表（重要）：以国际学校常见的 4 年制（IGCSE 两年 + A-Level 两年）为基准做时间轴—— 高一 / 高二学 IGCSE 并大考，高三学 AS（第一年），高四学 A2（第二年）、6 月大考、8 月出分、9 月起申请、次年秋入学。 若孩子所在学校是 3 年制（高一即 AS 年），把整张表整体前移一年即可，节点月份不变。

方向 · 理科工程

对标智能汽车 / 自动驾驶 / AI 工程这一类「数理 + 计算机」交叉的硬核方向。工程对口的 A-Level 组合是「数学 + 物理」双核心，再配计算机、化学。

四门考试

数学（9709）· 物理（9702）· 计算机（9618）· 化学（9701）。数学物理是工程标配，计算机体现 AI/算法能力，化学覆盖材料/电池方向。

五个目的地

香港 · 英国 · 澳洲 · 中国内地（接受 A-Level）· 加拿大，都认 A-Level 成绩，一次准备、多地同申，对冲风险。

一句话路线

高一广撒网打基础 → 高二 IGCSE 拿高分、定方向 → 高三 AS 冲 A + 竞赛科研 + 首考雅思 → 高四 A2 冲 A* + 多地申请。

②

四门考试策略

Four A-Level subjects

数学 9709 （核心，工程必选）

考什么：纯数 1（P1，75 分）+ 纯数 3（P3，75 分）+ 应用两卷（力学 M 50 分 + 概率统计 S1 50 分，或 S1+S2）。

工程关键：微积分、向量、力学——这三块是大学工程的命根子，务必学扎实。

本站资源：纯数学 + 进阶数学（9231）+ 力学 + 统计 + 数学真题包。

目标：A*（工程顶尖校几乎都看数学 A*）。

物理 9702 （核心，工程必选）

考什么：5 张卷——P1 选择（40）、P2 AS 结构（60）、P3 实验（40）、P4 A2 结构（100）、P5 规划分析（30）。

工程关键：力学、电学、场——工程所有分支的地基；实验卷 P3/P5 是拉分项。

本站资源：物理站（AS+A2 十二单元，含实验）+ 物理真题包。

目标：A* 或 A。

计算机 9618 （AI/算法能力背书）

考什么：4 张卷——P1 理论（75）、P2 编程（75）、P3 进阶理论（75）、P4 上机写代码（75）。

工程关键：算法、数据结构、OOP、AI——直接对应自动驾驶/机器人软件栈。

本站资源：IGCSE 0478（入门）+ A-Level 9618（进阶）+ 计算机真题包。

目标：A 或 A*；上机 P4 用 Python 练熟。

化学 9701 （材料/电池方向）

考什么：5 张卷，结构同物理——物理化学 / 无机 / 有机 / 光谱四大块。

工程关键：电化学（电池、燃料电池）、材料——新能源车方向很有用。

本站资源：化学站（18 单元 108 站）+ 化学真题包。

目标：A（作为第三/四门，稳住 A 即可，不必死磕 A*）。

选科建议：工程方向「数学 + 物理」雷打不动；第三门建议计算机（AI 方向）或化学（材料/电池方向），第四门备选。若目标英国 G5/香港港三大，四门 A-Level 里确保 数学 A* + 物理 A*（或 A）+ 另外两门 A 的组合最稳。
③

分年级可操作时间轴

Year-by-year timeline
高一 · IGCSE 第一年（广撒网，养手感）
关键词：打基础 · 不偏科 · 把兴趣玩出来
  • 学业：IGCSE 全科跟上，重点压数学、物理、CS、化学四门；每天 30 分钟刷本站「预习站」，先看说人话再做题。
  • 考试：无外部大考；认真对待每次校内小测，把错题攒成本子。
  • 背景：纯玩出兴趣——PhET 物理仿真、CircuitVerse 搭逻辑门、Scratch/CS Unplugged；11 月试水 AMC 8/10 找感觉。
  • 英语：不急着考雅思，先养成读英文科普、听 TED 的习惯；词汇 2000+。
  • 暑期：跟母亲进一次公司测试场「少年观察员」，看真车、真雷达、真数据。
高二 · IGCSE 大考年（定方向）
关键词：IGCSE 冲 A/A* · 锁定 A-Level 选科
  • 学业：IGCSE 全面冲刺，四门核心科目保 A*，其余保 A。
  • 考试：5–6 月 IGCSE 大考；8 月出分。
  • 方向：出分后正式锁定「数学 + 物理 + 计算机（或化学）」组合；数学强就加进阶数学。
  • 背景：暑期进公司测试场实习（ADAS 路测数据标注起步），攒一段「有实感」的工程经历。
  • 英语：暑期首考雅思，目标 6.0–6.5，摸清弱项。
高三 · AS 年（冲 A + 攒背景，全年最忙）
关键词：AS 四门冲 A · 竞赛科研 · 雅思达标
  • 学业：AS 四门（数学 P1、物理、CS、化学）全面学，站内「速查表 + 真题包模拟卷」限时练。
  • 考试：5–6 月 AS 大考，8 月出分（英国申请时 AS 成绩是重要参考）。
  • 竞赛（按月份）：10–11 月 AMC 12 / BPhO / UKMT；1 月 UKChO（化学）；2 月 USACO / 加拿大 CCC（计算机）；3–4 月 Physics Bowl。
  • 科研/项目：启动一个「工程向」个人项目或 EPQ——如「车联网校车安全监护系统」（孩子主导算法，母亲法务部支持报专利）。
  • 英语：雅思刷到 6.5–7.0（单项 6.0+），最迟高三暑假前锁定。
高四 · A2 年 + 申请季（定胜负）
关键词：A2 冲 A* · 多地同申 · 等 offer
  • 学业：A2 四门冲刺，数学/物理冲 A*，其余稳 A。
  • 考试：5–6 月 A2 大考，8 月出最终成绩。
  • 申请（关键月）：9 月 UCAS 开放、澳洲提前批；10 月中 牛剑+医学截止（不申牛剑可忽略）；11 月–1 月 香港 Non-JUPAS、加拿大 OUAC（1 月中截止）、内地中外合作。
  • 文书：个人陈述（PS）用「竞赛 + 测试场实习 + 专利项目」串成一条工程主线。
  • 结果：次年 1–5 月陆续收 offer，按 A-Level 条件录取（conditional）确认。
一句话节奏：高一玩出门道 → 高二 IGCSE 拿高分定方向 → 高三 AS 冲 A + 竞赛科研雅思三线并进 → 高四 A2 冲 A* + 九月起多地同申。竞赛、科研、雅思都集中在高三，务必提前把英语底子打在高一高二。
④

五个目的地 · 申请要点

Five destinations

下列等级为工程类专业典型参考值（A*AA 表示三科中一门 A* 两门 A），每年微调，申请季务必以各校官网当年为准。

香港 Non-JUPAS

认可：完全认可 A-Level，国际生走 Non-JUPAS 单独通道。

典型要求：港大工程 A*AA（数学/物理 A*）；港科大 A*AA/AAA；港中文 AAA。

申请：各校独立系统，港大 10 月–1 月滚动、港科大 11 月–1 月。

注意：面试常见；英语看雅思或 IGCSE 英语成绩；离内地近、留港/回内地都方便。

英国 UCAS

认可：A-Level 是英国本土主渠道，衔接最顺。

典型要求：帝国理工 / UCL 工程 A*AA（数学 A*）；罗素集团（曼大/谢菲/布里斯托）AAB–AAA。

申请：UCAS 统一平台，9 月初开放，1 月中截止（牛剑 + 医学 10 月 15）。

注意：一次最多申 5 所；一篇 PS；用预估分申、8 月实考分兑现条件。

澳洲 2/7 月入学

认可：接受 A-Level，按等级换算（通常 3 门 A-Level 计分）。

典型要求：悉尼 / 墨大 / UNSW 工程 AAA–AAB。

申请：8–10 月提前批，主轮 12 月–次年；多数只看成绩、无需 PS。

注意：2 月 / 7 月两次开学；移民与工作政策友好，是「保底 + 留外」的好选项。

中国内地 接受 A-Level

认可：中外合作大学（西交利物浦 / 宁波诺丁汉 / 上纽大 / 昆山杜克 / 港中深 / 北师港浸会）+ 部分顶尖高校国际生通道。

典型要求：西浦 / 宁诺 AAB–AAA；港中深 A*AA。

申请：各校独立，12 月–次年滚动；港中深有面试。

注意：适合「离家近 + 拿国际名校学位」；全英文授课、可衔接海外读研。

加拿大 OUAC

认可：接受 A-Level，通常看 2–3 门 A-Level + IGCSE 背景。

典型要求：多伦多大学工程 A*AA–AAB（数学 + 物理/化学）；麦吉尔 / UBC 工程 AAA–AAB。

申请：安省 OUAC 1 月中截止（早批 11 月）；其他省各自系统。

注意：看重课内成绩连续性；部分省要额外文书/面试；毕业工签政策宽松。

② 科研与项目

EPQ

Extended Project Qualification，独立研究项目，写报告 + 答辩。英联邦大学普遍认，是 PS 里「会做研究」的证据。

工程个人项目

做一个有成果的工程作品——如「车联网校车安全监护系统」（算法主导 + 报专利）、传感器智能硬件、自动驾驶仿真。

CREST Award

英国认可的科学项目认证（银奖/金奖），门槛比竞赛低、比纯兴趣高，适合高一高二起步。

立即启动 · 行动清单

Action checklist

本周（先动起来）

  • 本周带孩子解密公司最新智驾系统（用 AR 眼镜可视化「感知 → 决策」全过程），建立「这就是我以后要做的事」的画面感。
  • 本周打开本站总目录，和孩子约定「每天 30 分钟预习」，先玩物理 PhET、计算机 CircuitVerse 建手感。

本月（趁报名窗口）

  • 本月协调技术团队开《车规级 AI 开发》迷你课程。
  • 本月报名 11 月竞赛：AMC 10/12（数学）、BPhO（物理）——早报名早锁定。

本季（搭框架）

  • 本季在重庆仙桃数据谷策划「未来交通创客营」（员工子女 + 产业链伙伴子女一起）。
  • 本季建立「青少年科技导师库」，从公司技术骨干里定 2–3 位长期导师。

本学期（定方向）

  • 本学期和孩子一起定死 A-Level 四门组合与三年大时间表（可套用本页③时间轴）。
  • 本学期做一次雅思摸底，规划英语提升节奏。
母亲专属（来自原计划，立即启动）：本周解密智驾系统 → 本月开《车规级 AI 开发》迷你课 → 本季策划未来交通创客营。这三步把「企业家的资源」先转成「孩子眼前能摸到的工程」，再顺着本页时间轴一路沉淀成申请时的竞赛、专利、实习、项目——这才是可落地的「协同成长」。
本计划以 CAIE A-Level（数学 9709 / 物理 9702 / 计算机 9618 / 化学 9701）为基准，各目的地等级要求为工程类典型参考值，申请季请以各校当年官网为准。全站学科内容（预习站 + 速查表 + 真题包）在总目录，学起来直接点。
