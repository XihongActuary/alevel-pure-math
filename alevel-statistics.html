1 数据类型与频数表Data types and frequency tables Types of data数据类型
这一站要你会：判断一组数据是定性还是定量、离散还是连续，并能把原始数据整理成频数表。Goal: classify data as qualitative/quantitative, discrete/continuous, and organise raw data into a frequency table.
拿到一堆数字先别急着算，先问一句：这些数字是「名字」还是「数量」？「红色、蓝色」是名字（定性）；「3 分、5 分」是数量（定量）。数量里再分：能一个个数的（班里 28 个人）是离散；只能拿尺子量的（身高 1.73 米）是连续。分对了，后面画什么图、用什么公式才不会错。Before calculating, ask one thing: are these numbers "names" or "amounts"? "Red, blue" are names (qualitative); "3 marks, 5 marks" are amounts (quantitative). Amounts split again: countable (28 students) is discrete; measured (1.73 m tall) is continuous. Get this right and the right chart and formula follow.
  • 定性 qualitative：描述类别的词，不能做加减乘除（不能说「红色 + 蓝色」）。Qualitative: category words; you can't do arithmetic on them ("red + blue" is meaningless).
  • 定量 quantitative：真正的数字，能做运算。Quantitative: real numbers you can compute with.
  • 离散 discrete：只能取某些孤立的值（人数、骰子点数）。连续 continuous：可以取区间内任意值（身高、时间、重量）。Discrete: isolated values only (headcount, dice). Continuous: any value in a range (height, time, mass).
  • 频数表：把每个值（或每组）出现的次数数出来，列成两列——值和频数。Frequency table: count how often each value (or group) occurs, in two columns — value and frequency.
连续数据要「分组」：身高不能一个个列（1.71、1.72、1.73…无穷多），所以按区间分，如「1.60–1.70」记成一组。离散数据小的话就一个一个列。Continuous data needs grouping: you can't list every height, so use intervals like "1.60–1.70". Small discrete data can be listed one by one.
🗣 考场英文怎么说：How to say it in the exam: Quantitative data can be discrete, taking only certain values such as counts, or continuous, taking any value within a range such as measurements of height or time. Qualitative data describes categories rather than amounts.
例题Example
判断下列数据是「离散」还是「连续」：（a）某班学生人数；（b）学生的身高；（c）骰子掷出的点数；（d）跑 100 米的时间。Classify as discrete or continuous: (a) the number of students in a class, (b) students' heights, (c) dice scores, (d) 100 m sprint times.
(a) 人数是离散——只能 28、29、30，不能 28.5 个。(a) headcount is discrete — 28, 29, 30, never 28.5. (b) 身高是连续——可以是 1.73 m，也可以是 1.731 m。(b) height is continuous — 1.73 m or 1.731 m. (c) 骰子是离散——只有 1–6 六个值。(c) dice are discrete — only 1 to 6. (d) 时间是连续——可精确到任意小数。(d) time is continuous — measurable to any precision.

2 柱状图、饼图、茎叶图Bar charts, pie charts, stem-and-leaf Charts图表
这一站要你会：会画并读懂柱状图、饼图、茎叶图，知道各自适合什么数据。Goal: draw and read bar charts, pie charts and stem-and-leaf plots, and know which suits which data.
画图是为了一眼看出数据的形状。柱状图适合定性或离散数据（几类、几个值，条之间有缝）；饼图适合看占比（谁占几成）；茎叶图适合数据不多的两位数数据——它最妙的地方是不丢原始数据，一眼既能排序又能看出「哪个区间最密集」。Charts let you see the shape of data at a glance. Bar charts suit qualitative or discrete data (categories/values, bars separated); pie charts show proportions; stem-and-leaf suits small two-digit data — its beauty is that it keeps the raw values, so you can sort and spot where the data clusters.
  • 柱状图：条之间有空隙（区别于直方图），用于类别或离散值。Bar chart: bars separated (unlike a histogram), for categories or discrete values.
  • 饼图：一个圆切成扇形，扇形角度 ∝ 频数（每 1 个数据 = 360°/总数）。Pie chart: a circle sliced into sectors, angle ∝ frequency (360° ÷ total per item).
  • 茎叶图：茎 = 高位（十位），叶 = 低位（个位）；要有标题和「键」（key）说明单位。Stem-and-leaf: stem = leading digit(s), leaf = trailing digit; always give a title and a key showing the units.
茎叶图别忘「键」：考试里「4 | 2 代表 42」这句话（key）值一分。没有键，别人不知道「4 | 2」是 42 还是 4.2。Always add a key: the line "4 | 2 means 42" is worth a mark. Without a key, nobody knows if "4 | 2" is 42 or 4.2.
🗣 考场英文怎么说：How to say it in the exam: A stem-and-leaf diagram displays each data value by splitting it into a stem and a leaf, so the original data is not lost and the distribution can be seen. A key must be given to show what the digits represent.
例题Example
把数据 12, 15, 15, 18, 21, 24, 24, 24, 30 画成茎叶图，并写出键。Draw a stem-and-leaf plot for 12, 15, 15, 18, 21, 24, 24, 24, 30, and write the key.
1 | 2 5 5 8 2 | 1 4 4 4 3 | 0 键 key：2 | 4 代表 24
十位作茎、个位作叶，叶子从小到大排好，键说明「2 | 4 = 24」。Tens as stem, units as leaves in order, key says "2 | 4 means 24".

3 直方图与频数密度Histograms and frequency density Frequency density频数密度
这一站要你会：会用「频数密度 = 频数 ÷ 组宽」画直方图，也能从直方图反推频数。Goal: plot histograms using frequency density = frequency ÷ width, and recover frequencies from a histogram.
柱状图看的是条的高度，直方图看的是条的面积。为什么？因为直方图处理连续数据，分组时各组宽度可能不一样（0–10 宽 10，20–30 可能只宽 5）。如果还用高度代表频数，窄的组看起来就「矮」得冤枉。所以引出一个新量：频数密度 = 频数 ÷ 组宽——用它当纵轴，面积（密度 × 宽度）就正好等于频数，谁都不吃亏。A bar chart reads by bar height; a histogram reads by bar area. Why? Histograms handle continuous data, and groups may have unequal widths (0–10 is width 10, but 20–30 might be width 5). If height still meant frequency, the narrow group would look unfairly short. So we introduce frequency density = frequency ÷ width — plot that, and area (density × width) equals frequency exactly. Nobody is short-changed.
  • 频数密度 fd = 频数 ÷ 组宽。直方图的纵轴永远是频数密度，不是频数。Frequency density = frequency ÷ class width. The vertical axis is always frequency density, never frequency.
  • 面积 = 频数（高度 × 宽度 = fd × width = frequency）。Area = frequency (height × width = fd × width = frequency).
  • 条之间无空隙（连续数据连在一起），这是和柱状图的直观区别。No gaps between bars (continuous data joins up) — the visible difference from a bar chart.
反推频数的题：题目给一张直方图（含频数密度轴），问某组有多少个数据——就用「频数 = 频数密度 × 组宽」。别直接读高度当成频数，那是最常见的失分。Reverse questions: given a histogram, find a group's frequency via "frequency = frequency density × width". Reading the height as the frequency is the classic lost mark.
🗣 考场英文怎么说：How to say it in the exam: In a histogram the area of each bar is proportional to the frequency, so when the class widths are unequal we plot frequency density, equal to frequency divided by class width, on the vertical axis.
例题Example
某组区间「10 ≤ x < 20」宽 10，频数 40；另一组「20 ≤ x < 30」宽 10，频数 20；第三组「30 ≤ x < 40」宽 5，频数 20。求各组的频数密度。Groups: "10 ≤ x < 20" width 10, frequency 40; "20 ≤ x < 30" width 10, frequency 20; "30 ≤ x < 40" width 5, frequency 20. Find each frequency density.
频数密度 = 频数 ÷ 组宽。Frequency density = frequency ÷ width.
40 ÷ 10 = 4.0 20 ÷ 10 = 2.0 20 ÷ 5 = 4.0
注意第三组虽然频数和第二组一样（都是 20），但组宽只有一半，所以它的条更高（密度 4.0 对 2.0）——面积才公平。Note the third group has the same frequency (20) as the second but half the width, so its bar is taller (density 4.0 vs 2.0) — that keeps area fair.
练习Practice

点开看答案Show answer

4 箱线图与五数概括Box plots and the five-number summary Box plot箱线图
这一站要你会：求出一组数据的五数概括并画出箱线图，会用四分位距 IQR 描述数据的分散程度。Goal: find the five-number summary, draw a box plot, and use the interquartile range (IQR) to describe spread.
箱线图是数据的「体检报告」——它不画每一个数据，只画五个关键位置：最低点、下四分位（后 25% 从这里开始）、中位数（正中间那个）、上四分位（前 25% 到这里）、最高点。中间那个箱子框住的是最中间的 50%，箱子的长度叫「四分位距 IQR」，是衡量数据「散不散」的最常用尺子——因为它不受极端值影响，比「范围」可靠得多。A box plot is the data's medical report — it doesn't draw every value, just five key positions: minimum, lower quartile, median, upper quartile, maximum. The box encloses the middle 50%; its length is the "interquartile range (IQR)", the standard measure of spread because it ignores extreme values and is far more robust than the range.
  • 五数概括：最小值、Q1、中位数 Q2、Q3、最大值。Five-number summary: minimum, Q1, median Q2, Q3, maximum.
  • 中位数：排序后正中间的值（偶数个取中间两个的平均）。Median: the middle value once sorted (average of the two middle ones if even).
  • 四分位距 IQR = Q3 − Q1：中间 50% 数据的跨度，越大越分散。IQR = Q3 − Q1: the span of the middle 50%; larger means more spread out.
  • 离群值 outlier：落在「Q1 − 1.5×IQR」之下或「Q3 + 1.5×IQR」之上的极端数据（S1 常见）。Outliers: values below Q1 − 1.5×IQR or above Q3 + 1.5×IQR.
别把「范围」和「IQR」搞混：范围 = 最大 − 最小，会被一个极端值拉得很大；IQR 只看中间 50%，稳得多。题目问「哪种更能代表分散程度」时，优先答 IQR 并说明它不受极端值影响。Don't confuse range and IQR: range = max − min, easily inflated by one extreme value; IQR looks only at the middle 50%, so it is robust. When asked "which better measures spread", answer IQR and say it is unaffected by outliers.
🗣 考场英文怎么说：How to say it in the exam: The interquartile range is the difference between the upper and lower quartiles, so it measures the spread of the middle 50% of the data and is not affected by extreme values.
例题Example
数据（已排序）：3, 4, 6, 7, 9, 12, 15。求中位数、下四分位 Q1、上四分位 Q3 和 IQR。Sorted data: 3, 4, 6, 7, 9, 12, 15. Find the median, Q1, Q3 and IQR.
① 7 个数，中位数是第 4 个 = 7。① 7 values, median is the 4th = 7. ② 下半段 3, 4, 6 的中位数是 4 → Q1 = 4；上半段 9, 12, 15 的中位数是 12 → Q3 = 12。② lower half 3, 4, 6 → Q1 = 4; upper half 9, 12, 15 → Q3 = 12. ③ IQR = 12 − 4 = 8。③ IQR = 12 − 4 = 8.
练习Practice

下半段 5,8,9,11 → Q1 = (8+9)/2 = 8.5；上半段 12,14,15,18 → Q3 = (14+15)/2 = 14.5。
IQR = 14.5 − 8.5 = 6。 8 values: median = (11+12)/2 = 11.5.
Lower half 5,8,9,11 → Q1 = (8+9)/2 = 8.5; upper half 12,14,15,18 → Q3 = (14+15)/2 = 14.5.

5 累积频率图与百分位数Cumulative frequency graphs and percentiles Ogive累积频率
这一站要你会：建累积频率表、画累积频率图，并从图上读中位数、四分位数和百分位数。Goal: build a cumulative frequency table, draw the graph, and read off the median, quartiles and percentiles.
累积频率就是「数到这儿一共有多少」：第一个区间累积 5 个，到第二个区间累计 5+8=13 个，以此类推，越加越多。把这些「累计数」画成图，就是一条从左下爬到右上的 S 形曲线。它最有用的一点：能直接读出任意百分位数——想找中位数（第 50 百分位），就从纵轴 50% 处画条水平线，碰到曲线后往下看横轴，读数就是答案。四分位数、第 90 百分位都这么读。Cumulative frequency is a running total: 5 in the first group, 5+8=13 by the second, and so on, growing as you go. Plot these totals and you get an S-curve climbing from bottom-left to top-right. Its superpower: it reads any percentile directly. For the median (50th percentile), draw a horizontal line from 50% on the vertical axis, hit the curve, drop to the horizontal axis — that is your answer. Quartiles and the 90th percentile work the same way.
  • 累积频率表：把每个区间的频数依次累加，最后一格 = 总数。Cumulative frequency table: add each frequency in turn; the last entry equals the total.
  • 读中位数 / 四分位：在纵轴取 50% / 25% / 75%（或对应的累计频数），水平画线→碰曲线→垂直读横轴。Reading quartiles: take 50%/25%/75% on the vertical axis, go across to the curve, then down to the horizontal axis.
  • 百分位数：第 p 百分位是「p% 的数据都不超过它」的值。Percentiles: the p-th percentile is the value below which p% of the data lies.
画图起点：累积频率图从「第一个区间下界、累积 0」开始画，再连到每个区间上界的累计值。很多人漏掉起点那一段，曲线就会错位。Start the curve right: begin at the lower bound of the first class with cumulative 0, then join to each class's upper bound. Missing the starting point shifts the whole curve.
🗣 考场英文怎么说：How to say it in the exam: To find the median from a cumulative frequency graph, draw a horizontal line from the 50% (or half the total frequency) level on the vertical axis to the curve, then read the corresponding value on the horizontal axis.
例题Example
某组数据：区间 0–10（频数 5）、10–20（频数 8）、20–30（频数 7）。求累积频数表。Data: class 0–10 (frequency 5), 10–20 (8), 20–30 (7). Build the cumulative frequency table.
上界 累积频数 10 → 5 20 → 5+8 = 13 30 → 13+7 = 20
总数 20，中位数对应累计频数 10，落在 10–20 这一组里（从图读精确值）。Total 20; the median corresponds to cumulative 10, in the 10–20 class (read precisely from the graph).
练习Practice

点开看答案Show answer

1 平均数、中位数、众数Mean, median and mode Mean · median · mode平均数·中位数·众数
这一站要你会：会算平均数、中位数、众数三个代表值，并说得出各自的优缺点、什么时候用哪个。Goal: calculate the mean, median and mode, and explain their pros and cons and when to use each.
三个代表值就像三张成绩单：平均分是「把总分平摊到每个人头上」，中位数是「站中间那个人的成绩」，众数是「出现最多的那个选项」。一个班考试，平均分 80 可能被一个满分的学霸拉高，也可能被一个 0 分的拉低——所以平均数怕极端值。中位数才不管学霸考多高，它只问「谁站正中间」，所以稳。众数最特别：它能处理没法平均的东西，比如「大家最爱喝什么奶茶」——你能说珍珠奶茶出现最多，却没法算「奶茶的平均值」。The three averages are like three report cards: the mean "spreads the total over everyone", the median is "the score of the person in the middle", the mode is "the most common choice". In an exam, a mean of 80 could be pulled up by one 100-scorer or down by one 0-scorer — so the mean fears extreme values. The median doesn't care how high the top scorer went; it only asks "who is in the middle", so it is robust. The mode is special: it handles things you can't average, like "which bubble tea is most popular" — you can say pearl milk tea appears most, but you can't take "the average bubble tea".
  • 平均数 mean = 总和 ÷ 个数 = Σx / n：受极端值影响大。Mean = total ÷ count = Σx / n: strongly affected by extreme values.
  • 中位数 median：排序后正中间的值（偶数个取中间两个的平均），不受极端值影响。Median: the middle value once sorted (average of the middle two if even), unaffected by outliers.
  • 众数 mode：出现次数最多的值；可能有多个众数，也可能没有。是唯一能用于定性数据的代表量。Mode: the most frequent value; may have several or none. The only average that works for qualitative data.
  • 什么时候用哪个：对称分布用平均数；有极端值或偏态用中位数；定性数据用众数。When to use which: mean for symmetric data; median for skewed or outlying data; mode for qualitative data.
中位数先排序再找：偶数个数据没有「正中间那一个」，要取中间两个的平均。别拿没排序的原始数据直接找「中间位置」。Sort before finding the median: with an even count there is no single middle value — average the middle two. Never read the "middle" from unsorted data.
🗣 考场英文怎么说：How to say it in the exam: The mean is the sum of all values divided by the number of values, and it is affected by extreme values. The median is the middle value when the data are arranged in order and is not affected by outliers, so it is a better average for skewed data. The mode is the most frequent value.
例题Example

① 先排序：3, 5, 5, 8, 30。① sort first: 3, 5, 5, 8, 30. ② 平均数 = (3+5+5+8+30) ÷ 5 = 51 ÷ 5 = 10.2。② mean = (3+5+5+8+30) ÷ 5 = 51 ÷ 5 = 10.2. ③ 中位数 = 第 3 个 = 5。③ median = 3rd value = 5. ④ 众数 = 5（出现 2 次）。④ mode = 5 (appears twice). ⑤ 平均数 10.2 比中位数 5 高出一大截，因为 30 这个极端值把它拉高了——所以这组数据用中位数 5更合适。⑤ the mean 10.2 is much higher than the median 5, because the extreme 30 pulls it up — so the median 5 better represents this data.

2 范围与四分位距Range and interquartile range Range · IQR范围·四分位距
这一站要你会：算范围 range 和四分位距 IQR，并解释为什么 IQR 比范围更稳健。Goal: calculate the range and the interquartile range, and explain why the IQR is more robust than the range.
「代表值」告诉我们数据大概在哪，但光有中心还不够——两组成绩平均都是 60，一组人人都在 55–65 之间，另一组从 0 分到 100 分都有，差别就大了。这就是离散度要说的：数据散不散。最朴素的尺子是范围——最大减最小。但它有个致命伤：只要一个极端值，范围就爆表。于是有了四分位距 IQR——它只看中间 50% 的数据（Q3 减 Q1），把两头各 25% 的极端分子直接踢出局，所以怎么都不会被带偏。"Averages" tell us where the data sit, but a centre isn't enough — two classes can both average 60, yet one stays between 55 and 65 while the other ranges from 0 to 100. That difference is spread: how scattered the data are. The simplest ruler is the range — max minus min. But it has a fatal flaw: one extreme value blows it up. So we have the interquartile range (IQR) — it looks only at the middle 50% (Q3 minus Q1), kicking out the top and bottom 25% of extremes, so it can never be dragged off course.
  • 范围 range = 最大值 − 最小值：简单，但一个极端值就能把它拉得很大。Range = max − min: simple, but one extreme value inflates it.
  • 四分位距 IQR = Q3 − Q1：中间 50% 数据的跨度，不受极端值影响，是更稳健的离散度量。IQR = Q3 − Q1: the span of the middle 50%, unaffected by extremes — a more robust measure of spread.
  • Q1：下四分位（25% 的数据不超过它）；Q3：上四分位（75% 的数据不超过它）。Q1: lower quartile (25% of data at or below it); Q3: upper quartile (75% at or below it).
别把「范围」和「IQR」搞混：范围 = 最大 − 最小，会被一个极端值拉大；IQR 只看中间 50%，稳得多。题目问「哪种更能代表分散程度」时，优先答 IQR 并说明它不受极端值影响。Don't confuse range and IQR: range = max − min, easily inflated by one extreme; IQR looks only at the middle 50%, so it is robust. When asked "which better measures spread", answer IQR and say it is unaffected by outliers.
🗣 考场英文怎么说：How to say it in the exam: The range is the difference between the largest and smallest values, so it is easily affected by a single extreme value. The interquartile range is the difference between the upper and lower quartiles, measuring the spread of the middle 50% of the data, and so it is more robust.
例题Example

① 范围 = 15 − 3 = 12。① range = 15 − 3 = 12. ② 7 个数，中位数是第 4 个 = 7。下半段 3, 4, 6 → Q1 = 4；上半段 9, 12, 15 → Q3 = 12。② 7 values, median is the 4th = 7. Lower half 3, 4, 6 → Q1 = 4; upper half 9, 12, 15 → Q3 = 12. ③ IQR = 12 − 4 = 8。③ IQR = 12 − 4 = 8. ④ 范围 12 只看两头，IQR 8 只看中间 50%——如果 15 变成 150，范围会暴涨到 147，IQR 却一点不变。④ the range 12 uses only the ends, the IQR 8 uses the middle 50% — change 15 to 150 and the range explodes to 147, but the IQR stays exactly the same.

3 方差与标准差Variance and standard deviation Variance · SD方差·标准差
这一站要你会：理解离差、方差、标准差的含义，并用公式求出方差 σ² 和标准差 σ。Goal: understand deviation, variance and standard deviation, and calculate σ² and σ from the formula.
范围只看两头，太浪费。更好的想法是：看每一个数离平均数有多远——这个距离叫「离差」。但离差有正有负（比平均大的为正，小的为负），直接加起来正好互相抵消、恒等于 0，等于白算。怎么办？先平方，负数变正数，再求平均，这就是方差。方差单位是「平方」了（平方分、平方米），和原数据对不上，所以再开方还原，就是标准差。一句话：标准差是「平均每个数离平均有多远」——它越大，数据越散。The range only uses the ends, which wastes information. A better idea: look at how far every value is from the mean — that distance is the "deviation". But deviations are positive and negative, so they sum to exactly zero — useless. So square them first (negatives turn positive), average to get the variance. The variance is in "squared" units, so we square-root it back to the standard deviation. In one line: the standard deviation is "how far each value is from the mean, on average" — bigger means more spread.
  • 离差 = x − x̄：每个数减平均数，有正有负。Deviation = x − x̄: each value minus the mean, positive or negative.
  • 方差 σ² = Σ(x − x̄)² / n：离差平方的平均。Variance σ² = Σ(x − x̄)² / n: the mean of squared deviations.
  • 标准差 σ = √σ²：方差的平方根，单位和原数据一致。Standard deviation σ = √σ²: the square root of the variance, in the same units as the data.
  • σ 越大越散：标准差小 = 数据都挤在平均附近；大 = 数据散得开。Larger σ = more spread: small means the data huddle near the mean; large means they scatter.
考试两种公式都要会用：方差除了 Σ(x−x̄)²/n，还有计算更快的 Σx²/n − x̄²。手算数据多时，后者少算一遍离差，更不容易错。Know both forms: besides Σ(x−x̄)²/n, there is the faster Σx²/n − x̄². With many values, the second saves a pass over the deviations and is less error-prone.
🗣 考场英文怎么说：How to say it in the exam: The variance is the mean of the squared deviations from the mean, and the standard deviation is its square root. The standard deviation measures the average distance of the data values from the mean.
例题Example
求数据 2, 4, 6 的方差和标准差。Find the variance and standard deviation of 2, 4, 6.
① 平均数 x̄ = (2+4+6) ÷ 3 = 4。① mean x̄ = (2+4+6) ÷ 3 = 4. ② 离差：2−4 = −2，4−4 = 0，6−4 = +2。② deviations: 2−4 = −2, 4−4 = 0, 6−4 = +2.
σ² = Σ(x − x̄)² / n = [ (2−4)² + (4−4)² + (6−4)² ] / 3 = [ 4 + 0 + 4 ] / 3 = 8/3 ≈ 2.67
③ 标准差 σ = √(8/3) ≈ 1.63。③ standard deviation σ = √(8/3) ≈ 1.63.

4 分组数据求平均Mean from grouped data Mid-interval value组中值
这一站要你会：用「组中值 × 频数」的方法估算分组数据的平均数 x̄ = Σ(fx) / Σf。Goal: estimate the mean of grouped data using mid-interval values, x̄ = Σ(fx) / Σf.
分组数据最大的遗憾是：原始数据丢了。表上只写着「0–10 有 3 个」，你根本不知道这 3 个具体是 1、2、9 还是别的。怎么办？做个合理假设：每组的人全站在组正中间——0–10 全当 5，10–20 全当 15。这个「组正中间」叫组中值 mid-interval value。然后就像算加权平均：每个组中值 × 它的人数，加起来除以总人数。因为是个假设，结果只是估算值，但只要分组够细，误差很小。The big loss with grouped data is that the raw values are gone. The table only says "0–10 has 3", so you can't tell if they are 1, 2, 9 or anything else. What do we do? Make a fair assumption: everyone in a class stands at its midpoint — 0–10 is all 5, 10–20 is all 15. That midpoint is the mid-interval value. Then it's just a weighted average: each midpoint times its count, summed and divided by the total count. Because it's an assumption, the result is only an estimate, but with fine enough groups the error is small.
  • 组中值 = (下界 + 上界) ÷ 2：如 0–10 的组中值是 5。Mid-interval value = (lower + upper bound) ÷ 2: e.g. 0–10 has midpoint 5.
  • 平均数 x̄ = Σ(fx) / Σf：每个组中值 x 乘它的频数 f，求和后除以总频数。Mean x̄ = Σ(fx) / Σf: each midpoint x times its frequency f, summed and divided by the total frequency.
  • 这是估算 estimate：因为假设了组内数据都等于组中值，结果不是精确值。This is an estimate: we assumed all values in a class equal its midpoint, so the answer is not exact.
先建表再算：列两列「组中值 x」和「频数 f」，再算一列「fx」，加起来。别心算组中值——「0–10」的组中值是 5 不是 10，这类小错最常见。Make a table first: columns for midpoint x, frequency f, then fx. Don't do midpoints in your head — the midpoint of "0–10" is 5, not 10, a classic slip.
🗣 考场英文怎么说：How to say it in the exam: For grouped data, we use the midpoint of each class as a representative value, then estimate the mean using x̄ = Σfx / Σf.
例题Example
下表是某班身高的分组频数：0–10（3 人）、10–20（5 人）、20–30（2 人）。估算平均身高。Grouped heights: 0–10 (3 people), 10–20 (5), 20–30 (2). Estimate the mean height.
① 组中值：5、15、25。① midpoints: 5, 15, 25.
Σf = 3 + 5 + 2 = 10 Σfx = 5×3 + 15×5 + 25×2 = 15 + 75 + 50 = 140
② x̄ = Σfx / Σf = 140 / 10 = 14。② x̄ = Σfx / Σf = 140 / 10 = 14.

5 分组数据求标准差SD from grouped data σ² = Σf(x−x̄)²/Σf分组标准差公式
这一站要你会：用组中值套公式，求出分组数据的方差 σ² = Σf(x−x̄)²/Σf 和标准差 σ。Goal: use midpoints in the formula to find σ² = Σf(x−x̄)²/Σf and the standard deviation for grouped data.
求平均用组中值，求标准差还是用组中值，只是多乘一个频数 f。回想第 3 站：方差 = 离差平方的平均。分组后，每个「离差平方 (x−x̄)²」都要乘上这组的人数 f（因为组里每个人都贡献了这一份离差），全部加起来，除以总人数，再开方。道理没变，只是每个离差要「乘以它出现多少次」。We used midpoints for the mean; for the standard deviation we use midpoints again, just multiplying by the frequency f. Recall stop 3: variance = mean of squared deviations. After grouping, each squared deviation (x−x̄)² is multiplied by the class count f (every person in the class contributes that deviation), summed, divided by the total, then square-rooted. The idea is unchanged — each deviation is just multiplied by how often it occurs.
  • 方差 σ² = Σf(x − x̄)² / Σf：每个「离差平方」乘频数，求和除以总频数。Variance σ² = Σf(x − x̄)² / Σf: each squared deviation times its frequency, summed and divided by total frequency.
  • 等价快算公式 σ² = Σfx² / Σf − x̄²：先算「平方的平均」再减「平均的平方」，少算一步离差。Faster form σ² = Σfx² / Σf − x̄²: "mean of squares" minus "square of the mean", skipping a deviation pass.
  • 标准差 σ = √σ²：最后开方，单位和数据一致。Standard deviation σ = √σ²: square-root at the end, in the data's own units.
结果也是估算：分组标准差同样建立在「组内全等于组中值」的假设上，所以答案是估算值。计算题里只要按组中值正确套公式就行。The answer is also an estimate: it rests on the "all values equal the midpoint" assumption. In a calculation you just apply the formula with midpoints correctly.
🗣 考场英文怎么说：How to say it in the exam: For grouped data the variance is estimated by σ² = Σf(x − x̄)² / Σf, where x is the class midpoint, and the standard deviation is its square root.
例题Example

① 组中值 5、15、25，Σf = 10。① midpoints 5, 15, 25, with Σf = 10.
Σf(x−x̄)² = 3×(5−14)² + 5×(15−14)² + 2×(25−14)² = 3×81 + 5×1 + 2×121 = 243 + 5 + 242 = 490
② σ² = 490 / 10 = 49。② σ² = 490 / 10 = 49. ③ σ = √49 = 7。③ σ = √49 = 7.

6 选哪个代表量Choosing measures Skew · compare偏态·对比
这一站要你会：根据数据的形状（对称、偏态、有极端值、定性）选出正确的代表量与离散量，并会写「对比与解释」题。Goal: choose the right measure of centre and spread for symmetric, skewed, outlying or qualitative data, and answer "compare and explain" questions.
学到这里你会发现：没有哪个代表量永远最好，只有「最合适」。数据长得对称、没有捣乱的极端值，就用平均数 + 标准差——它把每一个数据都用上了。数据一边长着条「尾巴」（偏态）或者混进几个极端值，就用中位数 + 四分位距——它们不吃极端值那一套。数据根本不是数字、是类别（颜色、口味），那就只剩众数能用。判断偏态有个巧记：尾巴拖向哪边，平均数就被拉到哪边，众数永远守在山顶，中位数夹在两者之间。Here's the takeaway: no average is always best — only "most suitable". Symmetric data with no troublemaking outliers: use mean + standard deviation, which uses every value. Skewed data with a tail, or a few extremes: use median + IQR, which shrug off outliers. Data that aren't numbers at all (colour, flavour): only the mode works. A mnemonic for skew: the mean is pulled toward the tail, the mode stays on the peak, and the median sits in between.
  • 对称分布 → mean + SD：用尽所有数据，是「最精确」的一对。Symmetric → mean + SD: uses every value, the "most precise" pair.
  • 偏态 / 有极端值 → median + IQR：不受极端值影响，更能代表「大多数」。Skewed / outliers → median + IQR: unaffected by extremes, better represents "most of the data".
  • 定性数据 → mode：类别没法算平均，只能看出现最多。Qualitative → mode: categories can't be averaged, only counted.
  • 解释题套路：先指出分布形状 / 是否有极端值，再据此选量，最后用数据（谁大谁小、谁更稳）作对比。Explain-answer routine: state the shape or outliers, choose measures accordingly, then compare using the actual numbers.

1 概率是什么Basic probability Basic probability基本概率
这一站要你会：用「有利结果 ÷ 总结果」算简单概率，知道概率范围 0–1，并会用 P(not A) = 1 − P(A)。Goal: find a simple probability as favourable ÷ total, know it lies in 0–1, and use P(not A) = 1 − P(A).
概率就是「这件事有多可能发生」，用一个 0 到 1 的数表达。0 是不可能（太阳从西边升起），1 是铁定发生（明天太阳照样升起），中间的数表示「有多大把握」。怎么算？先数总共有几种结果，再数你要的那几种「有利结果」占几分之几。掷骰子想出 6：一共 6 种结果，有利的只有 1 种，所以概率是 1/6。Probability is how likely something is, a number from 0 to 1. 0 means impossible, 1 means certain, and in between is "how sure". How to find it: count all the outcomes, then see what share are the favourable ones you want. A die showing 6: 6 outcomes, 1 favourable, so 1/6.
  • 概率 = 有利结果数 ÷ 总结果数（前提：每种结果等可能 equally likely）。Probability = favourable ÷ total, provided all outcomes are equally likely.
  • 范围 0 ≤ P(A) ≤ 1，也可写成 0% 到 100%。0 ≤ P(A) ≤ 1, or 0% to 100%.
  • P(A) + P(not A) = 1，所以 P(not A) = 1 − P(A)。P(A) + P(not A) = 1, so P(not A) = 1 − P(A).
  • 等可能：每种结果发生的机会一样（公平的骰子、公平的硬币）。Equally likely: every outcome has the same chance (a fair die or coin).
先数清楚再除：分母是「总结果数」，分子是「你要的结果数」。答案写分数、小数、百分数都对（1/2、0.5、50% 是同一个数），但一道题里别来回混。Count before you divide: the denominator is all outcomes, the numerator is the ones you want. Fractions, decimals and percentages are all fine (1/2, 0.5, 50% are equal), but don't mix them in one answer.
🗣 考场英文怎么说：How to say it in the exam: The probability of an event is the number of favourable outcomes divided by the total number of equally likely outcomes. Probabilities always lie between 0 and 1, and P(not A) = 1 − P(A).

2 Venn 图Venn diagrams Venn diagrams韦恩图
这一站要你会：用 Venn 图表示事件，算交集与并集的概率，掌握 P(A∪B) = P(A) + P(B) − P(A∩B)。Goal: represent events with a Venn diagram, find intersection and union probabilities, and use P(A∪B) = P(A) + P(B) − P(A∩B).
把「事件」画成圆圈，事情立刻就清楚。A 圆是「事件 A 发生」，B 圆是「事件 B 发生」。两圆重叠的那块叫交集 A∩B，意思是「A 和 B 同时发生」。两个圆合起来的总范围叫并集 A∪B，意思是「A、B至少发生一个」。算并集有个坑：把 P(A) 和 P(B) 直接相加，重叠那块被数了两次，所以要减掉一次 P(A∩B)。Draw events as circles and everything gets clear. Circle A is "A happens", circle B is "B happens". The overlap is the intersection A∩B — both happen at the same time. The whole of both circles is the union A∪B — at least one happens. The union has a trap: if you just add P(A) and P(B), the overlap is counted twice, so subtract P(A∩B) once.
  • 交集 A∩B：两个事件同时发生。Intersection A∩B: both events happen together.
  • 并集 A∪B：至少一个发生（A 或 B 或都发生）。Union A∪B: at least one happens (A or B or both).
  • P(A∪B) = P(A) + P(B) − P(A∩B)。P(A∪B) = P(A) + P(B) − P(A∩B).
  • 若 A、B 不重叠（互斥），P(A∩B)=0，则 P(A∪B) = P(A) + P(B)。If A and B don't overlap (mutually exclusive), P(A∩B)=0, so P(A∪B) = P(A) + P(B).
「或」是「至少一个」，不是「二选一」：「下雨或刮风」包括「又下雨又刮风」。所以算「或」必须减掉交集，否则重叠部分被重复计数。"Or" means "at least one", not "pick one": "rain or wind" includes "both rain and wind". So an "or" calculation must subtract the overlap, or it gets counted twice.
🗣 考场英文怎么说：How to say it in the exam: For two events A and B, the intersection A∩B means both occur, and the union A∪B means at least one occurs. To avoid counting the overlap twice, P(A∪B) = P(A) + P(B) − P(A∩B).

3 互斥与独立Mutually exclusive vs independent Mutually exclusive vs independent互斥与独立
这一站要你会：分清「互斥 mutually exclusive」和「独立 independent」，并会用各自的公式算 P(A∩B)。Goal: tell apart "mutually exclusive" and "independent", and use each one's formula for P(A∩B).
这两个词最容易被搞混，但本质完全不同。互斥说的是「结果」：两件事不能同时发生——掷一次骰子，不可能既是 1 又是 6，所以「出 1」和「出 6」互斥。独立说的是「概率」：一件事发生不影响另一件的概率——掷两次骰子，第一次出几完全不改变第二次出几，这两次就独立。一句话：互斥看「能不能同时」，独立看「会不会互相影响」。These two are the easiest to mix up, but they're completely different. Mutually exclusive is about outcomes: both can't happen — one die can't show 1 and 6 at once, so "1" and "6" are mutually exclusive. Independent is about probabilities: one event doesn't change the probability of the other — two rolls, and the first never changes the second, so they're independent. In one line: exclusive asks "can they happen together?", independent asks "do they affect each other?"
  • 互斥：P(A∩B) = 0（不能同时发生）。此时 P(A∪B) = P(A) + P(B)。Mutually exclusive: P(A∩B) = 0 (can't both happen). Then P(A∪B) = P(A) + P(B).
  • 独立：P(A∩B) = P(A) × P(B)（互不影响）。Independent: P(A∩B) = P(A) × P(B) (no effect on each other).
  • 互斥 ⇒ 一定不独立：一件发生了，另一件概率直接变成 0。Mutually exclusive ⇒ never independent: once one happens, the other's probability drops to 0.
  • 独立 ⇒ 一般不互斥（除非某个概率是 0）。Independent ⇒ usually not mutually exclusive (unless a probability is 0).
判断独立只看一句：「B 发生了，会改变 A 的概率吗？」会变 → 不独立；不变 → 独立。别背「独立 = 相交圆」这种记法，那只是画图，不是定义。To test independence ask one thing: "does B happening change P(A)?" Yes → not independent; no → independent. Don't memorise "independent = overlapping circles" — that's just the picture, not the definition.
🗣 考场英文怎么说：How to say it in the exam: Two events are mutually exclusive if they cannot both occur, so P(A∩B) = 0. They are independent if one occurring does not change the probability of the other, so P(A∩B) = P(A) × P(B).

5 条件概率Conditional probability Conditional probability条件概率
这一站要你会：用 P(A|B) = P(A∩B)/P(B) 算条件概率，并理解它与独立的关系（独立则 P(A|B)=P(A)）。Goal: compute conditional probability with P(A|B) = P(A∩B)/P(B), and see its link to independence (independent ⇒ P(A|B)=P(A)).
条件概率就是「在已知某件事已经发生的前提下，另一件事的概率」。竖线 A|B 读作「在 B 发生的条件下，A 的概率」。直觉很简单：既然 B 已经发生了，我们就只看 B 这个圈，别的地方都不算数；A 还能发生的部分，就是和 B 重叠的 A∩B。所以 P(A|B) = 重叠 ÷ B 整个圈。如果 A 和 B 独立，那 B 发不发生根本不影响 A，于是 P(A|B) = P(A)——这就是「独立」的最准确定义。Conditional probability is "the probability of A, given that B has already happened". The bar A|B reads "probability of A given B". The idea is simple: since B has happened, we look only at circle B — nothing else counts; the part of A that can still happen is the overlap A∩B. So P(A|B) = overlap ÷ the whole of B. If A and B are independent, then B happening doesn't affect A, so P(A|B) = P(A) — the exact definition of independence.
  • P(A|B) = P(A∩B) ÷ P(B)，前提 P(B) ≠ 0。P(A|B) = P(A∩B) ÷ P(B), provided P(B) ≠ 0.
  • 读法：已知 B 发生，A 的概率。Reads: probability of A, given B.
  • 若 A、B 独立，则 P(A|B) = P(A)。If A and B are independent, then P(A|B) = P(A).
  • 变形：P(A∩B) = P(A|B) × P(B)（条件概率版的乘法）。Rearranged: P(A∩B) = P(A|B) × P(B) (the conditional multiplication rule).
「已知」二字就是信号：看到「在……的条件下」「已知……」「given that」，就用 P(A|B) 公式，先找出 P(A∩B) 和 P(B)，再除。"Given" is the signal: when you see "given that", "if it is known that", use the P(A|B) formula — find P(A∩B) and P(B), then divide.
🗣 考场英文怎么说：How to say it in the exam: The conditional probability of A given B is P(A|B) = P(A∩B)/P(B), the proportion of B that is also A. If A and B are independent, then P(A|B) = P(A).

1 计数原理与阶乘Counting principle and factorial Factorial阶乘
这一站要你会：用乘法原理算「分步」的总数，会算阶乘 n!，并记住 0! = 1。Goal: use the counting principle for multi-step totals, compute n!, and remember 0! = 1.
数东西也有规律，不用一个个傻数。核心就一句：一件事分几步做，就把每步的做法数乘起来。比如点早餐——面包 3 种、饮料 2 种、水果 2 种，一共就是 3 × 2 × 2 = 12 种搭配。这个「乘法原理」是后面所有排列、组合的总开关。而「阶乘」是它最顺手的写法：n! 就是从 n 一直乘到 1，比如 4! = 4 × 3 × 2 × 1 = 24。0! 有点怪，记成 1 就行。You don't count one by one. The rule: if a thing is done in steps, multiply the number of ways at each step. Breakfast: 3 breads, 2 drinks, 2 fruits → 3 × 2 × 2 = 12 combos. This "counting principle" is the master switch behind all permutations and combinations. The factorial is its handiest notation: n! multiplies down from n to 1, so 4! = 4 × 3 × 2 × 1 = 24. And 0! is a bit odd — just remember it's 1.
  • 乘法原理：分步进行的事，把每一步的方法数相乘（m × n × …）。Counting principle: for steps done in sequence, multiply the ways at each step (m × n × …).
  • 阶乘：n! = n × (n−1) × … × 3 × 2 × 1，读作「n 的阶乘」。Factorial: n! = n × (n−1) × … × 3 × 2 × 1.
  • 4! = 4 × 3 × 2 × 1 = 24。4! = 4 × 3 × 2 × 1 = 24.
  • 0! = 1（约定，记住即可）。0! = 1 (a definition — just remember it).
0! = 1 别纠结为什么：它的意思是「什么都没有，只有一种空排法」。记住它，后面公式在边界处才不会出错。Don't overthink 0! = 1: it means "with nothing to arrange, there is exactly one (empty) arrangement". Remember it and the formulas stay correct at the edges.
🗣 考场英文怎么说：How to say it in the exam: By the counting principle, if a task is carried out in several steps, the total number of ways is the product of the number of ways at each step. The factorial n! is the product of all the integers from n down to 1, and 0! is defined to be 1.

2 排列：顺序重要Permutations: order matters Permutation排列
这一站要你会：会用 ⁿPᵣ = n!/(n−r)! 求「从 n 个里取 r 个并排序」的方法数，比如 5P3 = 60。Goal: use ⁿPᵣ = n!/(n−r)! to count "r of n in order", e.g. 5P3 = 60.
排列的关键是顺序重要——A、B、C 和 B、A、C 是两码事，就像排队，谁站第一个不一样。从 5 个人里选 3 个排成一列：第一个位置 5 个人可选，第二个只剩 4 个，第三个只剩 3 个，所以是 5 × 4 × 3 = 60。这个「5 × 4 × 3」写成公式就是 ⁿPᵣ：P 是 permutation（排列）的首字母。The key to a permutation is that order matters — A, B, C and B, A, C are different, like a queue where who stands first matters. Line up 3 of 5 people: first slot 5 choices, second 4 left, third 3 left → 5 × 4 × 3 = 60. That "5 × 4 × 3" is written ⁿPᵣ, where P stands for permutation.
  • ⁿPᵣ = n! / (n − r)!：从 n 个里取 r 个并排顺序。ⁿPᵣ = n! / (n − r)!: take r of n in order.
  • 5P3 = 5! / 2! = 5 × 4 × 3 = 60。5P3 = 5! / 2! = 5 × 4 × 3 = 60.
  • 思路永远是：先选第一个、再第二个、再第三个，每步少一个。Always think: first slot, then second, then third — one fewer each step.
  • n 个全排就是 n!（nPn = n!）。Arranging all n is just n! (nPn = n!).

3 组合：顺序不重要Combinations: order doesn't matter Combination组合
这一站要你会：会用 ⁿCᵣ = n!/(r!(n−r)!) 求「从 n 个里选 r 个、不管顺序」的方法数，比如 5C3 = 10。Goal: use ⁿCᵣ = n!/(r!(n−r)!) to count "choose r of n, order irrelevant", e.g. 5C3 = 10.
组合和排列就差在顺序重不重要。组队时 A、B、C 和 B、A、C 是同一支队伍——谁先谁后无所谓。所以组合的数一定比排列小：先按排列算（5P3 = 60），再想想「这 3 个人自己的 3! = 6 种排法其实都是同一队」，把重复的除掉：60 ÷ 6 = 10。这就是 5C3 = 10，C 是 combination（组合）的首字母。A combination differs from a permutation only in whether order matters. In a team, A, B, C and B, A, C are the same — order is irrelevant. So a combination count is always smaller: start as a permutation (5P3 = 60), then notice the 3! = 6 orders of the same three people are all one team, and divide out the repeats: 60 ÷ 6 = 10. That is 5C3 = 10, where C is for combination.
  • ⁿCᵣ = n! / (r!(n − r)!)：从 n 个里选 r 个，不管顺序。ⁿCᵣ = n! / (r!(n − r)!): choose r of n, order irrelevant.
  • 5C3 = 5! / (3! × 2!) = 60 / 6 = 10。5C3 = 5! / (3! × 2!) = 60 / 6 = 10.
  • 组合 = 排列 ÷ r!：先排好，再把 r 个自己的顺序除掉。combination = permutation ÷ r!: arrange first, then divide out the r! internal orders.
  • 对称性：ⁿCᵣ = ⁿC₍ₙ₋ᵣ₎（选 3 个 = 剩下 2 个）。Symmetry: ⁿCᵣ = ⁿC₍ₙ₋ᵣ₎ (choosing 3 = leaving 2).

🗣 考场英文怎么说：How to say it in the exam: The number of combinations of r objects chosen from n distinct objects, where order does not matter, is nCr = n! / (r!(n − r)!).

5 含限制条件的计数Counting with restrictions Restrictions限制条件
这一站要你会：处理三类常见限制——相邻、不相邻、至少一个——并能一步步把结果算对。Goal: handle three common restrictions — adjacent, not adjacent, at least one — and compute the result step by step.
限制条件的题，是把前面所有东西加一点「刁难」。别怕，只有三招：相邻的捆成一个——把必须挨着的绑成一捆当一个人，最后捆内再排；不相邻的先排别人再插空——把不能挨着的塞进别人的空隙里；至少选一个就用总数减——正面不好算，就从反面「一个都不选」去减。看清题目属于哪一种，套对招数就稳了。Restriction questions just add a twist to everything above. Don't panic — there are only three tricks: tie the adjacent together into one block and permute inside it; place the others first, then slot in the non-adjacent ones; and subtract the unwanted from the total for "at least one". Spot which type it is, apply the right trick, and you're done.
  • 相邻：把相邻者捆成一捆当整体参与排列，再乘「捆内排列」。Adjacent: tie them into one block, arrange the blocks, then multiply by the block's internal order.
  • 不相邻：先排其余元素，再往空隙里插。Not adjacent: arrange the rest first, then insert into the gaps.
  • 至少一个：总数 − 一个都不选（反面法）。At least one: total − selecting none (complement).
反面法只对「至少」最好使：题目一说「至少一个」，先别硬数，想想「总数」和「一个都没有」哪个好算，相减就出答案。The complement shines for "at least": when you see "at least one", don't count directly — compute the total and "none", then subtract.
🗣 考场英文怎么说：How to say it in the exam: To keep certain objects adjacent, treat them as a single block, arrange the blocks, then multiply by the arrangements within the block. For "at least one", subtract the number of selections with none from the total.

1 随机变量是什么Random variables Random variables随机变量
这一站要你会：把随机试验的结果用一个数表示，判断一个随机变量是不是离散，并能写出它的概率分布表（每个值配一个概率）。Goal: turn a random outcome into a number, decide whether a random variable is discrete, and write its probability distribution (a probability for each value).

Roll a die: "one" gets tag 1, "two" gets tag 2… So the score X can be 1,2,3,4,5,6, each with its own probability. Because it takes finitely many, countable values, it is a discrete random variable. One iron rule: the probabilities must add up to 1 — the result has to be one of the six faces, no escape.
  • 随机变量 random variable：把随机试验的每个结果对应到一个数，用大写字母表示（如 X、Y）。Random variable: assigns a number to each outcome of a random trial; written with a capital letter (X, Y).

  • 概率分布 probability distribution：一张表，列出所有取值 x 和对应的 P(X=x)。Probability distribution: a table listing every value x with its P(X=x).
  • 铁律：Σ P(X=x) = 1，即所有概率相加等于 1。Iron rule: Σ P(X=x) = 1 — all probabilities add to 1.

2 期望 E(X)Expected value E(X) Expected value期望
这一站要你会：用公式 E(X) = Σ x·P(X=x) 求随机变量的期望，并理解它是「长期平均」而不是「最可能的值」。Goal: find the expected value with E(X) = Σ x·P(X=x), and see that it is a "long-run average", not "the most likely value".
期望就是「长期平均」。玩一个游戏：赢一次得 3 分、概率 1/3，得 5 分、概率 1/3，得 1 分、概率 1/3——平均每局拿 (3+5+1)/3 = 3 分。期望不是「最可能出现的那一个」，而是玩很多很多次之后，平均每次拿多少。算法就是：每个取值 × 它的概率，再加起来——概率大的值贡献多，所以叫「加权平均」。Expected value is the "long-run average". A game pays 3 points with probability 1/3, 5 with 1/3, 1 with 1/3 — on average (3+5+1)/3 = 3 per round. It is not "the most likely value", but what you get on average after many, many plays. The method: multiply each value by its probability, then add — values with bigger probability contribute more, hence "weighted average".
  • 定义：E(X) = Σ x·P(X=x)，把每个取值乘上它的概率再加起来。Definition: E(X) = Σ x·P(X=x) — multiply each value by its probability and add.
  • 含义：长期平均——重复无数次后的平均结果，不是「最可能的值」。Meaning: the long-run average over many repeats, not the most likely value.
  • 量纲：期望的单位和 X 一样（分、元、点）。Units: the expected value has the same units as X (marks, dollars, points).
  • 特例：若所有取值等概率，E(X) 就是普通的算术平均。Special case: if all values are equally likely, E(X) is just the ordinary average.
别把期望和「最可能值」搞混：掷骰子的期望是 3.5，但 3.5 根本掷不出来——它是长期平均，不是说「会掷出 3.5」。Don't confuse it with the most likely value: a die's expected value is 3.5, yet you can never roll 3.5 — it is the long-run average, not "you will roll 3.5".
🗣 考场英文怎么说：How to say it in the exam: The expected value of a discrete random variable X, written E(X), is the sum of each possible value multiplied by its probability, and it represents the long-run average of X.
例题Example

E(X) = 1×0.3 + 2×0.4 + 3×0.3 = 0.3 + 0.8 + 0.9 = 2
② 答案是 2——长期平均每次取值 2。② Answer 2 — the long-run average is 2.

3 方差 Var(X)Variance Var(X) Variance方差
这一站要你会：用两个公式求方差 Var(X)，并会求标准差 σ，用它们衡量随机变量的波动大小。Goal: find the variance Var(X) with either formula, and the standard deviation σ, to measure how spread out a random variable is.
方差回答「这个随机变量到底有多『飘』」。两个分布期望都是 5，但一个永远在 4、5、6 打转，另一个可能蹦到 1 或 9——第二个明显更刺激、更不稳。方差就是把这个「不稳」量化：先算每个值和平均差多少，差得越多说明越飘；再把差平方（否则正负抵消）、按概率加权，就得到方差。开个根号就是标准差 σ，单位和 X 一致，好理解。Variance answers "how jumpy is this random variable?" Two distributions both have mean 5, but one stays around 4,5,6 while the other can jump to 1 or 9 — the second is clearly more wild. Variance measures that unsteadiness: see how far each value is from the mean, square it (otherwise plus and minus cancel), weight by probability, and add. Take the square root and you get the standard deviation σ, whose units match X.
  • 定义：Var(X) = Σ (x − μ)²·P(X=x)，其中 μ = E(X)。Definition: Var(X) = Σ (x − μ)²·P(X=x), where μ = E(X).
  • 快捷公式：Var(X) = E(X²) − [E(X)]² = E(X²) − μ²（做题首选）。Shortcut formula: Var(X) = E(X²) − [E(X)]² = E(X²) − μ² (use this in exams).
  • 标准差：σ = √Var(X)，衡量波动，单位和 X 一样。Standard deviation: σ = √Var(X), the spread in the same units as X.
  • 性质：方差恒 ≥ 0；方差 = 0 表示 X 只有一个取值（根本不随机）。Property: variance is always ≥ 0; variance 0 means X has only one value (no randomness).
快捷公式最常用：先算 E(X²)（把 x 平方后再乘概率求和），再减 μ²。别把 E(X²) 当成 [E(X)]²——(1+4+9)/3 = 14/3，而 2² = 4，差远了。The shortcut is the most used: find E(X²) (square each x, multiply by probability, add), then subtract μ². Don't confuse E(X²) with [E(X)]² — (1+4+9)/3 = 14/3 while 2² = 4, very different.
🗣 考场英文怎么说：How to say it in the exam: The variance of X, written Var(X), measures how spread out the values of X are around the mean; it is found by E(X²) minus (E(X))², and the standard deviation is its square root.

E(X) = (1+2+3)/3 = 2 E(X²) = (1+4+9)/3 = 14/3 Var(X)= 14/3 − 4 = 2/3 σ = √(2/3) ≈ 0.816
② 用快捷公式 Var(X) = E(X²) − μ²，得 2/3；标准差开根号约 0.816。② Using Var(X) = E(X²) − μ² gives 2/3; the standard deviation is about 0.816.

4 线性变换 E(aX+b) 与 Var(aX+b)Linear transformations E(aX+b) and Var(aX+b) Linear transforms线性变换
这一站要你会：对随机变量做线性变换（乘 a 加 b）后，快速求出新的期望和方差，并明白为什么方差只跟 a² 有关。Goal: after a linear transformation (multiply by a, add b), quickly find the new mean and variance, and see why the variance depends only on a².
生活中经常给随机变量「加工」：把分数 X 每个都乘 2 再加 3（比如加分政策），得到 2X+3。期望跟着变——乘 2 加 3 照做：E(2X+3) = 2E(X)+3。但方差有讲究：乘 2 会让波动放大到 4 倍（平方！），加 3 却完全不影响波动（只是整体平移，散开程度没变）。所以 Var(2X+3) = 4Var(X)，那个 +3 在方差里彻底消失。We often "process" a random variable: scale every mark X by 2 then add 3 (a bonus policy), giving 2X+3. The mean follows along: E(2X+3) = 2E(X)+3. But variance has a twist: multiplying by 2 makes the spread 4 times bigger (squared!), while adding 3 doesn't change the spread at all (just shifts everything over). So Var(2X+3) = 4Var(X), and that +3 vanishes from the variance.
  • 期望：E(aX+b) = aE(X) + b——跟着「乘 a 加 b」直接变。Mean: E(aX+b) = aE(X) + b — follow "multiply by a, add b".
  • 方差：Var(aX+b) = a²Var(X)——只受 a² 影响，加 b 无影响。Variance: Var(aX+b) = a²Var(X) — only a² matters, b has no effect.
  • 标准差：σ(aX+b) = |a|·σ(X)——取绝对值，因为标准差非负。Standard deviation: σ(aX+b) = |a|·σ(X) — absolute value, since it is never negative.
  • 直觉：a 是放大镜（a² 放大波动），b 是平移（不改变形状）。Intuition: a is a magnifier (a² scales the spread), b is a shift (doesn't change the shape).
方差公式里是 a²，不是 a：乘 2 → 方差 ×4；乘 3 → 方差 ×9。很多人只乘一次 a 就错。加号后面的 b 对 Var 完全没有贡献。The variance uses a², not a: ×2 → variance ×4; ×3 → variance ×9. Many people multiply by a only once and get it wrong. The b at the end contributes nothing to Var.

5 综合应用Applied problems Fair games综合应用
这一站要你会：把游戏、抽奖这类场景建模成随机变量，用期望判断「划不划算」，并理解公平游戏的标准是 E = 0。Goal: model games and lotteries as random variables, use the expected value to judge "worth it or not", and see that a fair game means E = 0.
所有「要不要玩」的问题，都能用期望一锤定音。抽奖要付 2 元，中奖（概率 0.1）得 10 元、不中（概率 0.9）得 0 元——先算「净收益」：中了净赚 8，不中净亏 2。再算期望：8×0.1 + (−2)×0.9 = −1。意思是平均每玩一次亏 1 元，长期必亏，不划算。反过来，如果期望正好是 0，就叫「公平游戏」——长期不赚不亏。记住：店家敢让你玩，往往是因为期望是负的（他赚）。Every "should I play?" question is settled by expected value. A draw costs 2: win (probability 0.1) gets 10, lose (0.9) gets 0. Work out the net gain: win nets +8, lose nets −2. Expected value: 8×0.1 + (−2)×0.9 = −1. That means on average you lose 1 per draw — a losing game long-term. If the expected value is exactly 0, it is a fair game — no win or loss on average. Remember: if the house lets you play, the expectation is usually negative (they profit).
  • 建模：把「净收益」（= 奖金 − 成本）当作随机变量，写出每个结果的概率。Model it: make the "net gain" (= prize − cost) the random variable, with a probability for each outcome.
  • 判断：E(净收益) > 0 划算（长期赚），< 0 不划算（长期亏），= 0 公平。Judge: E(net gain) > 0 worth it, < 0 losing, = 0 fair.
  • 公平游戏 fair game：E(净收益) = 0，长期不赚不亏。Fair game: E(net gain) = 0, no win or loss on average.
  • 别忘了扣成本：期望要算「净」值，奖金要减去票价/本钱。Don't forget the cost: use the net value — subtract the ticket price from the prize.
最常见的错是只算「奖金期望」忘了减成本：比如奖金期望 1.8 元，票价 2 元，净期望 = 1.8 − 2 = −0.2，是亏的。The classic mistake is to use the prize's expectation and forget the cost: prize expectation 1.8 with a 2-dollar ticket gives net 1.8 − 2 = −0.2, a loss.
🗣 考场英文怎么说：How to say it in the exam: A game is fair if the expected gain is zero. If the expected gain is positive the game favours the player, and if it is negative it favours the organiser.

1 二项分布的条件The conditions for a binomial Binomial conditions二项条件
这一站要你会：背出二项分布的四个条件，判断一个场景是不是二项，并把成功次数写成 X ~ B(n, p)。Goal: recall the four conditions, decide whether a situation is binomial, and write the number of successes as X ~ B(n, p).
想象你在罚球线上投篮 10 次：每一次都独立（上一次进没进，不影响下一次的手感），每次命中率都固定是 70%，结果只有「进」或「没进」两种。你只盯着一个问题——「进了几次」。这个「成功的次数」就服从二项分布，写作 X ~ B(10, 0.7)。这四条一个都不能少：少了一条，比如命中率越投越累会下降，那就不是二项了。Imagine taking 10 free throws: each shot is independent (the last one doesn't affect the next), the success rate is fixed at 70% every time, and the result is only "in" or "miss". You only care about one thing — how many went in. That count follows a binomial distribution, written X ~ B(10, 0.7). All four conditions are needed: drop one — say the rate falls as you tire — and it is no longer binomial.
  • 固定次数 n：试验次数是事先定好的（掷 10 次、抽 20 个），不是「直到成功为止」。Fixed number n: the number of trials is set in advance (10 rolls, 20 items), not "keep going until you succeed".
  • 每次独立：一次的结果不影响其他任何一次。Independent trials: one result never affects another.
  • 两种结果：每次要么「成功」（概率 p）要么「失败」（概率 1−p），没有第三种。Two outcomes: each trial is "success" (probability p) or "failure" (probability 1−p), nothing else.
  • p 不变：每次成功的概率都一样。满足四条，成功次数记作 X ~ B(n, p)。Constant p: the success probability is the same every time. Then the number of successes is X ~ B(n, p).
「不放回」要当心：从一个袋子里摸球、摸完不放回，下一次的概率就变了，严格来说不是二项。只有「摸完放回」（或总体大到可以忽略变化）才近似是二项。Watch out for "without replacement": drawing without replacement changes the probability each time, so it is not strictly binomial. Only "with replacement" (or a huge population) keeps p constant enough.
🗣 考场英文怎么说：How to say it in the exam: A binomial distribution X ~ B(n, p) models the number of successes in n independent trials, where each trial has only two outcomes — success with probability p or failure with probability 1 − p — and the probability p is the same for every trial.

2 公式 P(X=r)The binomial probability formula Probability formula概率公式
这一站要你会：用公式 P(X = r) = nCr · p^r · (1−p)^(n−r) 求「恰好 r 次成功」的概率，并明白 nCr 是干嘛的。Goal: use P(X = r) = nCr · p^r · (1−p)^(n−r) to find the probability of exactly r successes, and understand what nCr does.
这个公式看着吓人，其实就三块相乘：nCr 是「r 次成功可以藏在哪几个位置」的摆法数；p^r 是「这 r 次都得成功」的概率；(1−p)^(n−r) 是「剩下那 n−r 次都得失败」的概率。打个比方：3 次投篮里恰好进 2 次，有「进进不进」「进不进进」「不进进进」三种顺序，每种顺序的概率都是 p²(1−p)，所以总概率是 3C2 = 3 倍。nCr 就是帮你把所有顺序一次性数清楚。The formula looks scary but is just three pieces multiplied: nCr counts where the r successes can hide; p^r is the probability those r all succeed; (1−p)^(n−r) is the probability the other n−r all fail. Example: 2 hits in 3 shots has three orders — hit-hit-miss, hit-miss-hit, miss-hit-hit — each with probability p²(1−p), so the total is 3C2 = 3 times that. nCr counts all those orders for you at once.
  • 公式：P(X = r) = nCr · p^r · (1−p)^(n−r)，r 是成功次数，n−r 是失败次数。Formula: P(X = r) = nCr · p^r · (1−p)^(n−r), where r = successes and n−r = failures.
  • nCr = n! / (r!(n−r)!)，读作「n 选 r」，是 r 次成功分布在不同位置的选法数。nCr = n! / (r!(n−r)!), read "n choose r", the number of ways to choose where the r successes occur.
  • p^r：r 次都成功的概率；(1−p)^(n−r)：剩下 n−r 次都失败的概率。p^r: all r succeed; (1−p)^(n−r): the other n−r all fail.
  • 管次数、不管顺序：二项只关心「一共几次成功」，所以要把所有顺序合并——这正是乘 nCr 的原因。Count, not order: the binomial only cares how many successes, so all orders are merged — that is exactly why we multiply by nCr.
别把 nCr 和「顺序」搞混：二项分布只数成功次数、不管先后顺序。若题目问的是「前 2 次成功、后 3 次失败」这种指定顺序，就不用乘 nCr，直接是 p²(1−p)³。Don't confuse nCr with order: the binomial only counts successes, not order. If the question gives a specific order like "first 2 succeed, last 3 fail", you do not multiply by nCr — it is just p²(1−p)³.
🗣 考场英文怎么说：How to say it in the exam: The probability of exactly r successes is given by P(X = r) = nCr p^r (1 − p)^(n − r), where nCr counts the number of ways of choosing the r trials on which the successes occur.
例题Example
设 X ~ B(5, 0.5)，求 P(X = 2)，即 5 次试验里恰好成功 2 次的概率。If X ~ B(5, 0.5), find P(X = 2) — the probability of exactly 2 successes in 5 trials.
① 套公式：P(X = 2) = 5C2 × 0.5² × 0.5³。① Plug in: P(X = 2) = 5C2 × 0.5² × 0.5³. ② 5C2 = 10，0.5² × 0.5³ = 0.5⁵ = 0.03125。② 5C2 = 10, and 0.5² × 0.5³ = 0.5⁵ = 0.03125.
P(X = 2) = 5C2 · 0.5^2 · 0.5^3 = 10 × 0.03125 = 0.3125
③ 答案是 0.3125，约三成一的把握恰好进 2 次。③ The answer is 0.3125 — about a 31% chance of exactly 2 hits.

3 期望与方差Mean and variance of the binomial Mean & variance期望方差
这一站要你会：用 E(X) = np 和 Var(X) = np(1−p) 快速求出二项随机变量的期望、方差和标准差。Goal: use E(X) = np and Var(X) = np(1−p) to quickly find the mean, variance and standard deviation of a binomial variable.
如果老老实实按定义算期望，要把 r 从 0 到 n 的每一项概率都算出来，再一个个乘、一个个加，n 一大就累死人。好在二项分布早有人帮我们推好了两条捷径：平均成功几次 = np（做 n 次、每次成功率 p，平均当然就是 np）；散不散 = np(1−p)。比如罚球 10 次、命中率 70%，平均进 7 个，一个式子就算完了。Doing the mean the slow way means computing every probability from r = 0 to n and adding them up — painful for large n. Luckily the binomial has two shortcuts: the average number of successes is np (n trials at rate p each), and the spread is np(1−p). With 10 free throws at 70%, you average 7 makes — one calculation, done.
  • 期望 E(X) = np：平均成功次数，就是「次数 × 每次成功率」。Mean E(X) = np: the average number of successes — "trials × success rate".
  • 方差 Var(X) = np(1−p) = npq：其中 q = 1−p 是失败概率。Variance Var(X) = np(1−p) = npq: where q = 1−p is the failure probability.
  • 标准差 = √Var(X) = √(npq)：开个根号就得到常用的离散尺度。Standard deviation = √Var(X) = √(npq): take the square root for the usual spread measure.
  • 先确认是二项：这两条公式只在「是二项分布」时成立，用之前先对照第 1 站的四个条件。Confirm it is binomial first: these formulas hold only for a binomial, so check the four conditions from stop 1 before using them.
常见错：把方差记成 np 或 np²。正确的是 np(1−p) = npq，比期望多乘一个失败概率 q。另外别忘了 q = 1−p 而不是 −p。Common mistakes: writing the variance as np or np². It is np(1−p) = npq — the mean times the failure probability q. And remember q = 1−p, not −p.
🗣 考场英文怎么说：How to say it in the exam: For a binomial random variable X ~ B(n, p), the mean is E(X) = np and the variance is Var(X) = np(1 − p).
例题Example

E(X) = np = 5 × 0.5 = 2.5 Var(X) = np(1−p) = 5 × 0.5 × 0.5 = 1.25
标准差 = √1.25 ≈ 1.12。期望 2.5 意味着平均成功 2.5 次，方差 1.25 说明结果围绕 2.5 上下小幅波动。Standard deviation = √1.25 ≈ 1.12. A mean of 2.5 means on average 2.5 successes, and a variance of 1.25 means results wiggle around 2.5 by a small amount.

4 查表与累加概率Tables and cumulative probabilities Cumulative累加概率
这一站要你会：用累加概率表求 P(X ≤ k) 和 P(X ≥ k)，并正确处理「小于」与「≤」之间的换算。Goal: use cumulative tables to find P(X ≤ k) and P(X ≥ k), and convert "less than" into "≤" correctly.
查表最大的坑不是不会查，是表里给的和题目问的不一样。表给的是累积值——P(X ≤ k) 表示「0 到 k 全部加起来」。题目却常问「至少」「小于」「超过」。记住两招：「至少 k」= 1 减「最多 k−1」（它们正好拼成全部）；「小于 k」=「最多 k−1」，因为 X 是整数，比 3 小就等于 0、1、2，也就是 ≤2。把题目的话先翻译成「≤ 几」，再去查表，就不会错。The trap isn't looking things up — it's that the table and the question don't match. The table gives cumulative values: P(X ≤ k) means "0 through k added together". But questions ask "at least", "less than", "more than". Two moves fix everything: "at least k" = 1 minus "at most k−1" (the two parts add to 1); and "less than k" = "at most k−1", because X is an integer — smaller than 3 means 0, 1, 2, which is ≤2. Translate the words into "≤ some number" first, then look it up.
  • P(X ≤ k)：0 到 k 的所有概率之和，表格直接给（或自己累加）。P(X ≤ k): the sum of probabilities from 0 to k — given directly by the table.
  • P(X ≥ k) = 1 − P(X ≤ k−1)：「至少 k」是「最多 k−1」的反面。P(X ≥ k) = 1 − P(X ≤ k−1): "at least k" is the opposite of "at most k−1".
  • 整数换算：P(X < 3) = P(X ≤ 2)；P(X > 3) = P(X ≥ 4)。Integer conversion: P(X < 3) = P(X ≤ 2); P(X > 3) = P(X ≥ 4).
  • 单点概率：P(X = k) = P(X ≤ k) − P(X ≤ k−1)。Single value: P(X = k) = P(X ≤ k) − P(X ≤ k−1).
「<」最容易错：题目写 P(X < 3)，先在心里翻成 P(X ≤ 2) 再查表，别把 3 直接当上界。反过来 P(X > 3) 是 P(X ≥ 4)，不是 P(X ≥ 3)。"<" is the classic slip: for P(X < 3), first translate to P(X ≤ 2) before looking it up — don't use 3 as the bound. Conversely P(X > 3) is P(X ≥ 4), not P(X ≥ 3).

  • 三个信号：固定做 n 次、每次独立、每次成功概率 p 相同且只有两种结果。Three signals: a fixed n, independent trials, and a constant success probability p with two outcomes.

Don't force it on small populations; for large ones, note "since the population is large, we can treat it as binomial".

1 正态曲线长什么样The normal distribution Normal distribution正态分布
这一站要你会：认出正态曲线的形状，知道 μ 决定位置、σ 决定胖瘦，并记住 68% 和 95% 两条经验规则。Goal: recognise the normal curve, know that μ sets the centre and σ the spread, and remember the 68% and 95% rules.
生活里很多东西都长成同一条曲线——全班的身高、体重、考试分数，都是中间一大坨、两边越来越少。把频率画出来，就是一条钟形曲线。它的好处是只用两个数就能完全描述：均值 μ 告诉你「中心在哪」，标准差 σ 告诉你「散不散」。σ 小的班，大家身高都差不多，曲线又高又瘦；σ 大的班，高矮悬殊，曲线又矮又胖。Many real things fall on the same curve — heights, weights and marks are all big in the middle and thin at the edges. Plot their frequencies and you get a bell. Its beauty: just two numbers describe it completely — the mean μ says "where the centre is", the standard deviation σ says "how spread out". Small σ means everyone is similar, so the curve is tall and narrow; large σ means a wide mix, so it is short and wide.
  • 正态分布 N(μ, σ²)：μ 是均值（位置），σ² 是方差，σ 是标准差（胖瘦）。Normal N(μ, σ²): μ is the mean (centre), σ² the variance, σ the standard deviation (spread).
  • 对称：关于 μ 左右对称，均值 = 中位数 = 众数，都在正中间。Symmetric: about μ, with mean = median = mode, all at the centre.
  • 总面积 = 1：整条曲线下的面积代表全部概率。Total area = 1: the whole area under the curve is all the probability.
  • 经验规则：约 68% 在 μ±σ，约 95% 在 μ±2σ（精确值 68.3%、95.4%）。Empirical rule: about 68% within μ±σ, about 95% within μ±2σ (exactly 68.3%, 95.4%).
别把 σ 和 σ² 搞混：题目常写成 X ~ N(μ, σ²)，括号里给的是方差。要用 σ 时先开根号。比如 N(100, 25) 其实是 σ = 5。Don't confuse σ and σ²: questions usually write X ~ N(μ, σ²), where the bracket is the variance. Square-root it to get σ. For example N(100, 25) actually means σ = 5.
🗣 考场英文怎么说：How to say it in the exam: The normal distribution is a symmetric bell-shaped curve. Its mean, median and mode are all equal, and the total area under the curve is 1. About 68% of values lie within one standard deviation of the mean and about 95% within two standard deviations.
例题Example
某市成年男性身高服从正态分布，均值 μ = 175 cm，标准差 σ = 6 cm。问身高落在 169–181 cm 之间的比例约是多少？Men's heights are normal with μ = 175 cm and σ = 6 cm. About what proportion lie between 169 and 181 cm?
169 = 175 − 6 = μ − σ；181 = 175 + 6 = μ + σ。169 = 175 − 6 = μ − σ; 181 = 175 + 6 = μ + σ. 这个区间就是 μ±σ，按经验规则约为 68%。This is exactly μ±σ, so by the empirical rule it is about 68%.

2 标准正态与 z 值Standard normal and z-score Standard normal标准正态
这一站要你会：把任意正态标准化成 Z = (X − μ)/σ，并读懂 z 值的含义。Goal: standardise any normal into Z = (X − μ)/σ and read what a z-score means.
每张正态表都只给标准正态 N(0,1) 的答案，可你的数据不一定是 N(0,1)。怎么办？做一个「翻译」：把原始值 x 换算成「离均值几个标准差」——这个数就是 z。翻译公式就一条：z = (x − μ) / σ。翻译完之后，不管原来是身高还是分数，全都变成了同一把「标准差尺子」上的刻度，就能统一查表了。Every normal table only answers for the standard normal N(0,1), but your data may not be N(0,1). The fix is a "translation": convert a raw value x into "how many standard deviations from the mean" — that number is z. One formula does it: z = (x − μ) / σ. After translating, heights and marks all become marks on the same "standard-deviation ruler", ready for one table.
  • 标准化：Z = (X − μ) / σ，结果 Z ~ N(0,1)。Standardise: Z = (X − μ) / σ, giving Z ~ N(0,1).
  • 标准正态 N(0,1)：均值 0，标准差 1，是查表的唯一入口。Standard normal N(0,1): mean 0, standard deviation 1 — the only table there is.
  • z 的含义：z > 0 在均值右边，z < 0 在左边，|z| 就是离均值几个 σ。Meaning of z: z > 0 is right of the mean, z < 0 is left, and |z| is how many σ away.

3 查表求概率Using the normal table Normal table正态表
这一站要你会：会用 Φ(z) 表求各种概率——左边的、右边的、中间的。Goal: use the Φ(z) table for left-tail, right-tail and between probabilities.
查表跟查字典一样，先要「翻译」（标准化成 z），再翻表找答案。表只给你左边那一片（Φ(z) = P(Z < z)）。可题目要的往往是右边的、中间的——没关系，靠两条就能拼出来：一是对称（左右关于 0 对称），二是总面积是 1。所以 P(Z > z) = 1 − Φ(z)，中间的 = Φ(大) − Φ(小)。Reading the table is like using a dictionary: first "translate" (standardise to z), then look it up. The table only gives the left-hand area (Φ(z) = P(Z < z)). But questions usually want the right or the middle — no problem, two facts rebuild anything: symmetry (left and right mirror about 0) and total area = 1. So P(Z > z) = 1 − Φ(z), and the middle = Φ(big) − Φ(small).
  • Φ(z) = P(Z < z)：表给的是左边面积。Φ(z) = P(Z < z): the table gives the left-hand area.
  • 对称性：Φ(−z) = 1 − Φ(z)。Symmetry: Φ(−z) = 1 − Φ(z).
  • 右边：P(Z > z) = 1 − Φ(z)。Right tail: P(Z > z) = 1 − Φ(z).
  • 中间：P(a < Z < b) = Φ(b) − Φ(a)。Between: P(a < Z < b) = Φ(b) − Φ(a).
永远先画图：把要求的概率涂出来，一眼就能看出该用 Φ、1 − Φ 还是两个相减。不画图直接套公式，最容易在「该不该减」上出错。Always draw first: shade the probability you want and it becomes obvious whether to use Φ, 1 − Φ, or a subtraction. Skipping the picture is where the "should I subtract?" mistakes happen.
🗣 考场英文怎么说：How to say it in the exam: The value Φ(z) is the probability that Z is less than z. To find P(Z > z) we use 1 − Φ(z), and by symmetry P(Z < −z) = 1 − Φ(z). For an interval, P(a < Z < b) = Φ(b) − Φ(a).

P(Z > 1) = 1 − Φ(1) = 1 − 0.8413 = 0.1587。P(Z > 1) = 1 − Φ(1) = 1 − 0.8413 = 0.1587. 对称性：P(Z < −1) = P(Z > 1) = 0.1587。By symmetry: P(Z < −1) = P(Z > 1) = 0.1587. P(−1 < Z < 1) = Φ(1) − Φ(−1) = 0.8413 − 0.1587 = 0.6826（正是 68% 那条经验规则）。P(−1 < Z < 1) = Φ(1) − Φ(−1) = 0.8413 − 0.1587 = 0.6826 (the 68% rule).

这一站要你会：已知概率反查 z，再用 x = μ + zσ 求出对应的原始值。Goal: given a probability, look up z, then recover x via x = μ + zσ.
正向是「给身高，求占比」，反向就是反过来——「给定占比，求身高」。比如想知道「最高的 10% 从多高开始」，就是反向查表。步骤反过来走：先在表里从概率找到 z，再乘 σ 加 μ 换回原来的单位。记住关键一步：面积 < 0.5，z 是负数，别把左右搞反。The forward problem gives a height and asks for the proportion; the inverse flips it — "given a proportion, find the height". "Where does the top 10% start?" is an inverse problem. Just run the steps backwards: find z from the probability, then multiply by σ and add μ. One key point: an area below 0.5 means z is negative — don't flip left and right.
  • 反向查表：在表里找概率 p，读出对应的 z。Inverse lookup: find the probability p in the table, then read off its z.
  • 还原公式：x = μ + zσ。Convert back: x = μ + zσ.
  • 判断正负：p < 0.5 时 z < 0（在左边）；p > 0.5 时 z > 0（在右边）。Sign check: p < 0.5 gives z < 0 (left); p > 0.5 gives z > 0 (right).

概率公式Probability formulas

P(A∪B) = P(A) + P(B) − P(A∩B) （或：至少一个） 互斥：P(A∩B) = 0 → P(A∪B) = P(A) + P(B) 独立：P(A∩B) = P(A) × P(B) 条件：P(A|B) = P(A∩B) / P(B) 补集：P(A′) = 1 − P(A)

排列与组合Permutations and combinations

阶乘：n! = n × (n−1) × … × 1，0! = 1 排列（顺序重要）：nPr = n! / (n−r)! 组合（顺序无关）：nCr = n! / (r!(n−r)!)

判断口诀：顺序变一下算不算新情况？算 → 排列；不算 → 组合。Quick test: does swapping the order make a new arrangement? Yes → permutation; no → combination.

随机变量Random variables

期望：E(X) = Σ x·P(X=x) 方差：Var(X) = E(X²) − [E(X)]² 线性变换：E(aX+b) = aE(X) + b Var(aX+b) = a²Var(X)

二项与正态分布Binomial and normal

二项：X ~ B(n, p) P(X=r) = nCr · p^r · (1−p)^(n−r) E(X) = np，Var(X) = np(1−p) 正态：X ~ N(μ, σ²) 标准化：Z = (X − μ) / σ μ±σ 约 68%，μ±2σ 约 95%
